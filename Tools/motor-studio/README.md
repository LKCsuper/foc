# FOC Studio 本地网页上位机

在仓库根目录运行 `node Tools/motor-studio/serve.cjs`，用桌面 Chrome / Edge 打开 http://127.0.0.1:4174/ 。无第三方依赖，无需前端构建；修改后刷新即可。

## 使用

1. 新通信功能需要本次配套固件，构建产物为 `F:\code\build\foc.hex`。本次没有烧录设备。
2. 在网页选择真实串口，连接 UART4 对应端口，默认 2,000,000 baud、8N1。连接会尝试 `studio on` 和参数回读，不启动电机。
3. 核对设备实际参数、反馈来源、速度环和电流限制。周期控制仅支持 I/F 控制路径，位置、关节、BLDC 和检测功能使用各自命令，不能混用。
4. 输入 RPM、Iq、Id，开启周期下发；此步骤只建立控制会话并同步目标。确认条件后另外点击启动。停止按钮会释放会话并请求停机。

## 功能与边界

- 上方常驻仪表、实时示波器和周期控制；下方命令、参数、日志独立切换。
- 覆盖当前 58 个注册命令及 help，每个命令和收录子功能有中文用途、参数与影响说明。
- 43 项配置、校准数据与电机档案；源码默认、本地草稿和设备回读分开显示。参数回读分时进行，不是整个配置的原子快照。
- 新固件支持停机逐项设置配置并返回执行确认，实际拒绝会显示原因。PWM/ADC 频率字段只读；不自动写 Flash。
- `saveparam` 的保存范围及上电默认覆盖行为由固件决定，不能假定所有调参值重启后保留。
- 曲线支持电流、速度、dq 和电角度正余弦；保留最多 1500 点，可导出当前曲线 CSV（主机时间和设备微秒时间）、参数 JSON 与日志。设备微秒计数会回绕。
- 新协议与旧 `plot` 流互斥；旧固件仍可使用手工命令，周期控制保持禁用。未连接时演示值不代表设备状态。

## 20 ms 通信

目标与遥测名义周期均为 20 ms（50 Hz），网页不是硬实时系统。目标只保留最新值，不积压补发；切到后台会暂停并尝试释放。主机超过 150 ms 未收到新遥测会停止周期下发；设备超过 300 ms 未收到有效目标会在后台任务请求停机，实际响应受任务调度影响，不能替代独立急停。

帧带 CRC、会话标识和递增序号。错误、过期及重复目标不续期；恢复连接不会自动重启。发送成功与设备执行成功分别显示。串口拥塞时固件整帧丢弃，不等待发送完成。未修改 FOC 中断及 ADC/PWM/DMA 同步配置。

### 同步多图

三相电流、转速、d/q 电流和电角度正余弦并列显示，共享 1/2/5/10 秒时间窗口，各自独立量程。宽屏四列，中小屏两列。新版遥测同一帧同时驱动四图，无需切换设备流或重新烧录。统一暂停仅冻结显示，接收和控制继续；四图 CSV 包含数据来源、主机时间和原始设备字段。无有效反馈时不绘制反馈转速。

### 组合操作

命令工作台顶部可选择 I/F 或 V/F 开环、目标 300 rpm 和可选参数，生成有中文说明的顺序命令。默认仅配置，勾选“最后启动电机”才包含 olstart；实际串口逐条等待对应回复和提示符，超时或失败中止并尝试 olstop。参数已生效部分不自动回滚，不自动清故障或保存 Flash。已有周期目标须先退出，组合不是周期控制，运行后的断线行为沿用普通 Shell 控制。真实硬件组合执行尚未验证。

无感组合可选“只观察（不接管）”或“无感接管运行”，后者可选速度环。模型/门槛/观测器/护栏按组设置，L 和磁链的命令单位为 mH/mWb；从设备回读填入时自动转换。无感接管启动需已知电机模型和接管/回退转速，目标不得低于接管门槛。实际锁定与 CLOSED 状态仍须看设备回复，模板不保证成功接管。

## 双端口分屏（当前默认布局）

- 控制台：http://127.0.0.1:4174/ ，连接串口、组合操作、参数与日志；图形已移到独立页面。
- 波形监视：http://127.0.0.1:4175/ ，只读四图、同步时间窗口、暂停和 CSV 导出，无串口连接或电机控制入口。
- 同一个 `node Tools/motor-studio/serve.cjs` 启动两个仅监听 127.0.0.1 的端口。两个窗口分屏，只在控制台连接 COM17。浏览器须保持控制窗口可见，已有周期控制在页面进入后台时仍会暂停。
- 控制页通过本地服务转发遥测，监视页通过 SSE 订阅，支持断线重连和最近 500 帧缓存；每次转发最多 100 帧，拥塞时不积压无限队列。不增加设备串口查询频率。
- 控制台心跳或设备样本过期时显示缓存/过期，演示数据明确标注。监视端禁止写入同步接口，控制端拒绝其他网站来源与并发控制页发布。此转发仅用于本机分屏，不提供远程网络控制。
- 验证命令：`node --test Tools/motor-studio/test-monitor.cjs Tools/motor-studio/test-protocol.mjs Tools/motor-studio/test-studio-link.mjs`；17 项通过，包含双端口、快照、持续同步及写入拒绝。

### 便捷操作

控制页支持本机命名模板、草稿自动恢复、模板JSON备份、整套命令复制、组合快捷入口与下一步引导。载入及恢复会清除启动勾选，只填表单，不自动执行。模板按浏览器和端口隔离保存，最多20项，同名保存覆盖。

监视页支持单图放大/恢复四图、点图例隐藏/显示通道、速度纵轴零点切换和清空曲线；隐藏通道不参与自动量程，清空只影响当前页面缓存。暂停/放大/显隐不影响设备控制或原始CSV导出。

### 顶部模式控制

顶部可选开环 I/F、正向电流/转矩、有感速度、无感速度和编码器位置模式，目标对应 rpm/A/角度。点击“配置并启动”才执行整套命令；若已运行会先停机后重启，执行失败尝试停机。位置默认保持当前位置，不自动清位置零点。

各模式沿用设备现有 PI/模型/保护配置；开环与无感起步默认 Iq=min(0.3A,回读电流预算)、Id=0。无感默认速度取接管门槛以上并受设备目标上限限制，有感要求对应标定，位置仅支持编码器。校准或状态不满足时按钮给出原因，不能替代实际反馈验证。

快捷电流模式当前仅正向 Iq，沿用有感角度及关闭速度环的电流路径，现有固件使用 1 rpm 非零参考放行使能，不作为实际速度目标或限速。该模式不保证速度；新增流程尚未实机启停验证。20 ms 周期目标仍保留在高级折叠区。

### 独立参数检测页

侧栏“电机参数检测”提供 R/L、R/L+磁链、分档磁链扫描，集中显示准备条件、参数、等待耗时、检测有效标志与原始输出。实机开始需停机、无故障、退出周期会话并勾选测试条件确认；运行时检测可能通电或旋转。

检测结果可导出JSON，三个模型值均有效时可仅填入无感模型草稿（μH自动换算为mH），不自动应用或写Flash。传感器/偏移校准按钮只打开高级命令说明，不自动执行。180秒无结束回复会请求中止；断线、超时或中止请求不代表已确认停机，须核对设备状态。新增页面未实机运行检测。

传感器与采样校准现已整合进检测页：直接选择偏移、编码器、霍尔或相序项目，使用同页开始/中止、原始输出和校准数据回读，不再跳转命令工作台。偏移/编码器为RAM版本，编码器会清除旧齿槽表，霍尔标定可能保存校准。编码器为同步固件流程，串口停止请求可能在流程返回后才处理；中止请求不等于已确认停机。
