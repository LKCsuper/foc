# 无实机验证入口

在仓库根目录执行 `python Test/run.py`。无需接电机、串口或烧录器。
默认使用已有 `.build/tools/ziglang/zig.exe`，也可通过 `--compiler <zig.exe路径>` 指定。
Python 测试沿用当前 Python 环境，缺少依赖会按失败记录，不自动安装。

本目录复用 `Tests/host/run.ps1` 的生产代码测试及 `Tests/host/test_*.py`，不复制已有算法或用例。
现有 C 套件遇到首个失败停止，其后用例不能视为已测；详细通过项以日志为准。
新增 `test_current_plant.c` 直接编译生产 `motor_pid.c`、`motor_foc.c` 和 `motor_utils.c`。

新增动态场景：

- 16 组 R/L、控制周期和 ADC 量化组合，执行 +1 A、−1 A、零电流阶跃。
- PI → 逆 Park → SVPWM → 比较值还原平均相电压 → Clarke/Park → RL 模型反馈。
- 每拍检查有限数值、电压限幅和 PWM 比较值范围；检查稳定区电流误差。
- 不可达 100 A 目标触发电压饱和，然后切换零目标，检查积分和电流恢复。

模型为锁轴、对称绕组的一阶 RL 精确离散模型，使用测试专用参数与增益。
生产 `inverse_park` 使用已验证的板级负极性，模型电压到正向电流的映射同步取反。
ADC 量化步长为 0.0806 A；量化场景误差门槛 0.10 A，理想采样为 0.02 A。
这不证明 BM75 低电流精度，也不代表当前实机默认增益已调好。
模型未覆盖机械运动、反电势、磁饱和、噪声、死区和真实 ADC/PWM 同步。
电压饱和后零目标恢复不是固件关桥测试；关桥与故障仲裁另由已有用例验证软件行为。

`python Test/run.py --skip-existing` 可单独运行新增动态场景。
每次运行覆盖 `Test/results/REPORT.md`、`summary.json` 和分组日志；生成文件已忽略。
测试组失败、编译失败或新增测试未运行都会返回非零退出码。
`Test/build/` 保存新增测试程序，现有套件沿用 `.build/`。

主机通过只说明所覆盖的软件行为符合断言，不能宣称全部代码功能或硬件验收通过。
