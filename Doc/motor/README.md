# 电机型号资料

| 型号 | 关键参数 | 资料与状态 |
| --- | --- | --- |
| 2804-220KV | 12N14P、7 极对、220 KV、12 V、额定 0.5 A | [工程图与首次调试](2804-220KV/适配与首次调试.md)，待上板验证 |
| C2208-100T | 12N14P、7 极对、120 KV、12 V、额定 0.8 A | [适配与首次调试](C2208-100T/适配与首次调试.md)，已有空载验证记录 |
| ATK-BL57H95D20E | 4 极、2 极对、24 V、额定 6.6 A | [原始资料](ATK-BL57H95D20E/) |

型号参数代码入口位于 `App/motor_param/inc/motor_nameplate.h`。新增或切换电机只修改型号 profile，
不得因此直接更改 BM75/VESC 派生的 ADC、PWM、DMA 和定时器基线。
