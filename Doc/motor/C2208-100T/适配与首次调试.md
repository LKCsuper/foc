# C2208-100T 新电机适配与首次调试

本文用于 BM75 功率板、C2208-100T 电机和 MT6701 绝对编码器的首次上板。当前编码器接口默认使用 SSI。

## 1. 已知参数与待确认项

| 项目 | 当前值 | 说明 |
| --- | ---: | --- |
| 磁极数 | 14 | 极对数为 7 |
| 槽数 | 12 | 12N14P |
| KV | 120 RPM/V | 工程图标称值 |
| 额定电压 | 12 V | 首次调试应使用限流电源 |
| 最大电压 | 24 V | 不是首次调试推荐电压 |
| 额定电流 | 0.8 A | 首次测试从 0.2～0.3 A 开始 |
| 最大电流 | 4.5 A | 不作为首次调试电流 |
| 电阻 | 21.2 Ω | 工程图未说明是相电阻还是线间电阻，必须实测确认 |
| 相电感 | 5.3 mH | 工程图标称值，建议实测确认 |

三根动力线没有固定的 U/V/W 标识。任意接入三相桥可以进行低功率验证，方向不对时通过相序或编码器方向标定处理，不要带负载直接试错。

## 2. 选择电机头文件

电机参数入口是 `App/motor_param/inc/motor_nameplate.h`。将默认选择改为：

```c
#define MOTOR_SELECTED_MODEL MOTOR_MODEL_C2208_100T
```

也可以在 Keil 工程预处理宏中定义：

```text
MOTOR_SELECTED_MODEL=MOTOR_MODEL_C2208_100T
```

两种方式只使用一种。编译后应使用 `motor_c2208_100t.h` 中的 7 极对、1800 RPM 等参数。

当前源码默认选择 C2208-100T。切换到 ATK-BL57H95D20E 时，必须同步选择对应电机头，不能混用参数。

## 3. MT6701 SSI 接线

MT6701 模块按板上丝印连接 BM75：

| MT6701 模块 | BM75 接口网络 | MCU |
| --- | --- | --- |
| VCC | 5V | — |
| GND | GND | — |
| CSN | RX_SDA_NSS | PB11 |
| CLK | SCK_ADC_EXT | PA5 |
| DO | MISO_ADC_EXT2 | PA6 |

模块供电使用 **5 V**。SSI 的 DO 是传感器输出，接 MCU 的 MISO；PA7/MOSI 不需要连接传感器。

当前软件参数：14 位单圈角度（16384 count/rev）、SSI 采样 10 kHz、SPI1 Mode 1。

## 4. 上电后的安全检查

首次上电先让电机保持空载并固定好机架，直流电源设置较低电流限制。不要先执行 `olstart`。

启动日志应包含：

```text
Init MT6701 SSI
Encoder MT6701 SSI: 16384 count/rev
```

执行：

```text
encoder show
```

应满足：

- `valid=1`
- `err=0` 或不持续增加
- `crc_err=0` 或不持续增加
- 手动缓慢转轴时 `count` 和 `mech` 连续变化
- 静止时 `rpm` 最终回到 0 附近

`zero_valid=0` 只表示尚未建立电角零点，不代表 SSI 通信失败。

## 5. 电流采样偏移

电流偏移属于 BM75 采样链和 ADC 的零点，不是电机参数。Flash 中已有有效偏移且三相均接近 2048 时，可以继续沿用；换电机本身不强制重测。

以下情况建议重新检测：

- 第一次使用这块功率板；
- 更换功率板、电流采样器件或 ADC 配置；
- Flash 参数无效；
- 停机时三相电流明显不为零；
- 温度变化后零漂明显。

确保电机停止，然后执行：

```text
detect offset
```

成功时应看到 `Detect End: SUCCESS`。检查三相 `Current Offset` 接近 2048 且彼此差异较小，再执行：

```text
saveparam
```

保存期间不得启动电机。

## 6. 推荐调试顺序

### 6.1 先验证开环和相序

1. 确认已选择 C2208 电机头文件，极对数为 7。
2. 确认母线电压、限流和电流偏移正常。
3. 保持编码器反馈关闭，先使用开环反馈：

```text
olfb openloop
spenable 0
slenable 0
```

4. 使用低电流、低目标转速进行首次试转。C2208 额定电流仅 0.8 A，建议从 0.2～0.3 A 开始，不要直接沿用原 ATK 电机的 1.5 A 给定。
5. 若抖动、反复摆动、过流或不能连续旋转，立即执行：

```text
olstop
```

此时先检查 U/V/W 相序、极对数、电流方向和参数，不要直接提高电流。

### 6.2 再标定编码器电角零点

编码器机械角可读并不代表能直接用于 FOC。闭环前必须建立以下关系：

- MT6701 机械角方向；
- 电机正转方向；
- 7 极对机械角到电角度的换算；
- 转子磁链 D 轴对应的电角零点。

当前 `encoder detect` 会把 `oliq` 当前值作为对齐 Id，在电角度 0 处用 0.5 s 缓慢升流、保持 0.7 s；随后正向移动 90° 电角判断 MT6701 方向并返回，再正反缓慢扫描一整圈机械角。扫描在 280 个位置对“编码器电角－强制电角”做 sin/cos 圆周平均，得到电角偏置。命令只允许 0.1～0.5 A，并在结束或故障时停止 PWM。

在自动对齐检测和零点持久化补齐前：

- 执行前保持电机空载，并确认 `oliq 0.2`；
- 执行时转子应平顺吸合后保持不动；若剧烈抖动、过流或不能稳定，立即断开驱动并排查相序/采样；
- 检测成功后方向与电角偏置会自动写入 Flash；重启时恢复并直接置 `zero_valid=1`；
- 旧 v2 Flash 槽仍可读取原有电流/电压偏移，首次成功检测后自动以 v3 格式写入新槽。

### 6.3 最后验证有感电流闭环

只有电角零点和方向均确认后，才切换：

```text
olfb encoder
```

从很小的 Iq 开始，观察 Id、Iq、转向、母线电流和故障状态。确认电流环稳定后，再逐步提高转速或加入速度环；不要同时开启速度环、弱磁和无感接管。

## 8. 当前限制

- C2208 图纸中的 21.2 Ω 电阻口径尚未确认。
- 磁链由 120 KV 估算，尚未通过反电势实测校核。
- BM75 对 C2208 小电流的采样分辨率不足；当前编码器速度环采用电压前馈与速度 PI，电流采样保留作诊断。
- 固定 D 轴电角零点对齐、方向自动判断、多点平均和 Flash 持久化均已实现。
- 编码器有感速度闭环已完成 30/60 RPM 上板验证；更高转速、带载能力和按角度抗齿槽补偿仍待验证。
