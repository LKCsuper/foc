# 无感一键多速度测试 sltest

当前命令已编译、烧录，在2804、16 V空载测试通过。

```text
sltest
```

先在600 RPM以0.30 A I/F拖转约8秒，再等待无感接管，稳定后依次测试500、600、700 RPM，每档稳定等待2秒、统计保持5秒。正常整轮约32秒，结束关断输出、目标置0、速度环关闭并恢复原配置。

```text
sltest 5 600 1000 1400 1800 2200 2600
```

第一参数为每档统计保持秒数（2～20），之后为1～6个正向目标（500～2600 RPM）。不指定目标时使用500/600/700。测试仅适用于当前7极对、15～17 V验证范围，接管门槛≤600 RPM、回退门槛<500 RPM；不足条件或正在运行/BLDC占用/参数检测/故障锁存时拒绝开始。

测试中输入一条新命令可中止；新输入作为停止请求消费，不会继续执行。故障、电流|Id/Iq|>1 A、起转阶段观测速度>900 RPM，闭环阶段超过min(3000,max(900,1.25×目标)) RPM、接管超时、接管丢失、目标被改变会中止；统计阶段连续5个监测样本速度误差超过max(60RPM,20%目标)也中止。监测在任务中每50ms检查，不替代快速硬件/电机保护。

最高目标大于1200 RPM时临时将输出电压上限设为8 V，结束恢复；高于800 RPM的目标仅在CLOSED接管后下发，起转上限仍800 RPM。配置最大速度不足请求值时拒绝开始。

沿用当前电机模型和电流零偏，不自动校准、不写Flash。临时使用已验证速度PI Kp=.0003、Ki=.0005、Iq上限.15 A，启动Iq=.30 A、Id=0；测试后恢复。编码器不是运行必需条件，仅在已启用比较且样本有效新鲜时附带输出参考转速。PASS表示固件维持无感反馈、观测跟踪通过，不代替实轴/负载验证。
