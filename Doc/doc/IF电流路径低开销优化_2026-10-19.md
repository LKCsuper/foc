# I/F 电流路径低开销优化

## 范围

沿用观测器下限优化，继续缩减 I/F 电流控制外围开销，不改双轴 PI 公式、增益、目标限流圆、矢量限幅、抗饱和、坐标交接、保护、15 kHz 或底层外设。

- `Motor_Current_LimitTargets`：使用与 ±FLT_MAX 比较检查有限数，保留 NaN/Inf 输入或非正上限时双目标清零。仅此函数改用局部检查，不改全局数学工具。
- 饱和分支以比较选择非负余量，替代固定正零下限的 fmaxf；保留 sqrt 和原缩放/符号规则。
- 弱磁关闭时不再提前计算只供 IdRoom 使用的 Iq 幅值；仍执行原 Motor_Fw_Step，状态清零和开启弱磁的行为保持。
- 坐标交接分支复用同次 Step 中已读的细分计时开关，避免重复查询；PI 的公开入口保持独立可用。

## 验证

新增 11×11×11=1331 组 Id/Iq/上限组合，覆盖 NaN、正负无穷、正负 FLT_MAX、正负零、常规目标与极小电流，逐位比较新目标限流结果与原 isfinite/fmaxf 实现。包括平方溢出、下溢情形，保持原有边界行为而非扩大本次范围修复其他数值问题。
