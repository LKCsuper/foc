# 采样时间与各层频率

> 2026-09-20。本板当前数字，不是通用教材。
> 外设链路细节见 [TIM / ADC / DMA 初始化总结](./TIM_ADC_DMA初始化总结.md)、[ADC 初始化笔记](./ADC初始化笔记.md)。
> 电流环怎么跑见 [开环电流环调试说明](./开环电流环调试说明.md)。

电机控制里「采样时间」至少有四种完全不同的东西。混在一起，后面电流环、速度环、霍尔测速、PI 的 `dt` 都会看不懂。

---

## 0. 先分清四种「时间」

| 名字                    | 问的是什么                   | 本板当前值                                                       | 单位直觉                     |
| ----------------------- | ---------------------------- | ---------------------------------------------------------------- | ---------------------------- |
| **模拟采样时间**  | ADC 电容充电多久才锁存电压   | 15 个 ADC 时钟 ≈**357 ns**                                | 纳秒，硬件窗口               |
| **ADC 触发周期**  | 多久采一帧电流/电压          | **30 kHz / 33.3 µs**                                      | 中心对齐 PWM 顶部+底部各一次 |
| **PWM 开关周期**  | MOS 完整三角波多久走一圈     | **15 kHz / 66.7 µs**                                      | 功率级真正开关频率           |
| **控制拍 `dt`** | PI / 斜坡 / 观测器按多长积分 | 电流环**15 kHz / 66.7 µs**；速度环 **1 kHz / 1 ms** | 软件认为的「这一拍时长」     |

另外还有电机自己的频率，和控制频率不是一回事：

| 名字                     | 公式                 | 72 RPM           | 1500 RPM        | 3000 RPM（额定） |
| ------------------------ | -------------------- | ---------------- | --------------- | ---------------- |
| 机械频率                 | `n / 60`           | 1.2 Hz           | 25 Hz           | 50 Hz            |
| **电频率** `f_e` | `n / 60 × 极对数` | **2.4 Hz** | **50 Hz** | **100 Hz** |
| 霍尔边沿                 | `6 × f_e`         | 14.4 Hz          | 300 Hz          | 600 Hz           |

本电机 2 对极（4 磁极）。电频率才是 Park 变换、反电势、弱磁该对齐的那个。

**层级关系（由快到慢）：**

```text
模拟窗口 357 ns
    ⊂  ADC 转换一帧 ~3 µs
        ⊂  ADC 触发 33.3 µs (30 kHz)
            ⊂  PWM / 电流环 66.7 µs (15 kHz)
                ⊂  Hall 更新 ~267 µs (3.75 kHz)
                    ⊂  速度环 1 ms (1 kHz)
                        ⊂  电周期 10 ms @ 3000 RPM  …  417 ms @ 72 RPM
                            ⊂  FreeRTOS 任务  (ms 级，不能进电流环)
```

电流环必须比电频率快一个数量级以上；速度环必须比电流环慢。本板 15 kHz 对 100 Hz 电频率，一圈大约 150 拍，余量足够。

## 1. 本板频率总表

时钟树：HSI/HSE → PLL → **SYSCLK = 168 MHz**。AHB 168 MHz；APB2 84 MHz（TIM1 定时器时钟 ×2 = **168 MHz**）；APB1 42 MHz（TIM2/4/5 定时器时钟 ×2 = **84 MHz**）；ADC 时钟 = APB2/2 = **42 MHz**。

| 量                       | 频率             | 周期                                 | 代码落点                                         |
| ------------------------ | ---------------- | ------------------------------------ | ------------------------------------------------ |
| CPU / HCLK               | 168 MHz          | 6.0 ns                               | `SYSTEM_CORE_CLOCK`                            |
| TIM1 计数时钟            | 168 MHz          | 6.0 ns                               | APB2 定时器                                      |
| TIM1 ARR                 | 5600 计数        | —                                   | `168e6 / 30000`                                |
| **PWM 开关**       | **15 kHz** | **66.7 µs**                   | `Bsp_Tim_Pwm1(30000)`，中心对齐所以 `/2`     |
| 死区                     | —               | **360 ns**                     | `HW_DEAD_TIME_NSEC`                            |
| TIM1 更新事件            | 30 kHz           | 33.3 µs                             | 三角波顶部 + 底部各一次 UEV                      |
| TIM2 触发 ADC            | 30 kHz           | 33.3 µs                             | TIM1 UEV 复位 TIM2，CCR2=1 后 CC2 下降沿         |
| ADC 模拟窗口             | —               | 15 cycle ≈ 357 ns                   | `ADC_SampleTime_15Cycles`                      |
| ADC 一帧转换             | —               | 5 档 × 27 cycle ≈**3.2 µs** | 三重同步，12 bit                                 |
| **ADC-DMA 回调**   | **30 kHz** | **33.3 µs**                   | `Motor_DmaInt`，`ol_foc_freq` 存的就是它     |
| FOC 分频                 | ÷2              | —                                   | `FOC_CONTROL_LOOP_FREQ_DIVIDER`                |
| **电流环 / SVPWM** | **15 kHz** | **66.7 µs**                   | 每个完整 PWM 周期一次                            |
| Hall FOC 采样侧          | 15 kHz           | 66.7 µs                             | 只用 TIM1**向下计数**（顶部零矢量）        |
| Hall 角度更新            | 3.75 kHz         | 267 µs                              | `MOTOR_HALL_ADC_DIVIDER = 4`                   |
| Hall-PLL 带宽            | 10 Hz            | —                                   | `MOTOR_HALL_PLL_BW_HZ`                         |
| **速度环**         | **1 kHz**  | **1 ms**                       | `foc pid` 任务，`speed_loop_hz`；ISR 只读 Iq |
| TIM5 耗时计数            | 1 MHz            | 1 µs                                | ISR`avg/max us`                                |
| FreeRTOS tick            | 10 kHz           | 100 µs                              | `configTICK_RATE_HZ`，`Bsp_Sys_Init(10000)`  |
| 编码器                   | 4096 计数/机械圈 | 事件驱动                             | TIM4，1024 线 × 4 倍频                          |

`olstatus` 里那一行直接读实测：

```text
FOC loop : 15000 Hz adc=30000 div=2 avg=..us max=..us load=..%
```

`ol_foc_freq` **不是** PWM 频率，是 ADC-DMA 基准 30 kHz。真正 FOC `dt` 还要乘分频。

## 2. PWM：15 kHz 是怎么来的

```c
Bsp_Tim_Pwm1(30000);          /* Library/Bsp/bsp_tim.c */
TIM_Period = 168000000 / 30000;   /* ARR = 5600 */
CounterMode = CenterAligned1;     /* 0 → ARR → 0 走一圈才是一个 PWM 周期 */
```

中心对齐：

```text
CNT
ARR 5600 ────────●────────          ← 顶部：高侧关、低侧开 → 零矢量 V0
                / \
               /   \
              /     \
             /       \
            /         \
0 ────────●───────────●──          ← 底部：高侧开、低侧关 → 零矢量 V7
          0    33.3µs    66.7µs
               ↑ ADC        ↑ ADC
```

公式：

```text
f_pwm = TIM1时钟 / (2 × ARR) = 168e6 / (2 × 5600) = 15 kHz
f_adc = TIM1时钟 / ARR       = 168e6 / 5600       = 30 kHz
```

传入 `30000` 的名字在 VESC 里叫 `f_zv`（零矢量采样频率），**等于 ADC 频率，是 PWM 的两倍**。逻辑分析仪上一个完整 PWM 周期约 66.6 µs，和注释一致。

死区 360 ns 插在上下管切换之间，防止直通。相对 66.7 µs 开关周期，约占 0.5%。

50% 占空比时 CCR = ARR/2 = 2800，波形以三角中心对称。SVPWM 改的是这三个 CCR，下一个 PWM 周期才真正出现在桥臂上（CCR 预装载 + COM）。

## 3. 电流采样时刻：为什么必须对准零矢量

本板 `HW_HAS_3_SHUNTS`：三个 **低边分流器**。电流只在 **下管导通** 时流过采样电阻。

中心对齐 PWM1（`CNT < CCR` 为有效、高侧开）时：

- **顶部**（CNT = ARR，随后向下计数）：三相高侧都关 → 三下管都开 → **V0**，三路分流器同时有电流。
- **底部**（CNT = 0，随后向上计数）：三相高侧都开 → 三下管都关 → **V7**，分流器上电流为 0，采到的是噪声/偏置。

所以 Hall FOC 路径直接丢掉向上计数那一拍：

```c
/* motor_it.c：TIM1 向下侧才是顶部零矢量 */
if ((TIM1->CR1 & TIM_CR1_DIR) == 0U) {
    return;   /* 向上计数 = 底部 V7，低边分流器没有窗口 */
}
```

非 Hall 路径用 `FOC_CONTROL_LOOP_FREQ_DIVIDER = 2` 隔一拍跑一次，效果也是每个 PWM 周期一次电流环，但不强制锁在下降沿。

触发链（VESC 基线，不要随手改）：

```text
TIM1 UEV（顶或底）
  → 复位 TIM2
  → TIM2 计 1 个 84 MHz 时钟（≈ 12 ns）
  → CC2 下降沿触发 ADC1
  → ADC2/ADC3 同步
  → DMA 把 15 路搬进 ADC_Value[]
  → DMA 中断进 Motor_DmaInt()
```

`MCPWM_FOC_CURRENT_SAMP_OFFSET = 2`，`TIMER_UPDATE_SAMP` 写成 `TIM2->CCR2 = samp/2 = 1`，是因为 TIM2 时钟是 TIM1 的一半。采样点几乎贴在三角波顶/底，躲开 MOS 开关边沿的振铃。

占空比很高时，V0 窗口变短。CCR 距 ARR 不足 `MOTOR_CURRENT_SHUNT_PICK_COUNTS`（900 计数，约 5.4 µs）时，`Motor_Current_ReconstructLongestZero()` 用 `Ia+Ib+Ic=0` 重构窗口最短的那一相。

## 4. ADC 模拟采样时间（357 ns）≠ 控制采样周期（33 µs）

ADC 时钟 42 MHz（APB2/2）。手册常用上限 36 MHz，本板按 VESC 超到 42 MHz，不作为「超了就改」的理由。

每个通道：

```text
采样保持  15 cycle  = 15 / 42e6 = 357 ns     ← 模拟「采样时间」
 successive 12 bit  = 12 cycle  = 286 ns
合计一档            = 27 cycle  = 643 ns
```

三重同步：ADC1/2/3 **同一序号同时**转。5 个序号串行：

```text
≈ 5 × 643 ns ≈ 3.2 µs   （远小于半个 PWM 的 33.3 µs）
```

一帧 15 路里，电流在 rank2（CH10/11/12）。换算在 `Motor_Sense_Update()`：原始计数 − 零偏 × 增益 → `ia/ib/ic`（A）。

这里的 357 ns 只保证运放输出被采稳；**控制上的「采样周期」永远是 ADC 触发间隔 33.3 µs，或电流环 `dt` 66.7 µs。**

## 5. 中断里谁快谁慢

`Motor_DmaInt()` 每 33.3 µs 都能进来，但不是每次都跑完整 FOC。

```text
DMA 30 kHz
 ├─ 检测占用：只采样，不跑 FOC
 ├─ BLDC 六步：保护每拍；BEMF/换相只用选定的半周期，dt = 2×ADC周期
 └─ FOC
      ├─ V/F：分频后才采样+改 PWM（回归快路径）
      └─ I/F / 电流环
           Hall：丢掉向上计数拍 → 15 kHz 采样+FOC
           其它：FOC_CONTROL_LOOP_FREQ_DIVIDER=2 → 15 kHz FOC
                采样换算 + 软件保护 仍可按分频后的拍执行
                Hall 角度再 ÷4 → 3.75 kHz
                速度环：foc pid 任务 1 kHz，ISR 只读上一拍 Iq
```

对应 `dt`：

```c
dt_adc = 1 / Hal_Motor_AdcSampleRateHz();          /* ≈ 33.3 µs */
dt_foc = dt_adc * FOC_CONTROL_LOOP_FREQ_DIVIDER;   /* ≈ 66.7 µs */
```

斜坡、电流 PI、观测器、I/F 积分角度 **必须用 `dt_foc`**。写成「每拍 +1」而不乘真实时间，改分频或改 PWM 频率后转速会整体错。

速度环在独立 `foc pid` 任务里跑，默认 `osDelayUntil(1 ms)`，`dt` 用 TIM5 实测。ISR 只在接管门槛处置 `SetRunAllowed`，电流环读上一拍 `iq_target`。

15 次电流环大约对应 1 次速度环。速度 PI 输出的是 **Iq 目标**，不是电压；电压仍由 15 kHz 电流环算。任务优先级 `PRI_SPEED` 高于 Shell，仍低于 DMA 中断。

## 6. 为什么电流环必须快、速度环必须慢

电机是两套时间尺度叠在一起：

```text
电气：L/R
  τ_e = L/R = 0.0008 H / 0.4 Ω = 2 ms
  电流能跟多快，受这个限制。电流环采样 66.7 µs，比 τ_e 快约 30 倍。

机械：J 很大，转速变慢
  速度环 1 ms 已经够用；再快只会放大测速量化噪声。
```

经验带宽（本板没有自动按此整定，默认 Kp/Ki 是手调值）：

```text
电流环带宽  ≲  fs_current / 10   ≈ 1.5 kHz
速度环带宽  ≲  电流环带宽 / 10    ≈ 150 Hz
速度环执行频率 1 kHz  >  2×带宽，合理
```

`Motor_Calc_FocCurrentKpKi(m, tc)` 用 `Kp = L/tc`、`Ki = R/tc`。`tc` 是电流环时间常数，**不是** PWM 周期。`tc` 太小（带宽太高）会把 ADC 噪声放大成 Iq 抖动。

Hall-PLL 带宽只有 **10 Hz**：霍尔每电周期只有 6 个边沿，不能当 15 kHz 编码器用。72 RPM 时边沿间隔约 69 ms，用 `Δθ/dt` 当速度会跳；所以速度环吃 PLL，不吃边沿周期。

编码器 1024 线 ×4 = 4096 计数/机械圈。72 RPM 时每个电流环拍平均只有 **0.33 个计数**，逐拍 `ΔN/Δt` 经常是 0 或 1。角够电流环用；转速同样要滤波/PLL，不能直接差分。

## 7. 电频率 vs 控制频率（用转速把数抠出来）

```text
f_e = RPM / 60 × pole_pairs
每拍电角 Δθ = 2π × f_e × dt_foc
```

| 机械 RPM | f_e    | 每拍 Δθ (15 kHz) | 每电周期 FOC 拍数 | 霍尔边沿间隔 |
| -------- | ------ | ------------------ | ----------------- | ------------ |
| 72       | 2.4 Hz | 0.058°            | 6250              | 69 ms        |
| 300      | 10 Hz  | 0.24°             | 1500              | 17 ms        |
| 1500     | 50 Hz  | 1.2°              | 300               | 3.3 ms       |
| 3000     | 100 Hz | 2.4°              | 150               | 1.7 ms       |

1500 RPM 时 Hall 插值已经有意义；72 RPM 时 60° 扇区相对电流环极粗，电角应钉在扇区中心（`MOTOR_HALL_INTERP_START_RPM = 150`）。

无感观测器看的是反电势 `ω_e × λ`。72 RPM、2 对极时 `ω_e = 15 rad/s`，`λ = 0.026 Wb`，反电势约 0.4 V，淹没在噪声里。所以低速必须 I/F 或 HFI，不是把观测器增益拧大。Ortega 积分见 [磁链观测器](./磁链观测器.md)。HFI 注入频率、扫角/跟踪分工见 [高频注入](./高频注入.md)。

## 8. ISR 时间预算

电流环 15 kHz → **每拍最多 66.7 µs**。超过就会首尾相接，Shell / PendSV 饿死，看起来像串口卡死。

```text
load% ≈ avg_runtime_us / 66.7 µs × 100
```

经验：`< 60%` 正常；`> 80%` 先减观测器/Hall 诊断，**不要降 PWM 频率迁就 CPU**（那会改开关损耗和采样窗）。分频已经是为这件事准备的：功率级仍 15 kHz，运算改为每周期一次。

Hall 路径还额外丢掉 V7 那半拍，避免 30 kHz 全跑采样+保护把 ISR 填满。

## 9. 一张时序：从开关到 Iq

```text
 t=0          三角波顶部 (V0，三下管开)
  │  ~12 ns   TIM2 CC2 触发 ADC
  │  ~3 µs    15 路转完，DMA 进 Motor_DmaInt
  │           Sense 换算 ia/ib/ic
  │           （Hall：确认 DIR=向下才继续）
  │           过流保护
  │           必要时重构最短窗口那一相
  │           Clarke / Park → Id Iq
  │           电流 PI → Vd Vq          ← 用 dt=66.7 µs
  │           每 1 ms：速度 PI → 新 Iq 目标
  │           反 Park + SVPWM → 新 CCR（影子寄存器）
  │
 t=33 µs      三角波底部 (V7) — ADC 仍触发，Hall FOC 直接 return
 t=66.7 µs    下一个顶部；COM/UEV 后新占空比才出现在桥臂
```

记住三句话：

1. **PWM 15 kHz** 决定 MOS 怎么开关、电流纹波多大。
2. **ADC 30 kHz** 是中心对齐带来的双边触发；低边分流器真正能用的是顶部那一次。
3. **电流环 15 kHz 在 ADC 中断，速度环 1 kHz 在 foc pid 任务**；PI 的 `dt` 必须等于「两次真正运算」之间的时间。

核对时看 `olstatus` 的 `FOC loop` 行，不要看 `ol_foc_freq` 的字面意思。
