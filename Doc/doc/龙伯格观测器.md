# 龙伯格观测器

> 更新日期：2026-09-20  
> 定位：讲清 FOC 无感里龙伯格（Luenberger）怎么用电流误差估反电势，以及它和 Ortega 磁链观测器差在哪。  
> 代码：`App/motor/observer/motor_luenberger.c`。对照：[磁链观测器](./磁链观测器.md)、[扩展卡尔曼滤波](./扩展卡尔曼滤波.md)、[滑模观测器](./滑模观测器.md)、[BEMF 原理](./BEMF原理.md)、[高频注入](./高频注入.md)。  
> **尚未接入 `Motor_Control_Step`，没有上板验收。** 当前实机无感仍走 `motor_sensorless` 里的 Ortega。不要把主机测试通过写成已经能无感闭环。

---

## 1. 一句话

电压方程里把反电势 `e` 当成状态。用电机模型积分出一套 **估算电流** `î`，拿它和实测 `i` 的差去修正 `ê`。`ê` 的方向就是电角度。这就是 **龙伯格反电势观测器**。

和 Ortega 磁链观测是两条路，不要混：

| | Ortega `motor_flux` | 龙伯格 `motor_luenberger` |
|--|---------------------|---------------------------|
| 积分什么 | 定子磁链 `ψs` | 电流 `î` 和反电势 `ê` |
| 校正靠什么 | `|ψr|` 相对额定磁链圆 | 电流误差 `i − î` |
| 输出 | `ψr`、atan2 角 | `ê`、atan2 角、粗略 `ωe` |
| 现在接没接主控制 | **没接** | **没接** |
| 默认 | 关 | 关 |

EKF 四状态同时估 `i、ωe、θe`，时变增益，见 [扩展卡尔曼滤波](./扩展卡尔曼滤波.md)。滑模把线性误差换成饱和函数，见 [滑模观测器](./滑模观测器.md)。四者都看 `ωe·ψf`，**零速都不可观**。

---

## 2. 电压方程

αβ 上：

```text
L · di/dt = v − R·i − e
eα ≈ −ωe · ψf · sin(θe)
eβ ≈  ωe · ψf · cos(θe)
```

Ortega 把 `dψs/dt = v − R i` 积起来再减 `L i`。  
龙伯格反过来：先假定一个 `ê`，按上式积分电流，看积分出来的 `î` 跟不上实测 `i`，就说明 `ê` 错了。

正转时：

```text
θe = atan2(−eα, eβ)
```

反转时 `e` 整个矢量反向，要用 `atan2(eα, −eβ)`。本模块用 `ê` 两拍之间的旋转方向判断符号。

---

## 3. 观测器方程

连续时间（每一轴一套，α/β 对称）：

```text
dî/dt = (v − R·î − ê) / L + l1 · (i − î)
dê/dt = ω̂ × ê − l2 · (i − î)
```

展开成 αβ：

```text
dêα/dt = −ω̂ · êβ − l2 · (iα − îα)
dêβ/dt =  ω̂ · êα − l2 · (iβ − îβ)
```

`l1` 是电流增益，单位 `1/s`。`l2` 是反电势增益，单位 `V/(A·s)`。

符号：`ê` 偏小 → 模型里电流涨得比真机快 → `i < î` → `(i−î)<0` → `−l2(i−î)` 把 `ê` 抬上去。

经典教材常把 `e` 当常数（`dê/dt = −l2(i−î)`）。反电势其实在以 `ωe` 旋转，高速会滞后。本实现用 **上一拍** 的 `ω̂` 去转 `ê`，减轻这件事。`ω̂` 不是 PLL，只是 `|ê|/ψf` 带符号。

未配置 `l1/l2` 时按二阶配置：

```text
s² + (R/L + l1) s + l2/L = 0
ωn = 2500 rad/s ≈ 400 Hz
ζ  = 0.707
l1 = 2ζωn − R/L
l2 = ωn² · L
```

400 Hz 夹在电频率（本机最高约 100 Hz）和电流环 15 kHz 之间。`l1·dt` 在 15 kHz 上约 0.2，欧拉积分还能用。不要把 `ωn` 开到接近电流环。

---

## 4. 一拍里代码做什么

`Motor_Luenberger_Step` 每 FOC 周期一次，状态由调用者持有。

```text
未 Seed：î = I，ê = 0，ω̂ = 0

ε = i − î
dî/dt = (v − R·î − ê)/L + l1·ε
dê/dt = ω̂×ê − l2·ε
î += dî·dt
ê += dê·dt

NaN/Inf → 整颗复位

|ê| = hypot(êα, êβ)
ω̂  = sign(ê_old × ê_new) · |ê| / ψf
θ   = atan2(∓êα, ±êβ) + phase_offset     // 符号看 ω̂
bemf_ok = |ê| > 0.5 V
```

Seed：

```text
î = I
ê = ωe · ψf · [−sin θ, cos θ]
```

`θ`、`ωe` 通常先用 I/F 的强制角和斜坡转速。只是初值，不代表已经对准。

电压必须是**上一拍真正下发**的 `vα/vβ`，配本拍新采样的 `iα/iβ`。

原始角和 `ω̂` 都会抖。电流环不要直接拿去 Park；平滑仍是 PLL 的事，本文件没有。

## 5. 和旁边几条路的边界

```text
motor_luenberger    电流误差 → ê 和原始电角
motor_smo           饱和残差 → ê
motor_flux          磁链圆约束 → ψr 和原始电角
        ↓
motor_sensorless    现在用的是 Ortega，不是龙伯格
        ↓ 低速
I/F / HFI
        ↓ 另一条硬件
六步 BEMF           悬空相 ADC，不是这套模型
```

龙伯格吃电流噪声更直接（校正项就是 `i−î`）。Ortega 吃电压偏置更直接（纯积分会漂，靠磁链圆拉回）。本仓库量产路径没有换成龙伯格，这两份文件都是学习用的并行算法。

---

## 6. 调用边界

纯算法，不读全局电机、不碰 HAL / RTOS / PWM。

| 函数 | 作用 |
|------|------|
| `Motor_Luenberger_Reset` | 清状态。停机、切模式、非法 dt 时调用 |
| `Motor_Luenberger_NormalizeConfig` | R≥0；L/ψf 低于下限则抬到下限；负增益置 0 |
| `Motor_Luenberger_Seed` | 用假设电角、电角速度和当前电流装初值 |
| `Motor_Luenberger_Step` | 一拍。`valid=true` 时才能读角 |
| `GetAngle` / `GetMagnitude` / `GetSpeedE` | 电角 (rad)、`|ê|` (V)、电角速度 (rad/s) |

| 字段 | 单位 | 含义 |
|------|------|------|
| `enabled` | — | 本拍是否积分；关掉会复位 |
| `resistance` | Ω | 定子电阻 |
| `inductance` | H | 定子电感，须能除 |
| `flux_linkage` | Wb | 额定 `ψf` |
| `current_gain` | 1/s | `l1`；≤0 时自动整定 |
| `bemf_gain` | V/(A·s) | `l2`；≤0 时自动整定 |
| `phase_offset` | rad | 加在 atan2 之后 |

`dt` 用电流环间隔，本板约 `1/15000 s`。  
`bemf_ok` 只说明 `|ê|` 不像噪声底，不说明可以闭环。反馈失效时不要拿这个角做堵转判断。

## 7. 本机数字

ATK-BL57H95D20E：`R=0.4 Ω`，`L=0.0008 H`，`ψf=0.02573 Wb`，2 对极。自动整定时：

```text
R/L = 500 rad/s
l1 ≈ 2×0.707×2500 − 500 ≈ 3035  1/s
l2 ≈ 2500² × 0.0008 ≈ 5000      V/(A·s)
```

72 RPM 时 `|e| = ωeλ ≈ 0.4 V`，低于 `bemf_ok` 的 0.5 V 门限。把 `l1/l2` 拧大，放大的是电流噪声。低速仍走 I/F 或 HFI。

## 8. 什么时候不能用 / 常见失败

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 零速/72 RPM 角乱转 | `e≈0` | I/F 或 HFI；观测器只许观察 |
| 高速角滞后 | 把 e 当常数、没用 ω̂ 旋转，或 `ωn` 太低 | 本实现已带旋转项；再加大带宽要看 `l1·dt` |
| `î` 发散 | L 填成 mH 当 H，或 `l1` 过大 | 先核对 0.0008 H |
| 正转对、反转差 180° | 用了单一 `atan2(−eα,eβ)` | 代码已按 ω̂ 符号切；Seed 时 ωe 符号要给对 |
| 一接 Park 就过流 | 原始角直接进电流环 | 先 PLL，再谈接管 |
| 和 Ortega 同时积两套 | 两套状态会抢角 | 主控制目前只用 `motor_sensorless` |
| 主机测试通过就上板 | 测试是理想 v、i | 实机仍走 I/F |
