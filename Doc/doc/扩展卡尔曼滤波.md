# 扩展卡尔曼滤波（EKF）

> 更新日期：2026-09-20  
> 定位：讲清 FOC 无感里四状态 EKF 怎么同时估电流、电角速度和电角，以及它和 Ortega / 龙伯格差在哪。  
> 代码：`App/motor/observer/motor_ekf.c`。对照：[磁链观测器](./磁链观测器.md)、[龙伯格观测器](./龙伯格观测器.md)、[滑模观测器](./滑模观测器.md)、[BEMF 原理](./BEMF原理.md)。  
> **尚未接入 `Motor_Control_Step`，没有上板验收。** 计算量明显大于另外两套观测器，不要默认丢进 15 kHz ISR。当前实机无感仍走 `motor_sensorless` 里的 Ortega。

---

## 1. 一句话

把电机当成非线性状态方程，每拍先按模型**预测**下一拍的电流和角度，再用实测电流算卡尔曼增益去**校正**。线性化用的是当前估计点的雅可比，所以叫 **扩展卡尔曼滤波（Extended Kalman Filter，EKF）**。

| | Ortega `motor_flux` | 龙伯格 `motor_luenberger` | EKF `motor_ekf` |
|--|---------------------|---------------------------|-----------------|
| 状态 | 定子磁链 `ψs` | `î`、`ê` | `iα, iβ, ωe, θe` |
| 校正 | 磁链圆 | 固定 `l1/l2` | 时变增益 `K`，由 `P、Q、R` 算 |
| 转速 | 无（要另接 PLL） | `|ê|/ψf` 带符号 | 状态里直接有 `ωe` |
| 反转 | atan2 磁链 | atan2 要切 `ê` 符号 | `θ` 积分，不必切符号 |
| 现在接没接主控制 | **没接** | **没接** | **没接** |
| 计算量 | 小 | 小 | 每拍几次 4×4 |

三者都看 `ωe·ψf`，**零速都不可观**。都不是六步悬空相过零。

## 2. 状态和模型

```text
x = [ iα, iβ, ωe, θe ]ᵀ
u = [ vα, vβ ]ᵀ          // 上一拍命令电压
z = [ iα, iβ ]ᵀ          // 本拍采样电流
```

连续时间（表贴机、忽略机械方程）：

```text
L · diα/dt = vα − R·iα + ωe·ψf·sin(θe)
L · diβ/dt = vβ − R·iβ − ωe·ψf·cos(θe)
dωe/dt     = 0
dθe/dt     = ωe
```

反电势 `e = ωe·ψf·[−sin θ, cos θ]` 已经写进电流方程，不再单独当状态。  
`dω/dt = 0` 表示把转速当缓变；加速时靠过程噪声 `Qω` 让滤波跟上。

欧拉离散：

```text
iα⁺ = iα + dt/L · (vα − R iα + ω ψf sinθ)
iβ⁺ = iβ + dt/L · (vβ − R iβ − ω ψf cosθ)
ω⁺  = ω
θ⁺  = θ + ω·dt
```

量测就是电流本身：`h(x) = [iα, iβ]`。

## 3. 一拍里代码做什么

`Motor_Ekf_Step` 每拍一次，状态由调用者持有。

```text
未 Seed：i=实测，ω=0，θ=0

在当前 x 算雅可比，F ≈ I + dt·∂f/∂x
按模型预测 x
P  ← F P Fᵀ + Q

S  = H P Hᵀ + R          // 这里就是 P 左上 2×2 加 r
K  = P Hᵀ S⁻¹
x  ← x + K (z − h(x))
P  ← (I−KH) P (I−KH)ᵀ + K R Kᵀ     // Joseph，减轻 P 变负
θ wrap 到 [−π, π)，|ω| 钳到 1500 rad/s
```

`H` 只挑前两个状态，所以 `HPHᵀ` 不用乘满 4×4。`S` 是 2×2，解析求逆；行列式过小就整颗复位，避免把脏角送进 Park。

Seed：

```text
x = [Iα, Iβ, ωe, θ]
P = diag(1e-4, 1e-4, 25, 0.02)
```

电流初值较确信，转速/角度留较大方差。`θ`、`ωe` 通常先用 I/F 强制角和斜坡转速。

电压必须是**上一拍真正下发**的 `vα/vβ`，配本拍新采样电流。

## 4. Q 和 R 是什么意思

| 量 | 默认 | 调大 | 调小 |
|----|------|------|------|
| `q_current` | `1e-3 A²` | 更不信电流模型 | 估电流更粘模型 |
| `q_speed` | `80 (rad/s)²` | 转速跟得快、更抖 | 转速平滑、加速慢 |
| `q_angle` | `1e-4 rad²` | 角更敢跳 | 角更跟 ω 积分 |
| `r_current` | `5e-4 A²` | 更不信采样、校正变弱 | 更信电流、噪声也放大 |

≤0 时 Step 套上面这组默认。本机 `R/L=500 rad/s`，电流环 15 kHz，这组数只在主机理想模型上核对过，**不是上板整定结果**。

Q 按**离散每拍**协方差加进 `P`，不是连续谱密度再乘 `dt`。换控制频率要重调，不要 15 kHz 的 Q 直接拿到 30 kHz 上。

## 5. 和旁边几条路的边界

```text
motor_ekf           四状态 EKF，同时出角和 ωe
motor_luenberger    固定增益，出 ê
motor_smo           饱和残差，出 ê
motor_flux          Ortega 磁链圆，出 ψr
        ↓
motor_sensorless    现在用的是 Ortega + PLL，不是 EKF
        ↓ 低速
I/F / HFI
```

EKF 把 PLL 的活也干了（`ω` 在状态里），但协方差和 4×4 乘法比 PLL 贵得多。本仓库 ISR 预算 66.7 µs，**还没有测过** EKF 最坏耗时。在测过之前，不要替换 `Motor_Sensorless_Update`。

零速不可观的原因和另外几套一样：`ω=0` 时电流方程里看不到 `θ`。把 `Qω` 拧大解决不了。

## 6. 调用边界

纯算法，不读全局电机、不碰 HAL / RTOS / PWM。

| 函数 | 作用 |
|------|------|
| `Motor_Ekf_Reset` | 清 x、P。停机、切模式、非法 dt 时调用 |
| `Motor_Ekf_NormalizeConfig` | R≥0；L/ψf 低于下限则抬到下限；负 Q/R 置 0 |
| `Motor_Ekf_Seed` | 用假设电角、电角速度和当前电流装初值 |
| `Motor_Ekf_Step` | 一拍预测+校正。`valid=true` 时才能读角 |
| `GetAngle` / `GetSpeedE` | 电角 (rad)、电角速度 (rad/s) |

| 字段 | 单位 | 含义 |
|------|------|------|
| `enabled` | — | 本拍是否运行；关掉会复位 |
| `resistance` | Ω | 定子电阻 |
| `inductance` | H | 定子电感 |
| `flux_linkage` | Wb | 额定 `ψf` |
| `q_current` / `q_speed` / `q_angle` | 见上 | 过程噪声 |
| `r_current` | A² | 量测噪声 |
| `phase_offset` | rad | 加在 θ 之后 |

`dt` 用电流环间隔，本板约 `1/15000 s`。  
`speed_ok` 只说明 `|ωe|>50 rad/s`（2 对极时大约 240 RPM），不说明可以闭环。反馈失效时不要拿这个角做堵转判断。

## 7. 什么时候不能用 / 常见失败

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 零速/72 RPM 角乱转 | `(ω,θ)` 不可观 | I/F 或 HFI；EKF 只许观察 |
| P 炸掉、角 NaN | `R` 太小或 `dt` 错，S 接近奇异 | 代码会复位；先核对 Ω/H/Wb 和 `dt` |
| 转速跟上但角差 180° | Seed 的 θ 在反向，或相序反了 | 先核 Clarke；不要只靠 `phase_offset` |
| 加速时 ω 明显落后 | `q_speed` 太小，模型当转速恒定 | 略增大 `q_speed`，不要先动 `r` |
| ISR 里 Shell 卡死 | 4×4 比 Ortega 贵，尚未测耗时 | **先不要接入电流环** |
| 和 Ortega 同时跑 | 两套角会打架 | 主控制目前只用 `motor_sensorless` |

过流软件阈值仍在。`olstop` 是 PWM 中点，不是关桥。
