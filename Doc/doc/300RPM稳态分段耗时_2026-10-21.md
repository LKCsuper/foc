# 300 RPM 稳态分段耗时

同一 PI 内联固件，外设、15 kHz、增益和保护不变；24 V、Iq=1 A、Id=0、限压4 V，速度 PI 关闭，无感观测开、接管关。每轮连续三次观测进入300±30 RPM后清零，约6.7秒采集，运行中先冻结再停机。期间不使用J-Link，保留五次单行安全查询。两轮最终均确认Enable=OFF、目标0、fault=0，恢复10 RPM/s斜坡。

## 实测

| 阶段 | 仅总分段 reset / us | 内部细分 detail / us |
| --- | ---: | ---: |
| 采样与保护 | 8.99 | 11.01 |
| 电流重构准备 | 1.27 | 1.18 |
| 控制编排整体 | 29.59 | 34.96 |
| 输出仲裁与提交 | 7.41 | 8.15 |
| 观测器（包含在控制内） | 9.09 | 9.02 |

detail中控制内部：配置规整2.68、启动0.74、拖转角度1.77、速度门控1.04、电流控制整段12.31 us。电流控制内部：Clarke/Park 1.88、目标1.82、双轴PI 0.55、矢量限幅0.92 us。采样内部：帧处理2.88、传感器反馈0.76、保护3.04 us。输出中的电压重建1.93 us。这些是嵌套测量，不得叠加为总耗时，段间差额也包含插桩/函数编排，不能直接断言全是浪费。

每256个完整拍采样一次，单段累计256次会自动清空再计入；detail最终137条、reset138条代表最后一个块，并非覆盖整轮的全部阶段样本。detail总分段比reset多约8.0 us，是采样拍上新增细分钩子等的影响，不能将detail总和当无插桩控制耗时。两轮全量full回调均值51.30/51.26 us，最大64/65 us；与上一轮split49.82 us不同，诊断模式不同，不能宣称固件变慢或收益已量出。

detail期间控制入口最大105 us、reset最大102 us。均无故障，但说明平均约66.7 us不保证每一拍间隔一致。速度PI关闭，任务入口最大1535/1601 us不是速度闭环更新结果。

## 判断

控制段约29.6 us最大，但观测器只约9.1 us，不能把全部负担归给观测器。双轴PI本身已不足1 us，不值得继续作为首要优化对象。下一步优先沿电流控制整段检查上下文/目标选择、诊断查询与状态搬运，尽量复用同拍数据；在没有区分调用开销前，不删保护、不改频率或增益。

## 停机逐项基准与首个小改动

进一步使用现有 `slcadence currentbench`，只计算独立实例、不输出PWM，每批4次短临界区隔离IRQ。真实电机保持停机，结束fault=0。日志 `Doc/verify/pi_currentbench_20261021.log`。此基准固定角度，可复用三角函数，不能直接替代旋转时的耗时。

轻载合成工况：空基准0.125 us，反馈变换0.676 us，目标1.129 us，RunPi整体1.762 us，Step整体5.563 us，手工链4.293 us，启用细分的Step 7.965 us；外层RunIf 9.516 us、同入口单独Step 6.215 us。强限幅合成工况RunPi 2.363 us、Step 6.164 us。说明编排、诊断检查和限幅状态都会影响总耗时，不应把差值全归给PI本体。

外层独立弱磁关闭调用约0.992～1.016 us（含基准入口开销，不能全算收益）。本轮仅在拖转的有效弱磁上限≤0时直接清零fw.id和ctx.id_fw，跳过多参数跨文件Motor_Fw_Step调用；仍每拍清零，避免弱磁运行中被关闭后遗留负Id。上限为正仍按原路径运行，且电流圆余量归零时也能及时退出。输出后last_vd/last_vq更新保持不变。

控制主机回归按原测试脚本的模型2通过，补测0/负上限/正上限/再次关闭与真实Motor_Fw_Step的一致性、遗留Id清零及上一拍电压更新。严格固件构建0错误0警告，Code=181288。尚未烧录本轮改动，不宣称已节省1 us或已解决高频预算。

## I/F 编排简化

用户要求简化后，在同一RunIf路径合并关节电流保持与直接电压保持的编码器失效出口，保留清目标/积分并返回SAFE。该函数内复用一次反馈源判断，非编码器路径不再计算编码器速度电压模式。对齐与拖转的电流控制调用合并成一个入口，弱磁准备仍按原阶段执行。FillCurrentCtx取消整块memset，所有八个成员均在每条路径明确赋值，只有默认id_fw单独初始化，不复用上一拍上下文。

主机测试以非零字节预填上下文，覆盖无对齐拖转、带对齐交接、定角电流爬升，控制回归通过；原有反馈失效、编码器电压/电流与关节路径用例一并通过。严格构建0错误0警告，Code=181272，比上一构建少16字节。未改外设、增益、频率或保护；未烧录，代码体积减少不等于已测得运行加速。
