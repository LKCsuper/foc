## PWM / 关断语义（代码契约）

| API | 行为 | 不等于 |
| --- | --- | --- |
| `Hal_Motor_PwmStart` | 使能已配置通道 | 零矢量 / 故障关断 |
| `Hal_Motor_PwmSetSafe` | 三相 period/2 并 Commit | 无电流、无转矩、已关桥 |
| `Hal_Motor_PwmStop` | BSP 关主/互补通道 | 万能故障安全（仍取决于门极极性与硬件 Break） |
| 控制层 `SAFE` | 走 SetSafe | 硬件紧急关断 |

故障锁存后：`Motor_Control_ArbitrateOutput` 强制 SAFE；`Motor_SetCommand` 停机走 SetSafe。硬关断通道需结合驱动器与板级电路，**待上板核对是否有独立 nFAULT/Break**。

## 偏移校准与保护

| 阶段 | 行为 |
| --- | --- |
| `DETECT_Offset` 置 `Motor_Detect_IsActive` | 任务编排 PWM / 逐相 `EnablePhase` |
| ISR | **采样 + `Motor_Protect_Run`**；不跑 FOC；故障则 `PwmStop` |
| 任务侧 | 轮询故障锁存，中止并返回 0，保持 fault |
| 堵转/失速 | `ol_enable=false` 时通常不触发；过流/欠压仍有效 |

旧行为：校准期 ISR 整段 return，软件保护被绕开——已改。硬件过流若存在仍应独立有效（待上板确认）。
