# Hall FOC 偶发 Id 毛刺：分型与解决办法

> 2026-09-19。BM75 / STM32F405RG，三电阻 INA240，Hall + I/F，CCR×1.35，弱磁 0 A。
> 目的是把「偶发 `|Id|>1 A`」从转速验收里拆开，按 VESC 的电流处理来改诊断和采样，而不是用弱磁或再加 CCR 去抹毛刺。
>
> 配套：[Hall FOC 提速调试经验](./Hall_FOC提速调试经验_2026-09-17.md) · [低速反馈对比](./低速反馈对比_VESC_SimpleFOC_ODrive.md) · [CCR / 母线 / 弱磁](./弱磁.md)

口头说的 **oldriver** 即 ODrive。本机 2 对极。

## 1. 先分清三种读数

| 看到的量 | 典型实机 | 是不是 Id 毛刺 | 说明 |
|----------|----------|----------------|------|
| `Ia+Ib+Ic` 峰值 1.4～1.6 A | 150～1800 都有 | **不是** | 三路几乎同向的共模。完整 Clarke 会丢掉相等共模，进不了 Id。50% PWM 堵转时 `sum_span` 约 2.2 A，说明这是 PWM 开启后的模拟包络，不是 Hall/SVM 算错。 |
| 单拍 `|Id−目标|≈1.04 A`，一万次里 1 次 | 150、1200 | **是（偶发）** | 把验证脚本当过流用时，会在 150 RPM 直接停掉升速。 |
| 数百分比的 `|Id|>1 A`，且 `Ia+Ib+Ic≈0` | 1800 曾 10.8%；2026-09-19 为 577/9274（6.2%） | **是（扇区相关差模）** | 例如 `Id=+1.7 A` 同时三相和 ≈0。那是角度/差模，不是共模。 |

2026-09-19 空载升速时，高级电源面板母线约 **0.22 A**（24 V × 0.22 A ≈ 5.3 W），母线只从 24.0 V 掉到 23.8～23.9 V。分流器上 1.5 A 级三相和比真实母线电流大一个数量级，不能当成电机在吃那么多电流。

不要把 Id 毛刺和「软件 `|Vd,Vq|` 贴顶」混为一谈。1500 转不动时也曾说成反电势到顶、要弱磁；后来用 CCR/ARR 重建 `PWM ideal`，发现 `svm_hqd` 实际平均电压大约只有请求的 1/3，Hall CCR×1.20/1.35 才到 1500/1800。2000 仍停在约 1815 RPM，是调制幅值问题，见提速文档，**不在本文用弱磁或加 CCR 处理**。

## 2. VESC / SimpleFOC / ODrive 怎么处理

三家量产路径都**不会**因为单拍 `|Id|>1 A` 或 `|Ia+Ib+Ic|>0.5 A` 停机。那是本仓库验证脚本自己加的诊断，比它们严一个数量级。

**VESC**（本仓库外设基线，应对齐这一套）

- `m_curr_unbalance = I0+I1+I2` 只当遥测，不跳闸。
- 高调制、某相低边窗口不够时（CCR 距 ARR 不足 `SHUNT_PICK_THR=900`），用另外两相重构：`I_bad = -(I_good1+I_good2)`，再 Clarke。
- 过流看 `|Id,Iq|` 幅值相对 `l_abs_current_max`（默认几十安），不是 `|Id|` 跟踪误差。
- Hall 低于约 500 ERPM（本机约 250 RPM）关掉插值，避免 60° 跳变打电流环。

**SimpleFOC**

- 三电阻时先减 `(Ia+Ib+Ic)/3` 再 Clarke。数学上等价于本仓库已有的完整 Clarke，**再减一次没有新信息**。
- 电流环用低通 + PI 限幅，没有三相和停机。

**ODrive**

- Clarke 用 `Iα=Ia`、`Iβ=(Ib−Ic)/√3`。相等共模会进 α 轴，三分流板上比 VESC 更差，不要学。
- `dc_calib` 是 PWM 中点开着平均；故障是限幅、时序、标定失败，不是 `|Id|>1 A`。
- Hall-PLL 管的是低速角度，不是电流共模。本机低速测速已经在用类似 PLL。

## 3. 本仓库落地的办法

按「诊断学 VESC、采样学 VESC、角度保持现有 Hall 规则」做，**未改 ADC/PWM/TIM/DMA，未加 CCR，未开弱磁**。

### 3.1 诊断：毛刺当遥测，幅值才停机

`Scripts/hall_verify_serial.py`：

- `|Ia+Ib+Ic|>0.5 A`、`|Id−目标|>1.0 A`、`olcurdiag` 的 `id_over`：**只告警**。
- 真正中止：定子电流幅值 `√(Id²+Iq²) > 2.5 A`（空载台架），或母线 `< 22 V`。
- 板上软件过流仍是相电流峰值 10 A、去抖 1 ms（`motor_protect.c`），与脚本门槛分开。

`olcurdiag` 继续按扇区累计 `sum_over` / `id_over`，便于看毛刺出在哪个 Hall 状态、前半还是后半；这些计数不再单独掐停升速。

2026-09-19 复测：150 RPM 仍有 **1/10250** 次 `|Id|` 刚过 1.04 A，脚本告警后继续，150～1800 转速通过。这就是偶发毛刺该有的处理。

### 3.2 采样：原始分流给保护，Clarke 前可重构

- 零偏改为 Hall FOC 同一沿（TIM1 下降 / 顶部零矢量）累加，避免任务里上沿+下沿混在一起。
- 过流判定看**重构前**的 `ia/ib/ic`。
- 之后调用 `Motor_Current_ReconstructLongestZero()`（`motor_current.c`，与 VESC `FOC_CURRENT_SAMPLE_MODE_LONGEST_ZERO` 相同门槛 900 计数）。`duty1/2/3` 是软件 A/B/C，与电流同相序；PWM 硬件 A-C-B 只在落 CCR 时交换。
- 完整 Clarke 已在 `clarke_transform()`：`Iα = 2/3 Ia − 1/3 Ib − 1/3 Ic`。不要再减三相均值。

当前 Hall CCR×1.35 时最大比较值大约 0.55～0.61 ARR，距 `ARR−900` 还远，**150～1800 这条重构基本不触发**。它是给以后更高占空比预留的，解释不了低速那 1 拍 Id。

### 3.3 角度：低速不插值，高速按邻扇区半宽

插值写死 ±30° 时，实机表 54°～65° 会在扇区边界偏几度，换算电流大约 0.05 A，**解释不了 1 A 级 Id**。现已按相邻表项实际半宽插值；低于 150 RPM 仍钉在扇区中心（与 VESC「低速关插值」同类）。

150 RPM 的偶发 Id 出现在插值关闭、扇区中心，所以不是插值公式造成的。

## 4. 不要用的办法

- 用 `|Id|>1 A` 或 `|Ia+Ib+Ic|>0.5 A` 当停机条件再去「追电流可信」。会把 150 RPM 的 1 拍噪声当成故障，挡在升速前面。
- 为了抹 Id 毛刺去加 CCR 或开负 Id。那是 1500→1800 的**调制**手段，和毛刺不是同一条链。
- 学 SimpleFOC 再减一次三相均值，或学 ODrive 的 `Iα=Ia`。
- 改 VESC 来源的 ADC/PWM/TIM/DMA 去「对齐采样沿」。最差一拍在 ISR 入口锁到 `cnt≈4739 / ARR=5600`，仍在顶部零矢量里（当时 CCR 最大约 2026），不是开关沿采偏。
- 把 PD2 `CURR_FILTER` 再拨来拨去。推挽输出高已经消除「脚浮空/固定低」的零点跳变；固定高并不能去掉剩余共模包络。

## 5. 还没解决的

- 1800 RPM 仍有数百分比的 `|Id|>1 A`，且历史上存在「Id 很大、三相和≈0」的差模样本。偶发门槛放开之后，这条还在，需要单独查 Hall 电角与差模采样，不能指望重构或共模减法消掉。
- 三相和 1.4 A 级共模包络还在。Clarke 会丢掉相等部分，不把它当过流即可；根因仍偏模拟（INA240 / GND / 滤波），无示波器前不改外设基线。
- 最长零矢量重构尚未在 CCR 接近 ARR 的工况上实机证明。
- 2000 RPM 停在约 1815，是 `PWM ideal` 仍约 6.2 V、软件请求已 13.7 V 的调制压缩，见提速文档。

## 6. 怎么看日志

```text
olsnap      Id, Iq、Iabc sum、Iadc raw/zero、Theta/CCR、PWM ideal
olcurdiag   分扇区 samples / sum_over / id_over / id_max，以及 worst 帧 adc/ccr/cnt/hall
```

判据：

1. `√(Id²+Iq²)` 是否远超空载应有的 Iq（脚本 2.5 A）。
2. `id_over` 是 1/万 还是数百分比；后者看 `phase` 前后半和 `hall=`。
3. `Iabc sum` 大而 Id 不大 → 共模，Clarke 丢掉即可。
4. 三相和≈0 而 `|Id|` 大 → 差模/角度，不要用共模办法去修。

验证入口：`Scripts/hall_verify_serial.py`（`--profile up --max-rpm …`）。烧录后若串口无回，优先 SWD 100 kHz 重烧，勿整片擦除以免清掉 Hall 表和零偏。
