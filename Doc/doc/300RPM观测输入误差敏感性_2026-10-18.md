# 300RPM观测输入误差敏感性

## 范围

基于已校验的512行CSV，仅做观测器输入误差预算与理想基波敏感性计算，不是完整FOC/电机/PLL仿真，也不是逐拍回放。缺少定子磁链内部矢量、初始状态和中间3拍数据，不能将插值生成的数据冒充实机输入。

复现：`python Scripts/fault_trace_sensitivity.py Doc/verify/fault_export_20261018_111253.csv`。原始计算输出`.build/host/fault_trace_sensitivity_20261018.json`。假设R=0.474Ω，电流比例0.080586076A/count，实际控制角电频约35Hz，窗口136.4ms。

## 电流偏置

完整Clarke为Iα=(2Ia−Ib−Ic)/3，Iβ=(Ib−Ic)/√3。

- ABC同时增加相同1计数时，αβ误差为0；这不表示原始相电流保护不受共模影响。
- 仅任一相增加1计数，αβ误差模长均为0.053724A，进入V−RI项的误差模长为0.025465V。
- 若完全忽略非线性磁链修正，这个恒定输入在136.4ms中积分量为3.473mWb。这是未修正积分漂移预算，不是预测真实磁链会增加3.473mWb；当前Ortega修正会改变结果，不能用它反推真实偏移计数。
- 实机数据对`常数+sin(theta)+cos(theta)`拟合，Iα/Iβ常数项约-0.03841/+0.01539A；软件电压输入常数项约+5.220/+1.011mV。组合V−RI常数项模长约24.26mV。电流与电压字段差一个控制处理时刻、窗口有限且有未记录拍，组合只能作为线索，不能视作独立测得的真实反电势直流偏置，更不能直接写回校准值。

## 电压比例与时间错配

记录中软件电压矢量模长RMS约0.955864V。对理想平衡基波，比例误差ε对应输入误差εV，积分后的基波磁链矢量误差量级为εV/ω。固定时间差τ对应电压矢量差2V|sin(ωτ/2)|。

| 假设 | 输入电压矢量误差量级 | 基波磁链矢量误差量级 |
| --- | --- | --- |
| 电压比例1% | 9.56mV | 0.0435mWb |
| 电压比例5% | 47.79mV | 0.2173mWb |
| 电压比例10% | 95.59mV | 0.4347mWb |
| 时间差33.33us | 7.01mV | 0.0319mWb |
| 时间差66.67us | 14.01mV | 0.0637mWb |
| 时间差266.67us | 56.05mV | 0.2549mWb |

266.67us是记录间隔的量级，不是已发现控制链错了4拍。上述是磁链矢量误差，不是磁链模长纹波，不能因10%比例误差的数值接近0.426mWb就认定比例错误10%。理想平衡情况下，统一比例与固定时移仍产生同频旋转矢量，叠加后模长可保持恒定；它们单独并不能说明现有一次/电周期模长纹波。实际不平衡、死区、采样窗口和模型误差仍可破坏此理想假设。

额外恒定电压偏置1/5/10mV，忽略非线性修正时在本窗口积分漂移量为0.1364/0.6820/1.3640mWb；同样不是当前观测器输出预测。

## 如何解释现有波形

现有磁链与PLL角差一次谐波幅值约0.4258mWb与0.1551rad，解释率88.1%/89.3%。静止坐标系固定矢量叠加旋转磁链会出现每电周期一次的模长/角度变化，因而各相不一致的电流偏置、静止电压误差或观测器磁链中心偏移是更有针对性的核查对象。

但本计算没有真实转子角和定子磁链内部矢量，无法确定是否真的存在固定磁链中心偏移，也无法给候选原因作严格因果排名。不能据此排除其他电机/逆变器谐波，也不能将低速误差直接等同3300RPM失步/过流根因。

下一步保持增益、保护和外设不变，离线核对各相电流偏移/增益与电压重建是否引入不一致项；必要时再设计独立测量。不能直接补常数、换ADC配置或继续升速。
