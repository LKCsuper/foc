# 滑模观测器（SMO）

> 更新日期：2026-09-20  
> 定位：讲清 FOC 无感里滑模（Sliding Mode Observer，SMO）怎么用饱和函数估反电势，以及它和龙伯格 / Ortega / EKF 差在哪。  
> 代码：`App/motor/observer/motor_smo.c`。对照：[磁链观测器](./磁链观测器.md)、[龙伯格观测器](./龙伯格观测器.md)、[扩展卡尔曼滤波](./扩展卡尔曼滤波.md)、[BEMF 原理](./BEMF原理.md)。  
> **尚未接入 `Motor_Control_Step`，没有上板验收。** 当前实机无感仍走 `motor_sensorless` 里的 Ortega。不要把主机测试通过写成已经能无感闭环。

---

## 1. 一句话

电压方程里反电势 `e` 当成未知扰动。用电机模型积分出估算电流 `î`，电流误差经过 **饱和函数** 变成滑模量 `z`，再拿 `z` 去修 `ê`。`ê` 的方向就是电角度。这就是 **滑模反电势观测器**。

和旁边几套都不要混：

| | Ortega `motor_flux` | 龙伯格 `motor_luenberger` | EKF `motor_ekf` | SMO `motor_smo` |
|--|---------------------|---------------------------|-----------------|-----------------|
| 状态 | 定子磁链 `ψs` | `î`、`ê` | `iα, iβ, ωe, θe` | `î`、`ê` |
| 校正 | 磁链圆 | 线性 `i−î` | 时变 `K` | 饱和 `z=k·sat(î−i)` |
| 转速 | 无（要另接 PLL） | `|ê|/ψf` 带符号 | 状态里直接有 `ωe` | `|ê|/ψf` 带符号 |
| 现在接没接主控制 | **没接** | **没接** | **没接** | **没接** |

四者都看 `ωe·ψf`，**零速都不可观**。都不是六步悬空相过零。SMO 可以看成「把龙伯格的线性误差换成有界饱和」；大误差时增益被掐住，小误差时和龙伯格差不多。

## 2. 电压方程

αβ 上：

```text
L · di/dt = v − R·i − e
eα ≈ −ωe · ψf · sin(θe)
eβ ≈  ωe · ψf · cos(θe)
```

教科书连续时间 SMO 常写成：

```text
L · dî/dt = v − R·î − z
z = k · sign(î − i)
ê = LPF(z)          // 进入滑动后 z 的平均值就是 e
```

`k` 必须大于 `|e|`，否则到不了滑模面。本机额定电频率 100 Hz 时 `|e|≈16 V`，连续时间里 `k=24 V` 够用。

**15 kHz 离散化不能照搬。** `L/dt ≈ 12 V`。若电流方程里再减一个满幅 `z`，`dt·k/L` 会大于 1，`î` 把误差放大，过不了几拍就炸。本实现因此改成：

```text
L · dî/dt = v − R·î − ê          // 等价反电势已经在模型里
z = k · sat(î − i)               // 只表示 ê 的残差，不是满 e
ê ← Rot(ω̂·dt) · ê + lpf · z     // 旋转减轻高速滞后，再掺一点残差
```

`s=0` 时 `z=0`，`ê` 只按上一拍 `ω̂` 转，Seed 进去的反电势不会被首拍清掉。  
`lpf` 默认 `0.002`，大约是龙伯格 `l2·dt/k`：残差 `z` 不能按「对满 e 做 0.1 低通」来取。

饱和函数不用 `sign()`，避免抖振：

```text
sat(s) = s / (|s| + ε)          // ε 默认 0.08 A
```

正转：

```text
θe = atan2(−eα, eβ)
```

反转时 `e` 整个矢量反向，要用 `atan2(eα, −eβ)`。本模块用 `ê` 两拍之间的旋转方向判断符号。

## 3. 一拍里代码做什么

`Motor_Smo_Step` 每 FOC 周期一次，状态由调用者持有。

```text
未 Seed：î = I，ê = 0，ω̂ = 0

s = î − i
z = k · s / (|s| + ε)
î += dt/L · (v − R·î − ê)
ê = Rot(ω̂·dt) · ê + lpf · z

NaN/Inf → 整颗复位

|ê| = hypot(êα, êβ)
ω̂  = sign(ê_old × ê_new) · |ê| / ψf
θ   = atan2(∓êα, ±êβ) + phase_offset     // 符号看 ω̂
bemf_ok = |ê| > 0.5 V
```

`Rot` 是二维旋转矩阵，不是欧拉 `ω×ê`。后者每拍把 `|ê|²` 乘上 `1+ω²dt²`，高速会把模长撑大，再经 `|e|/ψf` 正反馈。

Seed：

```text
î = I
ê = ωe · ψf · [−sin θ, cos θ]
z = 0
```

`θ`、`ωe` 通常先用 I/F 的强制角和斜坡转速。只是初值，不代表已经对准。

电压必须是**上一拍真正下发**的 `vα/vβ`，配本拍新采样的 `iα/iβ`。

原始角和 `ω̂` 都会抖。电流环不要直接拿去 Park；平滑仍是 PLL 的事，本文件没有。

## 4. 和旁边几条路的边界

```text
motor_smo           饱和残差 → ê 和原始电角
motor_luenberger    线性电流误差 → ê
motor_ekf           四状态，同时出角和 ωe
motor_flux          磁链圆约束 → ψr
        ↓
motor_sensorless    现在用的是 Ortega + PLL，不是 SMO
        ↓ 低速
I/F / HFI
        ↓ 另一条硬件
六步 BEMF           悬空相 ADC，不是这套模型
```

龙伯格吃小误差更线性、好整定。SMO 大误差时 `sat` 饱和，增益有界，理论上抗扰动更硬，但 `k、lpf、ε` 三个数耦在一起，离散步长一变就要重看 `dt·k/L`。EKF 把转速也估出来，计算量明显更大。本仓库量产路径没有换成 SMO。

## 5. 调用边界

纯算法，不读全局电机、不碰 HAL / RTOS / PWM。

| 函数 | 作用 |
|------|------|
| `Motor_Smo_Reset` | 清状态。停机、切模式、非法 dt 时调用 |
| `Motor_Smo_NormalizeConfig` | R≥0；L/ψf 低于下限则抬到下限；k 钳到 0～80 V |
| `Motor_Smo_Seed` | 用假设电角、电角速度和当前电流装初值 |
| `Motor_Smo_Step` | 一拍。`valid=true` 时才能读角 |
| `GetAngle` / `GetMagnitude` / `GetSpeedE` | 电角 (rad)、`|ê|` (V)、电角速度 (rad/s) |

| 字段 | 单位 | 含义 |
|------|------|------|
| `enabled` | — | 本拍是否积分；关掉会复位 |
| `resistance` | Ω | 定子电阻 |
| `inductance` | H | 定子电感，须能除 |
| `flux_linkage` | Wb | 额定 `ψf` |
| `slide_gain` | V | `k`；≤0 时用 24 V，只乘进 `ê` 校正 |
| `lpf` | — | `ê` 对 `z` 的每拍掺入；非法时用 0.002 |
| `sigmoid_eps` | A | 饱和边界 `ε`；≤0 时用 0.08 |
| `phase_offset` | rad | 加在 atan2 之后 |

`dt` 用电流环间隔，本板约 `1/15000 s`。  
`bemf_ok` 只说明 `|ê|` 不像噪声底，不说明可以闭环。反馈失效时不要拿这个角做堵转判断。

## 6. 本机数字

ATK-BL57H95D20E：`R=0.4 Ω`，`L=0.0008 H`，`ψf=0.02573 Wb`，2 对极。

```text
L / dt     ≈ 12 V           // 电流方程里能塞的电压步
|e| @100Hz ≈ 16 V
k 默认       24 V           // 只修 ê，不进 L dî/dt
lpf 默认     0.002          // Δê ≈ 0.05 V · sat(s) / 拍
ε 默认       0.08 A
```

72 RPM 时 `|e| = ωeλ ≈ 0.4 V`，低于 `bemf_ok` 的 0.5 V 门限。把 `k` 拧到超过 `L/dt` 再塞回电流方程，放大的是离散发散，不是观测带宽。低速仍走 I/F 或 HFI。

## 7. 什么时候不能用 / 常见失败

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 零速/72 RPM 角乱转 | `e≈0` | I/F 或 HFI；观测器只许观察 |
| `î` 几拍就炸 | 电流方程里减了满幅 `z`，`dt·k/L>1` | 本实现不把 `z` 放进电压差；不要改回去 |
| `|ê|` 慢慢涨、转速跟着飞 | 把 `lpf` 当成「对满 e 低通」取了 0.1 | `lpf` 保持 0.002 量级 |
| 高速角滞后 | 没用 `ω̂` 旋转，或只用欧拉 `ω×ê` | 本实现已用旋转矩阵 |
| 正转对、反转差 180° | 用了单一 `atan2(−eα,eβ)` | 代码已按 `ω̂` 符号切；Seed 时 ωe 符号要给对 |
| 一接 Park 就过流 | 原始角直接进电流环 | 先 PLL，再谈接管 |
| 和 Ortega 同时积两套 | 两套状态会抢角 | 主控制目前只用 `motor_sensorless` |
| 主机测试通过就上板 | 测试是理想 v、i | 实机仍走 I/F |

过流软件阈值仍在。`olstop` 是 PWM 中点，不是关桥。
