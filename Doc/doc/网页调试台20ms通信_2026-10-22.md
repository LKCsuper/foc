# 网页调试台 20 ms 通信

## 实现范围

本地页面 `Tools/motor-studio`，固件入口 `App/cmd/cmd_studio.c`，纯协议实现 `studio_protocol.c`。既有 plot 后台任务每 5 ms 调度通信，遥测名义周期 20 ms；不新建 FOC 中断通信路径，不改变 VESC 外设基线。

连接仅开启遥测并查询参数。控制分为会话建立、目标同步、显式启动；断线不会自动重启。周期目标限于 I/F 路径，禁止与位置、关节、BLDC、检测和霍尔校准混用。运行中反转及超限目标由固件拒绝。

## 线格式

CRC 为 CRC16/CCITT-FALSE，初值 FFFF，多项式 1021，测试向量 `123456789` 为 29B1。

下行目标：`@C1,token,sequence,rpm,iq,id*HHHH` 后接 CR。CRC 覆盖 @ 至星号前的字节，token 为非零 uint32，sequence 为 uint32。浮点数必须有限，长度和分隔符严格检查；超长行整行丢弃。目标不经 Shell 回显、历史或提示符。

上行二进制包：`46 53 01 type length:u16 sequence:u16 payload crc:u16`。数字为小端，CRC 覆盖包头和 payload。整帧最多 96 字节，序号为 uint16。接收器支持任意分包、混合文本、校验失败后重同步。

| type | payload | 用途 |
| --- | --- | --- |
| 1 | 72 字节 | timeUs、token、已应用目标序号、flags、fault、控制结果，随后 12 个 float |
| 2 | 20 字节 | 周期毫秒、超时毫秒、token、参数数量、编译电机型号 |
| 3 | 8 字节 | 参数 id:u16、总数:u16、值:float |
| 4 | 8 字节 | 参数 id:u16、结果:i16、实际值:float；FFFF 表示通用确认 |

遥测 12 个 float 依次为目标 RPM、反馈 RPM、斜坡 RPM、Ia、Ib、Ic、Id、Iq、母线电压、电角度、Id 目标、Iq 目标。flags 位 0..5 为使能、速度环、故障锁存、速度反馈有效、会话有效、会话超时；8 位起为控制模式，16 位起为反馈来源。无有效反馈时网页不把反馈 RPM 当成真实转速。

参数 id 0..42 对应 `studio_fields.inc` 的配置顺序；43..62 为三组电流偏移、三组相电压偏移、三组滑行相电压偏移、8 个霍尔表值及编码器偏移/反向/已校准。校准数据只读，配置 id 5（ol_foc_freq）只读。逐字段回读不是原子快照。

## 命令与控制约束

`studio on/status/off/params` 管理遥测和查询；`studio control [token]` 建立租约，`studio start` 显式启动，`studio release` 释放并请求停机；`studio set id value` 停机修改单项配置，经类型检查及 Motor_SetConfig 校验后回报实际值，不写 Flash。

CRC、会话、序号和范围均通过的目标才续期并进入单槽邮箱，后台只应用最新目标。重复及迟到帧不续期；已超时的会话不能由旧帧复活。网页切到后台暂停下发；150 ms 无新遥测主动退出；固件 300 ms 无有效目标请求停机。任务调度可能增加实际停机延迟，该机制不替代硬件急停。

后台消费邮箱与命令修改期间短暂锁定调度，FOC 中断仍可抢占；周期 CRC 和发送在此调度锁外。低频命令使用非阻塞入队，不等待 UART。BSP 新接口仅在现有环形缓冲有完整帧空间时写入，短临界区保持原 IRQ 屏蔽状态，不改变 UART/DMA 配置。串口满时丢整帧，避免发送等待阻碍超时处理。
