# 编码器位置环

> 2026-09-30。C2208-100T，MT6701，16384 计数/圈（1 计数约 0.022°）。
> 靠近目标时不换控制律。位置比例始终给出转速，速度 PI 直接出电压，到达后积分留住保持电压。
>
> 命令用法也写在 [命令行使用手册](./命令行使用手册.md)。ODrive 低速测速对照见 [低速反馈对比](./低速反馈对比_VESC_SimpleFOC_ODrive.md)。

本文说的 ODrive 即口头的 oldriver。学的是它的串级，不是它的实验 anti-hunt，也没有改 `olspeed` 的速度 PI。

## 1. 靠近目标时要避开什么

C2208 的编码器速度是电压模式。原来的速度环里，只要目标转速不是 0，就会叠上起动前馈：

```text
Vq ≈ ±(0.167 V + 0.00667 V/RPM × |目标转速|) + 速度 PI
```

0.167 V 大约对应 KV120 的 20 RPM。位置误差只剩零点几度时，转速命令往往只有零点几 RPM，但这截起动电压仍是满的，轴会在目标两边来回踢。

曾试过在 4° 或 1° 以内改成与角度成比例的电压弹簧，又在约 0.06° 内把恢复电压清成 0。误差能收小，终点仍会震，或者停得比编码器分辨率粗。原因是过零时电压跟着误差改号，而低速阻尼又经常被转速死区切掉。

ODrive 靠近目标时不切换。位置环、速度环一直串在一起。误差接近 0 以后比例项接近 0，速度积分留着刚才用来抵消摩擦和齿槽的那一份力。

## 2. 本机每一拍

位置环在 foc pid 任务里先于原来的速度环运行（`Motor_Position_Run`，然后 `Motor_SpeedLoop_Run`）。使能、电机已 `olstart`、编码器无故障时：

```text
误差 (°)     = 目标 − 当前位置
速度命令     = 限制在 ±max 以内的（kp × 误差）
速度误差     = 速度命令 − 编码器 PLL 转速
比例电压     = 0.050 V/RPM × 速度误差
积分电压    += 0.20 V/(RPM·s) × 速度误差 × dt
Vq_pi        = 限制在 ±2.0 V 以内的（比例 + 积分）
```

输出顶满、而且速度误差还在把电压往外推时，这一拍不再往同方向累加积分。`dt` 不是正数或大于 0.05 s 时，这一拍只算比例、不积分。

随后：

- `position_hold_v` 写成上面的 `Vq_pi`。`pos` 打出来的 `vq` 就是它，**不含**抗齿槽。
- `ol_target_rpm` 写成 0。原来的速度 PI 被清掉，0.167 V 起动前馈不会因为“有一个很小的转速”再加进来。
- 抗齿槽表仍按当前机械角把电压加到 `Vq_pi` 上，再一起限到编码器电压上限 13.8 V，并乘上启动时的电流软比例。
- 位置环自己的速度 PI **不读** `spkp` / `spki`。那两个仍只给 `olspeed`。

当前位置来自编码器累计机械计数，相对 `pos zero` 或上电 `Motor_Position_Init` 时的零点。转速用同一套 ODrive 式 PLL；PLL 在近零把速度打成 0。速度无效时，这一拍把实测转速当 0。

默认数：

| 项 | 值 | 含义 |
| --- | --- | --- |
| `kp` | 3.333 RPM/° | ODrive 默认 `pos_gain = 20`（圈/秒）/圈 |
| `max` | 60 RPM | 速度命令限幅 |
| 速度比例 | 0.050 V/RPM | 接近原速度环 0.008 A/RPM × 5 V/A，阻尼略强 |
| 速度积分 | 0.20 V/(RPM·s) | 停住后留下的就是这份电压 |
| 电压限幅 | ±2.0 V | 位置环自己的限幅；外面还有 13.8 V 总限幅 |

0.22° 误差大约给出 0.7 RPM 的速度命令。误差和实测转速都到 0 以后，比例项为 0，积分不再变化。

## 3. 手拧时看到的过程

2026-09-30 在目标 0° 上用手把轴拧走，再连打 `pos`：

| 时刻 | 位置 | 误差 | 速度命令 | vq | 说明 |
| --- | --- | --- | --- | --- | --- |
| 拧之前 | 0.00° | 0 | 0 | −0.066 V | 已经停住，积分留着保持电压 |
| 拧开 | −43.81° | +43.81° | +60 RPM | +2.000 V | 速度和电压都顶满，往 0° 拉 |
| 拉回 | +0.22° | −0.22° | −0.7 RPM | −0.078 V | 过冲约 10 个计数 |
| 之后几拍 | 0.00° | 0 | 0 | −0.086 V | 积分冻在这里，不再变 |

`0.00°` 是打印到 0.01°。−0.086 V 是这次回到零点时积下来的保持电压，不是残差没消掉。抗齿槽电压不在这个数里。

## 4. 和 olspeed 的边界

`olspeed`、`olstop`、以及改变反馈源，都会关掉位置环。关掉或编码器故障时，积分和 `vq` 清零。

`olspeed` 仍走原来的速度 PI 和起动前馈，增益没有因位置环改过。位置保持时不要用 `olsnap` 的 Speed Iq 判断有没有力：速度 PI 被清掉以后这项接近 0，力在 `pos` 的 `vq` 里，再加上抗齿槽。

`pos zero` 只能在停机时做。编码器重锚（首拍、换向、采样变旧或周期非法）只重锚 PLL，累计机械计数保持不变，位置零点不会因此跳回 0。缺帧期间轴如果真的转过，这段位移仍然补不回来。

## 5. 用法

`pos` 只打开位置环，不上电。电机尚未运行时必须再 `olstart`；运行中更新目标不会重复提示。

```text
olstop
olmode 1
encoder detect
olfb encoder
pos zero
pos hold
olstart
pos
```

| 命令 | 作用 |
| --- | --- |
| `pos` / `pos status` | 打印使能、位置、目标、误差、速度命令、`vq`、kp、转速上限 |
| `pos zero` | 停机时把当前位置记为 0° |
| `pos hold` | 目标设成当前角度并使能 |
| `pos set <deg>` | 绝对目标（相对零点） |
| `pos move <deg>` | 在当前目标上加一段 |
| `pos on` / `pos off` | 只开关，不改目标 |
| `pos kp <rpm/deg>` | 位置比例，范围 (0, 100] |
| `pos max <rpm>` | 速度命令限幅，范围 [1, 1800] |

首次 `hold` / `set` / `move` / `on` 要求反馈源已经是编码器，并且电机停着。成功后模式设为 I/F、速度环开关打开、目标转速写成 0，串口会提示再 `olstart`。

终点如果又开始震，先把这路速度比例从 0.050 V/RPM 降低，不要先去动 `spkp`。那是 ODrive 的调法：速度比例加到刚开始震，再退到大约一半，然后才靠积分停住。本机这两个增益目前是 `motor_position.c` 里的编译期常量。
