# 磁链观测器

> 更新日期：2026-09-20  
> 定位：讲清 FOC 无感里「磁链」是什么、Ortega 观测器怎么从电压电流估电角，以及本仓库两处代码各自干什么。  
> 代码：`App/motor/observer/motor_flux.c`（纯算法）、`App/motor/observer/motor_sensorless.c`（同一 Ortega 公式 + PLL + 开环接管）。  
> 反电势物理见 [BEMF 原理](./BEMF原理.md)。低速为什么看不见见 [低速反馈对比](./低速反馈对比_VESC_SimpleFOC_ODrive.md)、[高频注入](./高频注入.md)。频率数字见 [采样时间与控制频率](./采样时间与控制频率.md)。  
> **`motor_flux` 尚未接入 `Motor_Control_Step`，没有上板验收。** 当前实机无感仍走 `motor_sensorless` 里内嵌的同一公式。不要把主机测试通过写成已经能无感闭环。

## 1. 一句话

三相都在 PWM 时，看不见悬空相反电势。用本拍电流和上一拍命令电压，按电机方程积分**定子磁链**，再减去 `L×I`，剩下的旋转矢量就是**转子磁链**。它的方向就是电角度。这就是 **磁链观测器**。

本仓库拆成两层，不要混成一件事：

| | 纯算法 `motor_flux` | 无感状态机 `motor_sensorless` |
|--|---------------------|------------------------------|
| 干什么 | Ortega 积分，输出 `ψr` 和原始 atan2 角 | 同一 Ortega + PLL + I/F 接管/失锁 |
| 含不含速度 | **不含。** 原始角很抖，不能直接当转速 | PLL 出电角速度和机械 RPM |
| 现在接没接主控制 | **没接**，只提供 Step | 已接，`slenable` 打开才跑 |
| 默认 | 关（没人调） | 关 |

它看的是 `ωe·ψf` 这一项，**不是**六步里测悬空相电压，也**不是**弱磁 `motor_fw`（那个是故意打负 Id 把气隙磁链削小）。

## 2. 电压方程：磁链从哪来

一相（再写到 αβ）的电压：

```text
v = R·i + dψs/dt
ψs = L·i + ψr
```

- `ψs`：定子磁链 (Wb)。绕组自己看到的总磁链。  
- `L·i`：电流在电感里的磁链。电流一变，这项就变。  
- `ψr`：转子永磁体磁链在定子上的投影。表贴机模长接近额定 `ψf`，方向跟着转子电角走：

```text
ψrα = ψf · cos(θe)
ψrβ = ψf · sin(θe)
θe  = atan2(ψrβ, ψrα)
```

反电势就是转子磁链的变化率：

```text
e = dψr/dt ≈ ωe · ψf · [-sin θe, cos θe]
```

所以「看反电势」和「看磁链方向」是同一件事的微分/积分两种写法。六步无感直接测 `e`；FOC 观测器积分 `ψs`。

把电压方程整理一下：

```text
dψs/dt = v − R·i
ψr     = ψs − L·i
```

输入是 `vα/vβ`、`iα/iβ`，输出是 `ψr` 的方向。三相都在 PWM，**不要**把某一相打成 FLOAT。

## 3. 为什么不能纯积分

理想情况下欧拉积分就够：

```text
ψs[k+1] = ψs[k] + (v − R·i) · dt
```

实际会漂。原因都不是「公式写错」：

1. **命令电压 ≠ 电机端电压**：死区、管压降、母线纹波都没补。观测器用的是上一拍反 Park 的 `vα/vβ`。  
2. **R、L、ψf 填错数量级**：`400 mΩ` 写成 `400 Ω`，积分立刻废。  
3. **偏置会积成斜坡**：电流零点差一点，`(v−Ri)` 就有直流，磁链直线涨。  
4. **静止时 `e = 0`**：积分器没有旋转信息，atan2 锁不住真角。72 RPM、2 对极时 `ωeλ ≈ 0.4 V`，淹没在开关噪声里。把增益拧大，放大的是噪声。

所以必须：低速先 I/F 或 HFI 把转子拖起来；积分器上加**幅值约束**，不让 `|ψr|` 无限涨。

## 4. Ortega 怎么改

本模块用的是 Ortega 非线性磁链观测器（VESC / ODrive 同一类）。在电压方程上加一项，把 `|ψr|` 往额定磁链圆上拉：

```text
e_mag = ψf² − |ψr|²
dψs/dt = v − R·i + (γ/2) · ψr · e_mag
```

`γ` 是 `observer_gain`。`e_mag < 0` 表示估算磁链太大，修正项沿 `−ψr` 方向把矢量缩短；`e_mag = 0` 时退回普通电压方程。

本实现和 `motor_sensorless` **同一条单边规则**：

```text
若 e_mag > 0（估小了）→ 把 e_mag 截成 0
```

低速 `|ψr|` 本来就会被噪声压小。若这时还往外推，等于拿噪声当「磁链不够」去撑圆，容易炸。偏大时才拉回来，用来抑制积分漂移。

`γ ≤ 0` 时按 `1000 / ψf²` 回退，避免除零。无感路径默认 `γ = 1.2×10⁷`，数量级必须和 `ψf²` 匹配：`ψf` 填成 mWb 当 Wb 用，增益会差 10⁶。

论文出处见 VESC 注释：*An adaptive flux observer for the permanent magnet synchronous motor*。本文件没有做那篇里的电阻自适应，R 当常数。

## 5. 一拍里代码做什么

`Motor_Flux_Step` 每 FOC 周期一次，状态由调用者持有。

```text
未 Seed：按 θ=0、当前 I 自动初值

ψr = x − L×I                         // 积分前的转子磁链
e_mag = ψf² − |ψr|²
若 e_mag > 0：e_mag = 0               // 单边

ẋ = v − R×I + (γ/2)·ψr·e_mag
x += ẋ · dt                          // 欧拉积分定子磁链

出现 NaN/Inf → 整颗复位，valid=false

ψr = x − L×I                         // 用新 x 再拆一次
|ψr| = hypot(ψrα, ψrβ)
θ    = atan2(ψrβ, ψrα) + phase_offset
flux_ok = 0.5 ψf < |ψr| < 1.5 ψf
```

Seed 不是「已经对准转子」，只是避免从全零开始第一次 atan2 乱跳：

```text
x = L×I + ψf · [cos θ, sin θ]
```

`θ` 通常先用 I/F 的 `ol_theta`。后面仍要靠 `v−Ri` 把方向收敛到真角。

电压必须是**上一拍真正下发**的 `vα/vβ`，和本拍新采样的 `iα/iβ` 配对。用本拍还没送出去的电压，等于拿未来的 v 配现在的 i。

原始 `atan2` 角每个控制拍都会抖。电流环若直接拿它做 Park，Iq 会跟着抖。平滑和估速是 PLL 的事，在 `motor_sensorless`，不在本文件。

## 6. 和旁边几条路的边界

```text
motor_flux          只估 ψr 和原始电角
        ↓ 以后若接入
motor_sensorless    PLL → 转速；LOCKING/CLOSED → 接管 Park
        ↓ 低速不够
I/F / HFI           强制角或凸极注入，不靠反电势
        ↓ 另一条硬件路径
六步 BEMF           悬空相端电压过零，不是 FOC
```

| | 输入 | 输出 | 零速 |
|--|------|------|------|
| `motor_flux` | `vαβ`（命令）、`iαβ` | `ψr`、atan2 角、`flux_ok` | 不可信 |
| `motor_luenberger` | 同上 | `ê`、atan2 角、粗略 `ωe` | 不可信 |
| `motor_ekf` | 同上 | `θe`、`ωe`、估电流 | 不可信 |
| `motor_smo` | 同上 | `ê`、atan2 角、粗略 `ωe` | 不可信 |
| `motor_sensorless` | 同上 + I/F 角/转速 | 控制角、机械 RPM、effects | 必须先 I/F |
| `motor_hfi` | `iαβ`、注入电压 | 跟踪角、`vd_inj` | 要凸极 |
| 六步 BEMF | 悬空相 ADC | 换相时刻 | 必须先开环拖 |

中高速反电势够大了，应停 HFI、用观测器。这条交接还没做。  
`motor_fw` 的负 Id 是弱磁，改的是气隙磁链大小，不是估角。

现在主控制仍然只调 `Motor_Sensorless_Update`。`motor_flux` 是把 Ortega 单独拆出来学习/测试用的；**没有**让无感改调它，避免两套积分器抢状态。

## 7. 调用边界

纯算法，不读全局电机、不碰 HAL / RTOS / PWM。

| 函数 | 作用 |
|------|------|
| `Motor_Flux_Reset` | 清积分器。停机、切模式、非法 dt 时调用 |
| `Motor_Flux_NormalizeConfig` | R/L 钳到 ≥0；`ψf` 低于 `1e-6 Wb` 抬到该下限；负增益置 0 |
| `Motor_Flux_Seed` | 用假设电角和当前电流装初值 |
| `Motor_Flux_Step` | 一拍。`valid=true` 时才能读角 |
| `Motor_Flux_GetAngle` / `GetMagnitude` | 读原始电角 (rad)、`|ψr|` (Wb) |

配置每拍传入，不进 Flash：

| 字段 | 单位 | 含义 |
|------|------|------|
| `enabled` | — | 本拍是否积分；关掉会复位 |
| `resistance` | Ω | 定子电阻 |
| `inductance` | H | 定子电感 |
| `flux_linkage` | Wb | 额定 `ψf` |
| `observer_gain` | 1/(Wb²·s) 量级 | Ortega `γ`；≤0 时回退 |
| `phase_offset` | rad | 加在 atan2 之后的固定补偿 |

`dt` 必须是**这一拍电流环**的间隔，本板约 `1/15000 s`，不要拿速度环周期去积。  
未使能、`dt≤0`、输入非有限：复位并返回 `false`，避免脏角进 Park。

接入时 Park 应用角应先经 PLL，不要直接用 `output.angle`。`flux_ok` 只说明模长像那么回事，不说明已经能闭环。反馈失效时不要把这个角当成有效零速去做堵转判断。

## 8. 参数单位与本机数字

当前调试电机 ATK-BL57H95D20E，铭牌换算见 `motor_nameplate.h`：

| 量 | 值 | 不要写成 |
|----|----|----------|
| 线电阻 | `0.4 Ω` | `400`（那是 mΩ） |
| 线电感 | `0.0008 H`（0.8 mH） | `800` 或 `0.8` 当 H |
| 磁链 | `0.02573 Wb`（25.73 mWb） | `9.1 mWb`（旧笔记）、`25.73` 当 Wb |
| 极对数 | 2 | 把磁极数 4 当极对数 |
| Ortega `γ`（无感默认） | `1.2×10⁷` | 跟着错误 `ψf` 自动放大 |

`ψf` 由线间 RMS `Ke` 换算：`λ = Ke / (128.25498 × 极对数)`。`6.6 V/kRPM`、2 对极 → `25.73 mWb`。

本板电流环 15 kHz。100 Hz 电频率（3000 RPM）时，每电周期约 150 拍，欧拉积分够用。72 RPM 只有 2.4 Hz，问题不在步长，在反电势太小。

旧调试说明 §16.3 里写过 `0.0091 Wb`。以铭牌和 `MOTOR_FIXED_FLUX_LINKAGE` 为准，不要把那个数抄进 `motor_flux`。

## 9. 什么时候不能用 / 常见失败

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 零速/72 RPM 角乱转 | `ωeλ ≈ 0.4 V`，没有可观信息 | I/F 或 HFI 起转；观测器只许观察 |
| 磁链模长飙到好几倍 | R 偏小、电压偏大、或 `γ` 配错 `ψf` | 先核对 Ω/H/Wb；看 `flux_ok` |
| 模长一直偏小、`flux_ok=0` | 单边修正不往外推；或 L 估大了 | 略微低估 L 通常更稳；不要靠加大 `γ` 硬撑 |
| 角差大约 180° | atan2 用反了 α/β，或相序反了 | 先核 Clarke 与相序，再动 `phase_offset` |
| 一接 Park 就过流 | 把原始 atan2 当控制角 | 先 PLL，再按 `motor_sensorless` 那套锁定/渐变 |
| 用本拍 PI 输出当 v | 和本拍电流对不齐 | 存上一拍反 Park 的 `vα/vβ` |
| 和六步 BEMF 对角度 | 一条积分模型，一条悬空相过零 | 不要对；硬件路径都不同 |
| 主机测试通过就上板无感 | 测试是理想 v、i 模型 | 实机仍走 I/F；接管用 `sltakeover` |

过流软件阈值仍在。`olstop` 是 PWM 中点，不是关桥。
