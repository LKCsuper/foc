# 300 RPM 无感观测开关调度对照

## 方法

同一已烧录固件、15 kHz FOC、ADC-DMA 中断开启、24 V 母线、I/F 300 RPM 指令、Iq 1 A、Id 0 A、4 V 限幅；速度 PI 与接管关闭。只通过现有 `slenable` 切换观测器，顺序为开、关、开，每次均停机切换并回读使能。未改固件、调度、增益或外设配置。

每组启动后等待 4.5 秒，做一次精简安全检查，然后 `slcadence task` 重置任务统计；八次精简查询，每次之前 drain 0.7 秒；最后停机并冻结，由 J-Link 两次一致只读导出。统计包括重置回复和末尾停机至冻结，实际窗口约 10.2～10.4 秒，不是严格等长的纯稳态窗口。

开启组检查观测转速跟随；关闭组观测值不再有测速意义，只检查目标指令、电流、故障和接管状态。没有编码器，无法证明三组实际机械转速和负载完全相同。采样保护及开环目标限速保持，低电流采样分辨率限制仍适用，本次不是电流精度验收。

代码核查：`slenable 0` 保留 I/F 电流控制和采样保护，且 `Sensorless_Update` 走复位早退路径，因此比较的是完整观测计算与复位早退，不是把整个观测函数调用彻底删除。

## 结果

| 条件 | 任务间隔数 | 最大完成间隔 | 超过 1100 µs | 比例 |
| --- | ---: | ---: | ---: | ---: |
| 开启，前 | 10443 | 1262 µs | 15 | 0.144% |
| 关闭 | 10244 | 1062 µs | 0 | 0% |
| 恢复开启 | 10437 | 1202 µs | 111 | 1.064% |

关闭时未出现超过 1.1 ms 的任务完成间隔，恢复后长尾再次出现。这支持无感计算增加高频控制路径负载、侵占任务运行机会的解释。开启组两次长尾比例不同，说明相位等因素仍影响分布；不能从两个峰值相减估算观测器耗时，也不能断言观测算法错误或它是所有延迟的唯一原因。

下一步优先检查观测器每拍配置、重复运算及可安全缓存项，保持控制频率和增益；每次优化后按此开关对照复测，不先改 RTOS 调度。

结束已确认停机、目标 0、fault 0、母线 24 V，并恢复 `slenable 1`。fault 0 不证明存在独立硬件过流保护。
