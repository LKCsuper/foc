# 软件电压限幅4.0→4.5V对照

## 条件

用户要求“升电压测试”，本轮明确为临时提高软件dq矢量限幅，不提高24V电源电压。COM号由COM15变为COM9（CH340）；先仅停机及查询，确认fault0、24.0V、4V原限幅、模型R0.474Ω/L0.112mH/磁链2.390mWb、观测器12M与PLL2000/30000。

不烧录、不修改外设/电流PI/PLL，Iq仍1A、Id0、100RPM/s，无编码器、无感不接管；未武装高频记录。按300→800→1200→1800→2100→2200→2300→2400，每档8次轮询及末尾一次olsnap。相较此前跨600RPM直接升2400，这次增加中间保持档位，因此不是完全单变量、同起始状态的严格A/B试验。

脚本新增显式`--voltage-limit`，本对照最高4.5V；修改前读取原值、修改后回读核对，异常收尾也在确认停机后恢复原电压及guard。未写Flash。每档电压到98%限幅或观测坍塌/故障/意外接管即中止。相关5项主机测试通过，覆盖默认不改、合法4/4.5V、拒绝超限/非有限值等。

## 实测结果

| 目标 | 档末dq请求模长 | PI窗口样本数 | clamp |
|---|---:|---:|---:|
| 1800RPM | 3.233V | 159491 | 0 |
| 2100RPM | 3.704V | 159506 | 0 |
| 2200RPM | 3.845V | 160045 | 0 |
| 2300RPM | 4.018V | 159706 | 0 |
| 2400RPM | 4.182V | 159731 | 0 |

各统计窗口由olsnap读出清零，包含爬坡及保持；clamp是现有q轴积分差阈值统计，不是完整硬件饱和计数。输出由快照积分及比例项重建，CCR估计结果接近，但二者都不代表端电压实测。

2400档8次观测2400.7、2396.7、2402.0、2401.1、2397.7、2394.6、2400.0、2403.9RPM；升档后至少2秒的最后7次均值2399.4RPM，范围2394.6～2403.9。未再出现此前2275→接近0的观测坍塌，全部轮询fault0/tk0，脚本正常结束。没有独立轴速，也没有本轮用户机械听感反馈，不称为真实轴速精度/接管验收。

2400时请求4.182V，比原4V上限高0.182V；距新4.5V限幅仅余0.318V。这是单次快照，不是全窗口最小裕量。不继续3000。

## 解释

这比仅看理论反电势更直接：本轮2300/2400稳定观察时确实需要超过原4V的软件请求，放宽到4.5V后通过了此前未完成的2400档。**强烈支持原4V限制是高速停转的重要因素。**

但前一轮没有2400异常瞬间的电压记录，本轮增加了中间档、且跨运行与重启，不能宣称排除开环功角、加速过程或参数误差等因素。无需为“证明”再次用4V冲到停转；目前不调PLL、不加电流或弱磁。

## 收尾

先确认OFF/目标0/fault0、速度环关闭、takeover BLOCKED，随后恢复原4.0V及800RPM开环上限；另一次只读查询复核恢复成功。电源仍24.0V，不升母线电压，不自动再启动。
