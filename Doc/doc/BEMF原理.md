# BEMF（反电动势）原理

> 更新日期：2026-09-14
> 定位：讲清反电势是什么、六步无感怎么用它、BM75 硬件为什么适合、以及它和 FOC 电流环里的「反电势」有何不同。
> 上板步骤见 [Examples/06_bldc_sensorless.md](../../Examples/06_bldc_sensorless.md)。IO 见 [BM75_IO定义.md](../sch/BM75_IO定义.md)。
> 2026-09-14 已在 BM75/HD75、约 24 V、空载条件下验证 8%～10% 占空比的受限积分闭环；这不代表更宽转速、带载和堵转已经验收。

---

## 1. 一句话

转子磁钢扫过定子绕组时，绕组里会感应出电压。这个电压叫 **BEMF（Back Electromotive Force，反电动势）**。

幅值跟转速成正比：

```text
e(t) ≈ ωe × ψf × f(θe)
```

- `ωe`：电角速度 (rad/s)
- `ψf`：永磁磁链 (Wb)
- `f(θe)`：波形形状。梯形电机接近平顶，正弦 PMSM 接近正弦

静止时 `ωe = 0`，BEMF 也是 0。所以任何「看反电势换相」的方法都不能从零速直接闭环，必须先开环把转子拖到足够转速。

本工程里 BEMF 出现在两条完全不同的路径：

| 路径                  | 怎么用 BEMF                               | 要不要把某一相悬空     |
| --------------------- | ----------------------------------------- | ---------------------- |
| 六步无感 BLDC         | 直接测悬空相端电压，判断何时换相          | 要。每步必须一相 FLOAT |
| FOC 电流环 / 磁链观测 | 用 `v − Ri` 积分磁链估角，见 [磁链观测器](./磁链观测器.md) | 不要。三相都在 PWM     |

下面先讲物理，再讲六步检测，最后对照 FOC。

## 2. 电压是怎么感应出来的

一相绕组的电压方程：

```text
v = R·i + L·di/dt + e
e = dψ/dt
```

`e` 就是反电势。永磁电机里磁链主要来自转子磁钢，所以：

```text
e_phase ≈ ωe · ψf · sin(θe + 相位)
```

铭牌常给 **线间 RMS 反电势常数** `Ke`（V/krpm，机械转速）。本仓库当前电机 ATK-BL57H95D20E：

- 4 个磁极 → 极对数 `pp = 2`
- `Ke ≈ 6.6 V/krpm`（线间 RMS）
- 对应相磁链约 `25.7 mWb`（换算见 [开环电流环调试说明](./开环电流环调试说明.md) §22.10）

数量级可以自己算：

```text
n_mech = 417 RPM 时          （60° 扇区 12 ms，pp=2）
E_line_rms ≈ 6.6 × 0.417 ≈ 2.8 V
相电压峰值 ≈ E_line_rms × √2 / √3 ≈ 2.3 V
```

同样电机在 100 RPM 只有约 0.66 V 线间 RMS。ADC 分压后再看，低速几乎淹没在开关噪声里。这就是「低速无感难」的物理原因，不是软件没写好那么简单。

FOC 里电流 PI 后面的 `ωe·ψf` 前馈，补偿的就是这项。I/F 开环角还没对齐转子时，不能叠这一项，否则会把 Iq 顶歪。那是电流环的事，六步检测不走那条公式。

## 3. 六步为什么能「看见」BEMF

传统 BLDC 每个 60° 电角度只导通两相，第三相上下管全关，称为 **悬空相（FLOAT）**。

```text
        Vbus
          │
     PWM相半桥 ── PWM（斩波）
          │
        电机绕组
          │
     LOW相半桥 ── 下管常开 → GND
          │
     悬空相半桥 ── 上下管都关
          │
          └── 这一相的端电压 ≈ 中性点 + 该相 BEMF
```

本工程正转六步表在 `motor_bldc_six_step.c`：

| step | A     | B     | C     | 悬空相 |
| ---- | ----- | ----- | ----- | ------ |
| 0    | PWM   | LOW   | FLOAT | C      |
| 1    | PWM   | FLOAT | LOW   | B      |
| 2    | FLOAT | PWM   | LOW   | A      |
| 3    | LOW   | PWM   | FLOAT | C      |
| 4    | LOW   | FLOAT | PWM   | B      |
| 5    | FLOAT | LOW   | PWM   | A      |

电流从 PWM 相流入、从 LOW 相流出，悬空相没有桥臂电流。转子继续转，悬空相绕组仍切割磁力线，端电压就跟着该相 BEMF 走。

理想化的单点过零算法常把一个扇区画成“先过零、再延迟 30° 换相”。但实际端电压还叠加 PWM 共模、续流二极管钳位和换相振铃，不能把 ADC 看到的每次翻转都解释成转子 BEMF 过零：

```text
         正确极性半波（用来换相）
                    ╭────────
                   /
    ──────────────●  过零（约扇区中点，再过 30° 该换相）
                 /
    ────────────╯
     示意图只描述理想转子电势，不等于 ADC 端电压原始波形
```

正弦电机没有平顶，过零仍然存在，只是边沿更圆、更易被 PWM 尖峰干扰。ATK-BL57 属于这一类，所以六步 BEMF **能用，但比专用梯形 BLDC 更挑采样时刻和阈值**。

### 3.1 软件中性点

绕组是 Y 接时，真正的中性点一般没有引出。导通两相、第三相悬空时，导通支路把 Y 点大致钳在母线一半：

```text
bemf = V_float − Vbus / 2
```

当前 8%～10% 低占空比路径与 VESC 的低占空比分支一致，使用
`(Va+Vb+Vc)/3` 作为软件中性点。VESC 只在已经换相且占空比较高时改用
`ADC_V_ZERO`；不能脱离占空比和采样状态把两种基准互换。

实现见 `Motor_BldcSensorless_UpdateBemf()`。

## 4. 过零检测和伏秒积分

换相真正需要的不是「过零这一瞬间」，而是 **过零后再过约 30° 电角度**。那时电流换到下一对绕组，转矩最大。

### 4.1 单点过零 + 30° 延迟

```text
看到过零 → 记下本扇区已经走了多久 t_zc
         → 再等大约 t_zc（假设过零在扇区中点）
         → 换相
```

优点：概念简单。缺点：一次 PWM 尖峰、一次续流振铃就能造出一个假过零。假过零会让下一周期突然缩短，转子跟不上，表现为剧烈抖动或长短步交替。

本仓库上板曾经见过：

- 六步过零计数很均衡，但电机仍抖
- 周期变成 `47 ms / 4 ms / 47 ms / 4 ms` 这种严格交替
- 闭环被假过零拉到开环都跟不上的 8 ms 以下

所以过零计数「有」不能证明相位对。要看 **六个 step 的换相周期是否接近**。

### 4.2 伏秒积分（当前主路径）

思路改成：不管单点是否过零，只累计 **正确极性且超过噪声带** 的 BEMF 面积。面积到了阈值再换相。

```text
每个扇区：
  1. 换相后先消隐（blanking），丢掉续流尖峰
  2. 把 BEMF 按该 step 的期望极性取符号
  3. 反极性区间只记「已经看到反向」，不积分
  4. 正极性且 |bemf| > 噪声带 时：
        integral += (bemf − noise) × dt
  5. integral ≥ 当前 step 的检测阈值，并且不违反相邻周期变化保护 → 换相
```

面积的单位是 `V·s`（伏秒）。它近似对应「正确极性半波还剩多少磁链要扫过」，对单个 ADC 毛刺不敏感。VESC 的 `COMM_MODE_INTEGRATE` 是同一类方法；本工程是独立实现，不复制其寄存器配置。

积分阈值不是万能常数。理想 BEMF 幅值随 `ωe` 增大，而固定电角度持续时间按 `1/ωe` 缩短，两者乘积在理想模型下接近磁链增量；但实机积分量还包含 PWM 采样窗口、二极管钳位、噪声带和滤波延迟，因此仍需针对电机和硬件标定。

当前自动模式使用 `0.004 V·s` 作为启动同步判据，并增加 VESC 式原始相电压有效性门控：
前半扇区只累计远离 `0/Vbus` 钳位区的悬空相样本，后半扇区允许积分以避免永久漏检。
状态中的 `phase_gate valid/late/blocked` 分别记录前半扇区有效放行、后半扇区放行和被屏蔽的样本数。

### 4.3 状态机

```text
IDLE → ALIGN（固定 step0 定向）
     → OPEN_LOOP（周期从慢到快斜坡）
     → CLOSED_LOOP（积分决定换相）
     → FAULT（超时 / 丢 BEMF / 非法样本）
```

`bldc open` 走 `OPEN_LOOP_FIXED`：同样采样、同样记 min/max，但 **换相时刻不听 BEMF**。用来回答「是功率六步不行，还是无感闭环不行」。

开环平稳、闭环抖 → 查极性、采样窗、阈值、周期限幅。
开环也抖 → 先查六步表、相序、桥臂波形，不要调 BEMF。

## 5. BM75 的采样链

无感 BLDC 的「传感器」不是一颗芯片，而是整条模拟链。BM75（工程里也叫 HD75）按 VESC 类功率板做了这条链，所以 **硬件适合做 BEMF 六步**，不必再加比较器。

```text
半桥中点 SHA/SHB/SHC
        │
   56 kΩ / 2.2 kΩ 分压
        │
   SENS_FILTER（PC13，约 100 nF）── BLDC 运行时断开
        │
   PA0/PA1/PA2 = SENS1/2/3
        │
   ADC 规则组，由 TIM2 在 PWM 导通窗触发
        │
   Motor_Sense 换成伏特
        │
   motor_it.c 把 FOC 的 ACB 运行量还原成原理图 ABC
        │
   Motor_BldcSensorless_Step()
```

| 环节         | BM75 事实                      | 对 BEMF 的影响                                                       |
| ------------ | ------------------------------ | -------------------------------------------------------------------- |
| 分压         | `(56k+2.2k)/2.2k ≈ 26.45`   | 24 V 母线约 0.91 V 进 ADC；低速 0.2 V 电机电压只有约 10 个 LSB       |
| 滤波电容     | `PC13` 控制三路模拟开关      | FOC 磁链识别要接通，减小开关纹波；六步过零要断开，避免 RC 把相位拖晚 |
| 三相电压通道 | `SENS1/2/3` 来自三个半桥中点 | 缺任何一相都做不了六步无感                                           |
| 电流通道     | 低边 0.5 mΩ + INA240          | 六步换相不靠电流过零；电流只用于保护                                 |
| PWM          | TIM1 CH1/2/3 互补，可 FLOAT    | 必须真的关断上下管，悬空相才能露出 BEMF                              |

BLDC 入口恢复原理图 ABC，是因为 FOC 内部对 TIM1 CH2/CH3 做了 B/C 对调（ACB）。把 FOC 的 `va/vb/vc` 直接喂给六步，B/C 悬空相会认错。见 `Motor_DmaInt_Bldc()`：

```text
phase_voltage[0] = motor.va;   /* SENS1，逻辑 A */
phase_voltage[1] = motor.vc;   /* 还原原理图 B */
phase_voltage[2] = motor.vb;   /* 还原原理图 C */
```

### 5.1 必须在 PWM 导通窗采样

悬空相端电压在一个 PWM 周期里并不干净：

```text
PWM 相高边导通：Y 点 ≈ Vbus/2，悬空相 ≈ Vbus/2 + e     ← 要这个
PWM 相关断续流：电流走二极管，端电压被钳到 0 或 Vbus     ← 不是 BEMF
换相瞬间：LC 振铃、死区、反向恢复                        ← 要消隐
```

5% 占空比时导通脉冲很窄。如果 ADC 仍用 FOC 的固定触发点，样本会落在关断续流区，看起来像幅值很小、极性乱跳的「假 BEMF」。

本工程 BLDC 运行时把 TIM2 触发点跟到 **导通脉冲中点**，并且只收 TIM1 **向上计数侧** 的那一帧（`Hal_Motor_BldcBemfSampleReady()`）。停机后恢复 FOC 固定采样点，避免污染电流环。

`bldc status` 里的 `adc_sample=TIM2:xxx (TIM1:yyy)` 就是当前触发位置。占空比变了，这个数应该跟着变。

因为丢掉了向下计数侧样本，状态机的 `dt` 取 `2 × ADC周期`，对应一个完整 PWM 周期。

## 6. 和 FOC 无感不是同一件事

```text
六步 BEMF                          FOC 观测器 / 电流环反电势
────────────                       ─────────────────────────
一相必须悬空                        三相都 PWM
直接测端电压                        用电流、电压、R/L/ψ 反推
输出是 60° 换相步                    输出是连续电角度
低速必须开环拖转                    低速可用 I/F、HFI，中高速用观测器
适合梯形 BLDC，正弦机凑合可用        适合正弦 PMSM（本机主路径）
```

同一块 BM75 两种都能做：三相电压给 BEMF 六步，三相电流给 FOC。

对 ATK-BL57 这种正弦电机：

- 学六步、验证功率桥和相电压链 → 用 BEMF
- 要平滑、带载、宽调速 → 仍应走 FOC（霍尔/编码器/观测器）

电流环里的 `Motor_Current_ApplySpeedFeedforward()` 补偿 `ωe·ψf`， mag 识别里的滑行采样也在测反电势。那些用的是 **三相都激励或都关断** 时的端电压，不是六步悬空相过零。

## 8. 读 `bldc status` 时看什么

| 字段                                   | 正常时                           | 常见异常含义                                                       |
| -------------------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `mode`                               | `OPEN_FIXED` / `CLOSED_LOOP` | 一直`OPEN_LOOP` 后 `STARTUP_TIMEOUT`：没到接管点或积分从未命中 |
| `bemf` / `min/step` / `max/step` | 各步都有正负半波，幅值随转速变大 | 某两步幅值接近 0：该相采样或映射错；六步同号：极性或中性点错       |
| `last_period/step`                   | 六个值接近                       | 奇偶严格长短交替：相位偏了一整个扇区，或期望边沿反了               |
| `integral`                           | 每次换相后清零并重新累计          | 长期为 0：采样窗、消隐或极性把正面积丢掉了                         |
| `timing` / `guard`                 | 自动模式显示 `AUTO_BEMF` 及绝对安全下限 | 显示 `MANUAL` 表示曾用 `bldc tune` 关闭自动检测                  |
| `phase_gate`                       | 三类计数持续增长                  | `blocked`增长表示前半扇区样本贴近母线轨，不能直接用于积分          |
| `adc_sample`                         | 随占空比移动                     | 卡在 FOC 的固定 250：导通窗跟随没生效                              |
| `commutations` vs `forced`         | 积分换相为主                     | `forced` 很多：阈值太大或 BEMF 幅值不够，在靠超时硬换            |

`fault=NONE` 只说明状态机没跳闸，不能单独当「转得顺」的证据。

## 9. 适不适合现在这块板

**适合。** BM75 有三相端电压分压、可关断的相电压滤波、可把半桥打成 FLOAT 的互补 PWM，这就是 BEMF 六步需要的全部模拟条件。

需要记住的边界：

1. **零速不可用。** 必须 ALIGN + 开环斜坡，BEMF 够大再闭环。
2. **低占空比窗口很窄。** 样本必须落在导通中点；否则看到的是续流，不是反电势。
3. **当前电机是正弦机。** 过零不如梯形电机干净，积分比单点过零更合适，仍可能要按相核对极性。
4. **分压偏高压母线。** 低速小 BEMF 量化粗，不要指望 5% 占空比下有教科书波形。
5. **滤波开关和 FOC 相反。** 六步断开 `SENS_FILTER`，FOC 磁链识别要接通。

固定开环能在某周期转稳，只能证明功率六步和该工作点同步得上；证明不了闭环相位正确。要把开环对照和积分闭环分开做，见 Example 06。

## 10. 从机械转速到六步周期

理解日志里的 `period=12 ms`，必须先区分机械角和电角：

```text
θe = 极对数 × θm
ωe = 极对数 × ωm
```

一次完整电角周期包含六个 60° 扇区，所以：

```text
电角周期 Te = 6 × Tsector
电气转速 eRPM = 60 / Te = 10 / Tsector(s)
机械转速 RPM = eRPM / 极对数
```

当前电机极对数为 2，`Tsector = 12 ms` 时：

```text
Te = 6 × 0.012 = 0.072 s
eRPM = 60 / 0.072 ≈ 833
机械 RPM ≈ 833 / 2 ≈ 417
```

这也解释了为什么“只把频率调对”只能让固定开环在某个空载点转起来：开环直接规定旋转磁场速度，却不知道转子是否真的跟上。负载、母线、电机参数或惯量改变后，同一个周期可能同步，也可能滑步。

## 11. 如何读懂本次实测波形

固定开环 12.5 ms 顺滑时，八段 BEMF 统计曾得到：

```text
step 0/2/4：约 -12 V
step 1/3/5：约 +4～6 V
```

进入受限闭环后，转子相位重新落在另一稳定关系，记录为：

```text
step 0/2/4：约 +4～6 V
step 1/3/5：前段约 -12 V，后段逐渐靠近 0 V
```

这些数值不是纯净的正弦反电势。浮空端仍会受到绕组电流续流、体二极管钳位、PWM 共模和 ADC 采样位置影响，因此可能贴近 `0 V` 或 `Vbus`；减去软件中性点 `(Va + Vb + Vc) / 3` 后会形成正负交替的差分信号。真正用于控制的是同一采样约定下可重复的**有符号面积**，不是把每个电压点直接当成转子磁链幅值。

最终受限闭环采用：

| step | 浮空相 | 实测原始符号 | 软件处理 | 积分输入 |
| ---- | ------ | ------------ | -------- | -------- |
| 0    | C      | 正           | 保持     | 正       |
| 1    | B      | 负           | 取反     | 正       |
| 2    | A      | 正           | 保持     | 正       |
| 3    | C      | 负           | 取反     | 正       |
| 4    | B      | 正           | 保持     | 正       |
| 5    | A      | 负           | 取反     | 正       |

也就是 `step0_rising=true`。这里的 `rising` 是历史配置名，实质是“step 0 是否保持当前 BEMF 符号”，不能只凭变量名猜硬件极性；最终必须由受控波形和每步换相计数验证。

## 12. 离散积分到底怎么算

连续形式：

```text
Φbemf(t) = ∫ max(s × ebemf(t) − Vnoise, 0) dt
```

- `s`：当前 step 的极性，取 `+1` 或 `-1`
- `Vnoise`：噪声带，小信号不积分
- `Φbemf`：本扇区累计伏秒值

MCU 每个有效 ADC 周期执行离散累加：

```text
signed = polarity(step) × (Vfloat − (Va + Vb + Vc)/3)

if signed > Vnoise:
    integral += (signed − Vnoise) × dt

if integral >= threshold and sector_time >= minimum_period:
    commutate()
```

举例：若有效有符号 BEMF 平均约 5 V，控制周期约 `66.7 μs`，单个样本贡献约：

```text
5 V × 66.7 μs ≈ 0.000333 V·s
```

因此较小阈值可能只需几个样本就达到。当前自动模式采用实测后的 `0.004 V·s`，并结合相电压有效性门控与周期下限。这一点非常重要：

- `integral_commutations` 全部增长，证明极性和积分路径正确；
- `forced=0`，证明每步都能在最长周期前找到有效面积；
- 六步都是 12 ms，只证明启动捕获工作点稳定；
- 闭环稳态应由逐步检测的积分阈值决定，`guard` 只是不允许算法跑到不安全的极短周期。

## 13. 本次问题是怎样一步步解决的

### 13.1 最初现象

- 启动时快速转动，随后跟不上、震动并停机；
- 后来能进入 `CLOSED_LOOP`，但声音和震动仍大；
- 单看 `mode=CLOSED_LOOP`、过零计数或均匀周期，一度会误判为成功。

### 13.2 建立不会说谎的对照组

使用固定开环分别测试周期，最终找到可重复的顺滑基线：

```text
bldc open 0.08 12.5 cw
```

这一步证明功率桥、基本六步表和电机在该同步速度下能够正常运行，把问题范围缩到 BEMF 闭环。

### 13.3 暴露并修掉的控制错误

| 问题                        | 日志表现                                                      | 修正                                             |
| --------------------------- | ------------------------------------------------------------- | ------------------------------------------------ |
| 单点过零容易被 PWM 波形欺骗 | 周期出现严格长短交替                                          | 主路径改为正确极性的伏秒积分                     |
| 早期用未门控的启动面积直接学习 | 阈值从 `0.0004` 被抬到约 `0.0159 V·s`，周期拖到 35～39 ms | 当时移除；现版本改为与闭环相同的有效样本门控，并按六步分别检测，仍需重新上板验证 |
| 保护换相写回周期估计        | 一次漏检后周期持续变慢                                        | 保护换相不再更新滤波周期                         |
| 最长周期要求先`armed`     | 真正漏检时反而等到 17～40 ms                                  | 最长预测周期无条件生效                           |
| 软件中性点策略与工作区不匹配 | 容易把 VESC 不同占空比区域的策略混用                          | 当前低占空比对齐 VESC，使用三相平均值；高占空比分支尚未启用 |

| 用负到正过零计数判断同步    | 与积分模式的控制量不一致                                      | 分析器不再把该计数作为同步结论                   |

### 13.4 决定性证据

错误极性时：

```text
integral commutation/step: 0,196,1,197,0,196
forced commutation/step:   196,0,196,0,196,0
```

这不是“阈值略有偏差”，而是严格的奇偶极性错误。改成偶数保持、奇数取反，并保留 12 ms 安全下限后，最终日志为：

```text
last period/step:          12,12,12,12,12,12 ms
integral commutation/step: 211,211,212,212,211,211
forced commutation/step:   0,0,0,0,0,0
commutations:              1268
```

用户同时确认机械运行“实际顺滑”。数据和机械观察一致，才构成当前阶段的闭环证据。

### 13.5 2026-09-14 的占空比—周期验证

相电压门控加入后，实测得到以下空载工作点：

| 占空比 | 最短扇区周期 | 方向 | 结果 |
| ------ | ------------ | ---- | ---- |
| 0.08   | 12.0 ms      | CW   | `forced=0`，六步均衡 |
| 0.09   | 11.5 ms      | CW   | `forced=0`，六步均衡 |
| 0.10   | 11.0 ms      | CW/CCW | `forced=0`，六步均衡 |

反例同样重要：`0.08 / 11 ms` 出现 198 次强制换相，主要集中在奇数 step；
`0.08 / 10 ms` 出现 146 次强制换相，其中 step 5 为 139 次。这证明周期不能脱离可用转矩固定压低。

这些工作点现在只用于选择启动及检测捕获周期：`0.08→12 ms`、`0.10→11 ms`，区间内线性插值，区间外不外推。启动同步后先等待实际占空比到达目标并稳定 12 个扇区，再在受限闭环中分别平均每个 step 的 12 次有效 BEMF 面积，以排除占空比斜坡与接管初期的暂态；不能取最小值，因为它会系统性降低阈值并造成持续提前换相。六步全部完成后，才把平均值作为各步独立的闭环积分阈值并解除捕获周期限制。稳态周期由 BEMF 自行形成，不再被占空比表锁定；周期预测每一步最多变化 1%，避免六步累计形成过大的瞬时加减速。`bldc tune` 会关闭自动检测，供人工诊断使用。

这项自动检测在 2026-09-14 的上板试验中未通过：0.09 占空比下，即使等待占空比稳定并对每步 12 次积分取平均，解除约束后奇数 step 的实际面积仍会下降约一半并触发 `BEMF_LOST`。因此默认配置已恢复 `AUTO_DUTY` 受限模式，自动检测代码仅保留为未启用试验，不能宣称完成。后续应实现 VESC 的延迟换向检测、转速估计以及随转速/母线变化的运行积分阈值，再重新上板验证。

### 13.6 VESC 自动检测实际做了什么

核对 `ThirtyLibrary/bldc/conf_general.c::conf_general_detect_motor_param` 与
`ThirtyLibrary/bldc/motor/mcpwm.c` 后，可以把 VESC 的流程概括为：

1. 先用临时积分参数启动电机，并在达到一定占空比后切换到 `COMM_MODE_DELAY`；
2. 延迟模式不是记住固定周期，而是在期望极性的 BEMF 正区累计时间，达到估算换向周期的一半后换相；
3. 延迟模式稳定运行后，平均 50 次完整周期积分，得到基础 `cycle_int_limit`；
4. 再降到低占空比运行，平均 100 次积分和转速，计算 BEMF 耦合系数；
5. 正常运行时不是使用一个永久固定阈值，而是计算近似关系：

```text
running_limit = base_limit + Vbus × coupling_k / max(abs(erpm), minimum_erpm)
```

随后再应用高速相位提前和最大阈值限制。VESC 超时后还可能跳过两个换相步，让下一组有转矩的桥臂组合帮助重新拉住转子。

因此本项目下一阶段的正确实施顺序是：

1. 在默认关闭的独立模式中实现并验证 BEMF 延迟换向；
2. 从实际六步换向时间建立电角转速估计；
3. 只在延迟模式稳定时采集基础积分和耦合系数；
4. 加入动态运行阈值及上下限；
5. 最后才允许新算法替代 `AUTO_DUTY`，并分别验证 0.08、0.09、0.10、CW、CCW 和负载扰动。

在上述步骤完成前，`AUTO_DUTY` 是当前实测稳定基线，不能因为自动检测代码能够编译就改成默认策略。

### 13.7 换相前的被动过零诊断

为了在不改变稳定基线的前提下确认相序和过零位置，状态中新增了三相被动观测。每个换相扇区在消隐后，分别记录 A、B、C 相对软件虚拟中性点的最小绝对电压及其时刻。这些数据不参与积分门控、PWM 或换相决策。

当前六步表预期的悬空相为：

```text
step:           0  1  2  3  4  5
floating phase: C  B  A  C  B  A
```

采集分析会输出 `passive floating phase`、`floating zero-min phase` 和
`floating zero-min residual`。它们只是相端电压的被动诊断，不能单独当作真实转子过零相位。在电流未续流完成时，所谓悬空相会被 MOSFET 体二极管钳在低母线或高母线附近，此时 `floating-neutral` 并不是未受扰动的纯 BEMF。只有在相端脱离母线钳位后，才能把接近零点作为换相相位证据。

这项诊断特意不受现有积分有效性门控限制，否则被拦截的近零样本会消失，使诊断自己证明自己正确。

正反转实测都出现偶数 step 不过零、奇数 step 约在扇区 87% 接近零的固定奇偶差异；改用 `Vbus/2` 参考后偶数 step 残余反而由约 3.7 V 增大到约 5.6 V，因此不应用母线一半替代三相平均中性点。为继续核对中心对齐 PWM 的采样窗口，可在停机时使用 `bldc sample up|down` 选择已有 ADC 帧的计数半周期。该选择不修改 TIM1、TIM2、ADC 或 FOC 配置，默认仍为已验证可运行的 `up`。

`down` 侧自动启动实测中 BEMF 幅度只有约 0～1.45 V，`phase_gate valid=0`，214 个启动扇区均无效并触发 `STARTUP_TIMEOUT`。这说明下降计数侧位于不适合当前 BEMF 检测的开关窗口。因此自动闭环强制使用 `up`；`down` 仅保留给固定开环的被动诊断，不得用于自动接管。

`up` 侧的原始分量进一步证明了钳位现象：偶数 step 的悬空相约从 19 V 缓慢降到 18 V，奇数 step 则由约 0 V 上升到 14 V；三相平均中性点只是跟随变化，不是造成奇偶差异的根因。核对 VESC `set_next_comm_step()` 后，其 FLOAT 也是主输出强制无效且关闭互补输出，与当前 HD75 BLDC HAL 一致。因此这一波形不支持“FLOAT 桥臂误导通”的猜想，后续应像 VESC 一样在原始相电压脱离母线钳位后才累积有效 BEMF，并使用延迟模式建立换相周期，而不是强求六个 step 都出现理想 50% 单点过零。

### 13.8 仍未完成的部分

- 启动捕获表仅覆盖 8%～10%、约 24 V、当前电机和空载条件；
- 尚未完成不同母线、带载、堵转恢复和硬件 Break 验证；
- 没有编码器或转速计时，日志仍不能单独证明真实机械转速。

因此准确结论是：**当前硬件在 24 V、8%～10%、空载的已验证插值范围内实现了顺滑的 BEMF 积分六步闭环；尚不是全工况稳定版本。**
