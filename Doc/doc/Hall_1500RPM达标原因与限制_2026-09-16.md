# Hall FOC 达到 1500 RPM：原因、证据与限制

> 初次记录：2026-09-16；补测：2026-09-17。台架为 BM75 / STM32F405RG、24 V 可调电源、Hall 反馈、空载、`spiq 0.8`，弱磁默认关闭。用户已确认电源面板限流设为 3.0 A；运行时电源输入电流未记录。3.0 A 是电源直流限流值，不等同于定子 Id/Iq。

调试方法与踩坑总结见[Hall FOC 提速调试经验](./Hall_FOC提速调试经验_2026-09-17.md)。

## 结论

原来目标 1500 RPM 时停在约 1323 RPM，主要可解释为**旧调制把电流环请求电压压缩为较小的 PWM 占空比差**，使软件请求先到上限；不能仅凭软件显示的约 13.8 V 判断电机端已经用满 24 V 母线，也不能据此断定 1500 RPM 必须弱磁。只在 Hall + I/F 电流模式下把旧调制算出的三路逻辑 CCR 同比乘 1.2 后，保持弱磁 0 A，1500 RPM 已通过逐档实机验证。

另将 Hall 电流环固定为处理 TIM1 顶部零矢量后的向下计数侧 ADC/DMA 帧。这消除了原来控制拍可能落在向上或向下侧的不确定性；但**没有证据表明该调整已解决 Id/Iq 误差**。在固定采样侧之前，20% 调制试验已经通过 1500 RPM。

三组对照使用相同的 24 V 母线、Hall 反馈、速度 PI 参数、`spiq 0.8` 和弱磁 0 A。`olsnap` 的 `Vd,Vq out` 是根据 PI 积分项与瞬时误差还原的**软件输出请求**；`PWM ideal` 是用逻辑 A/B/C 的 CCR、ARR 和母线电压重建的**理想平均 αβ 幅值**。串口快照不是示波器测量，两个数也并非严格同一 PWM 瞬间，不能把 `PWM ideal` 当作端子实测电压。

## 为什么 20% 调制调整有效

现有 `svm_hqd` 先按电压请求计算扇区作用时间，再把三路 CCR 限制在旧公式所覆盖的部分 PWM 周期。按理想 PWM 占空比和本板 A/C/B 软件映射重建，原逻辑输出的 αβ 幅值约是输入请求的 **1/3**；150 RPM 与 1500 RPM 的串口估算都接近这一比例。于是电流 PI 的软件电压请求已到约 `Vbus/√3` 时，三相比较值之间仍有可用的差值空间。

初次试验保留原扇区、相序和 `svm_hqd`，仅在 [Hall 输出路径](../../App/motor/motor_it.c) 将三路逻辑 CCR 同比乘 1.2。理想差模幅值随之由请求的约 `1/3` 提到约 `0.4`；1500 RPM 复测的约 `5.2 / 13.0 ≈ 0.4` 与此一致。原 `svm_hqd` 的 CCR 最大不超过 `ARR/2`，乘 1.2 后不超过 `0.6 ARR`。这是一项小步试验结果，**不是完整线性 SVPWM 的验收**。

此前直接换成标准线性 SVPWM 的 150 RPM 试验只达到约 58 RPM，已撤回，见[失败记录](../verify/hall_verify_da452b0f-dirty_20260916-222044_150RPM.log)。这说明不能一次把旧调制比例改成理论满幅而不重新验证起转、电流环和采样；该次失败的具体根因尚未定位。

## 采样侧调整解释了什么

BM75 使用三相低边分流器。TIM1 顶部零矢量附近三路低边有共同导通窗口；顶部更新后 TIM1 向下计数。原 Hall 路径按 ADC 回调每两拍跑一次 FOC，诊断计数显示控制拍在不同运行时可能锁到 `up` 或 `down` 一侧。现仅对 Hall 电流环选择 `down` 帧，其他模式仍按原分频处理；ADC、PWM、TIM、DMA 和同步触发配置均未更改。代码及计数见 [Hall 控制入口](../../App/motor/motor_it.c) 和[采样方向日志](../verify/hall_verify_da452b0f-dirty_20260916-225440_1500RPM.log)。

选择更合适的采样窗口是合理的时序修正，但现有三次快照中 Id 仍为 `+0.294、−0.384、+0.711 A`（目标均为 0 A），Iq 也未始终跟随目标；三相电流和未稳定接近零。因此目前只能确认**采样侧确定、1500 RPM 可达**，不能断言电流采样已经准确，也不能把两项修改对转速的贡献混为一谈：1500 RPM 首次通过发生在固定采样侧之前。

## 当前边界与下一步

- 1500 RPM：空载 Hall 模式、弱磁关闭、三次快照 ±5% 验收通过；主机测试全通过，Keil 构建 0 错误、0 警告，J-Link 烧录校验通过，测试后 `olstop` 已确认。
- 2000/3000 RPM、弱磁、带载运行：截至 2026-09-16 尚未测试；2026-09-17 的补测结果见下节。
- 继续提速前应记录电源运行输入电流，并用示波器核对三相电流采样波形、零偏及 PWM 相位；再处理 Hall 扇区间的 Id/Iq 波动。
- 项目规则要求保持 VESC 来源的底层外设配置。若后续确需修改 ADC、PWM、TIM、DMA 或同步触发，须先核对锁定的 VESC 实现、MCU 时钟树、BM75 IO 与原理图，并说明影响后取得用户确认。
