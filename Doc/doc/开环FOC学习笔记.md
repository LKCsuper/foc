# 开环 FOC（电压模式）学习笔记

## 1. 什么是开环 FOC？

FOC（Field-Oriented Control，磁场定向控制）的核心思想：**把三相交流电机的控制，转化为类似直流电机的控制**。

```
┌──────────────────────────────────────────────────────────────┐
│                      闭环 FOC（正常）                         │
│                                                              │
│  电流传感器 ──→ Clarke ──→ Park ──→ PI控制 ──→ 逆Park ──→ SVPWM │
│                  ↑                  ↑           │            │
│                  │                  │           ↓            │
│              三相电流         角度(编码器)    三相PWM          │
│                                                              │
│  关键：角度来自真实传感器，PI 自动调节电压                      │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                      开环 FOC（当前）                         │
│                                                              │
│  虚拟角度 ──→ 逆Park ──→ SVPWM ──→ 三相PWM                    │
│     ↑                        ↑                              │
│     │                        │                              │
│  手动递增              固定Vd=0, Vq=手动设                      │
│                                                              │
│  关键：角度是"假的"，电压是手写的，没有反馈                      │
└──────────────────────────────────────────────────────────────┘
```

闭环有传感器反馈，PI 控制器自动算出该给多少电压。开环没有反馈——**你自己告诉电机"磁场朝这个方向、用这么大力"**，电机能不能跟上，全靠调参。

## 2. 数学原理（最简版）

### 2.1 坐标系变换

```
         B 相
          ↑
          │    / 转子磁场方向 (d轴)
          │   /
          │  /  θ = 电流角度
          │ /
          │/_____→ A 相
         /
        /
       ↓ C 相

    三相静止坐标(abc)          两相旋转坐标(dq)
    交流量，不好控制            直流量，好控制
```

FOC 的核心变换：

| 变换 | 作用 | 公式（简化） |
|------|------|-------------|
| **Clarke** | 三相(abc) → 两相静止(αβ) | `Iα = Ia`, `Iβ = (Ia + 2Ib)/√3` |
| **Park** | 两相静止(αβ) → 旋转(dq) | `Id = Iα·cosθ + Iβ·sinθ`, `Iq = -Iα·sinθ + Iβ·cosθ` |
| **逆Park** | 旋转(dq) → 两相静止(αβ) | `Vα = Vd·cosθ - Vq·sinθ`, `Vβ = Vd·sinθ + Vq·cosθ` |
| **SVPWM** | 两相静止(αβ) → 三相PWM占空比 | 空间矢量合成，不展开 |

### 2.2 d 轴和 q 轴的含义

```
        q轴 (转矩轴)
         ↑
         │   ○ 转子
         │  /
         │ /
         │/_____→ d轴 (励磁轴)
        /
       /
```

- **q 轴（交轴）**：产生转矩，**Vq 越大 = 电机越有力 = 电流越大**。电磁转矩 `Te = (3/2) * 极对数 * 磁链 * Iq`
- **d 轴（直轴）**：影响磁通，通常设为 0（永磁同步电机不需要额外励磁）

**开环时只设 Vq，Vd=0**。Vq 直接决定了电机转不转、有没有力。

### 2.3 开环的信号流（你的代码）

```
THETA_STEP          OPEN_LOOP_VQ
    │                     │
    ↓                     │
theta += THETA_STEP       │
    │                     │
    ↓                     ↓
┌──────────────────────────────────┐
│  inverse_park( Vd=0, Vq, θ )    │
│    → modAlpha, modBeta           │  逆Park：把dq电压转回αβ
└──────────────────────────────────┘
              │
              ↓
┌──────────────────────────────────┐
│  svm_hqd( Vα, Vβ, Vbus, ARR )   │
│    → duty1, duty2, duty3         │  SVPWM：αβ电压 → 三相PWM占空比
└──────────────────────────────────┘
              │
              ↓
┌──────────────────────────────────┐
│  TIMER_UPDATE_DUTY_M1(d1,d2,d3)  │  写入TIM1比较寄存器
│  TIM_GenerateEvent(COM)          │  立即更新PWM输出
└──────────────────────────────────┘
```

## 3. 两个参数的含义

### `THETA_STEP` — 控制转速

```
每一步中断（~66μs，15kHz），theta 加上这个值。
电频率 = THETA_STEP × FOC频率
        = 0.002 × 15000 = 30 rad/s ≈ 4.77 Hz

机械转速 = 电频率 / 极对数 × 60
         = 4.77 / 7 × 60 ≈ 41 RPM（假设 7 对极）
```

| THETA_STEP | 电频率 | 大致转速(7对极) | 效果 |
|------------|--------|----------------|------|
| 0.001 | 2.4 Hz | ~20 RPM | 很慢，可能卡顿 |
| 0.002 | 4.8 Hz | ~41 RPM | 慢速、平稳 |
| 0.005 | 12 Hz | ~103 RPM | 中速 |
| 0.01 | 24 Hz | ~205 RPM | 较快 |

### `OPEN_LOOP_VQ` — 控制电压/转矩

```
Vq 是送给电机的电压（伏特），除以母线电压 ≈ 调制深度百分比。
Vq=5V, Vbus=24V → 约 21% 调制 → 轻载够用
```

| Vq (24V母线) | 调制深度 | 效果 |
|-------------|---------|------|
| 2V | ~8% | 很弱，可能不转 |
| 5V | ~21% | 轻载能转 |
| 8V | ~33% | 中等转矩 |
| 12V | ~50% | 大力矩，注意电流 |

## 4. 调参口诀

```
         抖动增大
          ←——
    ┌──────────────┐
    │              │
    │   THETA_STEP │ 转速
    │              │
    └──────────────┘
          ——→
        卡顿/不转

    ┌──────────────┐
    │              │
    │  OPEN_LOOP_VQ│ 转矩
    │              │
    └──────────────┘
          ——→
      过流/重启
```

**核心矛盾**：

```
旋转磁场  vs  转子
(由theta控制)  (实际物理转动)

磁场转太快 → 转子跟不上 → 失步抖动
磁场转太慢 → 转子卡住不动
电压太小   → 转子没力 → 跟不上
电压太大   → 电流太大 → 过流保护
```

**调试四象限**：

|  | Vq 太小 | Vq 太大 |
|------|---------|------|
| **THETA 太小** | 完全不动 | 卡卡地动，发热 |
| **THETA 太大** | 高频尖叫不转 | 抖动剧烈 |

**调参优先级**：
1. 先把 Vq 设到能转（2→5→8 逐步加）
2. 再调 THETA_STEP 消抖（减小）
3. 微调两者到最佳配合

## 5. 代码关键细节

### 5.1 为什么 Vq 单位是伏特不是标幺？

```c
// inverse_park 只做旋转，不改变量纲：
*mod_alpha = -(mod_d * cosθ - mod_q * sinθ);  // 输入什么单位，输出就什么单位
*mod_beta  = -(mod_d * sinθ + mod_q * cosθ);

// svm_hqd 内部用 Vα/Udc 归一化：
X = ONE_BY_SQRT3 * Vbeta * Tpwm / Udc;  // Vbeta 除以 Udc
// 所以 Vα、Vβ 必须是伏特，和 Udc 同量纲
```

我第一次写成了 `Vq=0.3`，以为是标幺值，结果调制深度不到 2%——这就是电机不转的原因。

### 5.2 为什么加了 vBus 守卫？

```c
if (vBus < 1.0f) return;
```

`vBus` 由低通滤波计算，开机前几个周期值很小（甚至为 0）。`svm_hqd` 内部做 `Tpwm / Udc`，如果 Udc≈0，除法溢出，PWM 值会飞掉。

### 5.3 为什么要 COM 事件？

```c
TIMER_UPDATE_DUTY_M1(d1, d2, d3);   // 写入影子寄存器（不会立即生效）
TIM_GenerateEvent(TIM1, TIM_EventSource_COM);  // 强制 COM 事件 → 影子寄存器立即加载到活动寄存器
```

TIM1 配置了预装载（影子寄存器），写 CCR 值后要等到下一次定时器溢出才生效。COM 事件强制立即转移，否则 PWM 更新会延迟最多一个 PWM 周期。

## 6. 开环的局限性

开环只能验证硬件链路是否通（PWM、驱动芯片、MOS、电机绕线），不能实际带负载运行。原因：

1. **没有电流控制**：Vq 直接给电压，电流 = (Vq - 反电动势) / 绕组电阻。转速上来后反电动势增大，电流减小，转矩下降。
2. **会失步**：负载突变时转子跟不上旋转磁场，电流暴增但不出转矩。
3. **效率低**：Id 始终 0 只是近似，电机凸极效应下 Id≠0 才能效率最优（MTPA）。

下一步：加上电流传感器反馈，用 PI 控制 Iq = 设定值，这就是**电流闭环**——FOC 的核心。
