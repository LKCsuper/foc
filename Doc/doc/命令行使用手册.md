# 命令行使用手册

> 对应源码：`App/cmd/command.c` 命令表。
> 更新日期：2026-09-08。命令行为以代码为准；本文默认值来自 `MOTOR_Param_Init()`。

上电后通过调试串口操作电机：查状态、改参数、校准、起停。主控制路径是 `olstart` / `olspeed` / `olstop`，不要用 `duty` 当正式驱动。

## 1. 连接

| 项     | 当前工程                      |
| ------ | ----------------------------- |
| 串口   | UART4（`USART_NUM=4`）      |
| 引脚   | TX=PC10，RX=PC11              |
| 波特率 | **460800**，8N1，无流控 |
| 提示符 | `[T+秒.毫秒s] $ `，时间为上电以来的时基 |

上位机（串口助手 / MobaXterm / VOFA+）必须设成 460800。模块不支持时把 `DEBUG_USART_BAUD` 改回 `115200U` 并重新编译。

上电日志结束后会出现 `Type 'help' for command list` 和带时基的提示符，例如 `[T+1.234s] $ `。回车执行时再打一行 `[T+1.500s] > olstatus`，`olstatus` 页头也有同一格式的 `Uptime`。两张截图用 `T+` 相减就是间隔。没有 RTC，不是墙钟。若一直没有提示符：先核对波特率，再看偏移校准是否还在跑（首次约 5 s）。

## 2. 输入规则

- 一行一条命令，空格分隔，回车发送。
- `help` 列出全部命令（内部特殊处理，不在命令表里）。
- 多数命令**不带参数 = 查看当前值**；带参数 = 修改。
- 单行最多 159 字符；最多 8 段（命令名 + 7 个参数）。
- 退格可改当前行；无历史记录、无 Tab 补全。
- 未知命令：`unknown: xxx (try 'help')`。
- 部分停机字段（对齐 / HFI / 无感电机模型等）在电机运行时会拒绝，提示 `Stop motor before changing this config: olstop`。

## 3. 上电之后

1. `MOTOR_Param_Init` 加载 Flash 中的**校准**（电流/电压偏移、霍尔表）。控制增益仍用代码默认值。
2. `Detect_Init`：三相电流零点已在 1000～3000 ADC 计数内则**跳过检测**；否则校准约 5 s 并自动写入 Flash。
3. 运行命令默认禁用（`enable=OFF`）。`Hal_Motor_PwmStart` 只恢复 PWM 模式，**不等于已经起转**，也不等于桥臂已关断。
4. 需要转动时由 `olstart` 明确启动。

当前代码默认（调试用，不是任意电机通用）：

| 项                         | 默认                       |
| -------------------------- | -------------------------- |
| 模式                       | I/F 电流环（`olmode 1`） |
| 目标转速                   | 72 RPM                     |
| Iq                         | 0.6 A                      |
| 电流 PI                    | Kp=0.2，Ki=30              |
| 对齐 / HFI / 速度环 / 无感 | 均关闭                     |

## 4. 常用流程

先接好功率、能看到 `$ `，再用下面几条。参数按自己的电机改。

### 4.1 第一次确认板子活着

```text
olstatus
```

看 `Enable=OFF`、`Fault=... CLEAR`、母线电压合理、三相电流接近 0 A。

上板空载开环验证见 [开环稳定性验证](./开环稳定性验证.md)。可用 `python Scripts/ol_verify_serial.py`（默认 COM17）。只测 300 RPM：`--only V9`；列出项：`--list`。原文在 `Doc/verify/`。

### 4.2 I/F 开环拖转（推荐入门）

```text
olmode 1
oliq 0.6
olspeed 72
olstart
olstatus
olstop
```

- `olspeed` **只改目标，不会自己启动**。停机时会提示 `stopped, use olstart`。
- 目标为 0 时，`olstart` 用 `olmin`（默认 72 RPM）作为目标。
- 负转速为反转：先 `olstop`，再 `olspeed -72` 后 `olstart`。运行中直接改符号会被拒绝。

### 4.3 V/F 电压开环

```text
olstop
olmode 0
olboost 5
olspeed 72
olstart
olstop
```

低阻电机用 V/F 容易过流，优先 I/F。

### 4.4 重新做偏移 / 霍尔 / 相序

```text
olstop
detect offset          # 约 3 s，成功后自动存 Flash
detect hall            # 转一圈标定霍尔表；需另 saveparam
detect phase           # UVW 线序 vs 霍尔步进
saveparam              # 霍尔表等配置/校准；必须停机
```

`detect` 与 `detect offset` / `detect 1` 相同。Shell 的 offset **不含**未驱动相电压；上电 `Detect_Init` 在需要重测时会带未驱动相。

### 4.5 有感电流环（编码器或霍尔）

```text
olstop
olmode 1
encoder detect         # 无 Z 相：把当前位置标为电角 0
detect hall            # 霍尔路径：先标定表
olfb encoder           # 或 olfb hall
oliq 0.6
olstart
```

编码器未 `detect`、霍尔表未标定时，角无效，不要当闭环零速用。

### 4.6 有感速度环

```text
olfb hall              # 或 encoder，且角/速度有效
olstart
spenable 1
olspeed 300
spenable 0
olstop
```

`spenable 1` 要求：I/F 模式、无故障锁存，并且已有速度反馈（`slenable 1` 或 `olfb encoder|hall`）。

### 4.7 故障后恢复

```text
olfault                # 只查询，不清除
olfault clear          # 先停机再清锁存，不会自动再转
olstart                # 确认原因后再启动
```

### 4.8 VOFA+ 看波形

```text
plot create current    # ia ib ic v_bus，JustFloat，约 200 Hz
plot destory           # 也接受 destroy / stop
```

VOFA+：协议 JustFloat，波特率与调试串口相同。`plot` 占用 UART，期间不要同时刷 `olstatus`。

## 6. 命令说明

无特别说明时，省略参数即打印当前值。单位写在用法里。

### 6.1 运行与状态

| 命令         | 用法                                      | 说明                                                                         |
| ------------ | ----------------------------------------- | ---------------------------------------------------------------------------- |
| `olstatus` | 无参数                                    | 完整状态页。电机转着、FOC 负载高时可能卡住命令任务；运行中请用 `olsnap` |
| `olsnap`   | 无参数                                    | 短快照：Enable、转速、母线、Theta/CCR、故障、abc、Id/Iq、Vd/Vq 积分。打完后 Flush，300 RPM 下也应完整结束 |
| `speed`    | 无参数                                    | 与`olstatus` 相同                                                          |
| `olstart`  | 无参数                                    | `enable=true`。目标为 0 时改用 `olmin`                                   |
| `olstop`   | 无参数                                    | 停运行命令、中止霍尔标定。ISR 输出**中点占空比**（SAFE），不是硬件关桥 |
| `olspeed`  | `olspeed <rpm>`                         | 只改目标。运行中改方向须先 `olstop`                                        |
| `olmode`   | `olmode <0\|1>`                          | 建议先`olstop` 再切模式                                                    |
| `olfb`     | `olfb openloop\|sensorless\|encoder\|hall` | 也可用`0..3`。编码器要 `zero_valid`，霍尔要标定表                        |
| `olfault`  | `olfault` / `olfault clear`           | 无`clear` 只查询。清除前会停机                                             |

`olstatus` 里 `Enable=ON` 才表示运行命令已提交。`Fault ... LATCHED` 时不要起转，先查 `olfault`。

### 6.2 I/F 电流

| 命令         | 用法                 | 单位                                        |
| ------------ | -------------------- | ------------------------------------------- |
| `oliq`     | `oliq <amps>`      | A，转矩电流目标                             |
| `olid`     | `olid <amps>`      | A                                           |
| `olkp`     | `olkp <value>`     | 电流环 Kp                                   |
| `olki`     | `olki <value>`     | 电流环 Ki                                   |
| `olvlimit` | `olvlimit <volts>` | V，Vq 上限；运行时再受`Vbus/sqrt(3)` 限制 |

电流环增益允许在线改。Iq 过大易过流锁存。

### 6.3 V/F 与斜坡

| 命令        | 用法                | 单位                                                             |
| ----------- | ------------------- | ---------------------------------------------------------------- |
| `olboost` | `olboost <volts>` | V，启动补偿                                                      |
| `olkvf`   | `olkvf <V/Hz>`    | V/Hz                                                             |
| `olramp`  | `olramp <rpm/s>`  | 软启动斜率，越小越稳                                             |
| `olmax`   | `olmax <rpm>`     | 最大目标转速                                                     |
| `olmin`   | `olmin <rpm>`     | **仅**作 `olstart` 在目标为 0 时的默认目标，不是转速地板 |

### 6.4 对齐与 HFI

须停机修改。

```text
olalign <0|1> <Id_A> <time_s> [angle_rad]
hfistart <0|1> <voltage_V> <cycles> [min_confidence]
```

- `olalign`：I/F 启动里电流爬升之后的定角保持。`cycles` 对 HFI 为每轴周期数，范围 2～32；`min_confidence` 0～1。
- `olphase <rad>`：旧启动相位，**当前平滑启动不用**。

### 6.5 速度环

| 命令         | 用法               | 说明                       |
| ------------ | ------------------ | -------------------------- |
| `spenable` | `spenable <0\|1>` | 速度 PI。需 I/F + 速度反馈 |
| `spkp`     | `spkp <value>`   | A/RPM                      |
| `spki`     | `spki <value>`   | A/(RPM·s)                 |
| `spiq`     | `spiq <amps>`    | 速度环 Iq 上限             |
| `spbrake`  | `spbrake <0\|1>`  | 是否允许反向制动电流       |

无感未锁定时，有感无效则速度环会继续用 I/F 的 Iq，直到反馈有效。

### 6.6 无感

| 命令           | 用法                                          | 说明                                       |
| -------------- | --------------------------------------------- | ------------------------------------------ |
| `slenable`   | `slenable <0\|1>`                            | 关观测器时会同时关掉 takeover 和速度环     |
| `sltakeover` | `sltakeover <0\|1>`                          | 必须先`slenable 1`。授权观测器接管电角   |
| `slrpm`      | `slrpm <transition> <fallback>`             | 接管/回退转速 RPM                          |
| `slguard`    | `slguard <OLmax_rpm> <phase_rad> <blend_s>` | I/F 高速护栏、相位容差、混合时间           |
| `slmotor`    | `slmotor <R_ohm> <L_mH> <flux_mWb>`         | 注意 L、磁链的**输入单位**是 mH、mWb |
| `slobs`      | `slobs <gain> <pll_kp> <pll_ki>`            | 观测器与 PLL                               |
| `slphase`    | `slphase <rad>`                             | 固定电角补偿，单位**rad**（不是度）  |

I/F 目标超过 `sensorless_openloop_max_rpm` 且无感未完全接管时，会提示先停机再 `slenable 1` / `sltakeover 1` / `spenable 1`。`slguard` 把 OLmax 设为 0 会关掉该护栏。

### 6.7 校准与存储

| 命令          | 用法                            | 说明                                  |
| ------------- | ------------------------------- | ------------------------------------- |
| `detect`    | `detect [offset\|hall\|phase]`  | 也可用`1` / `2` / `3`           |
| `saveparam` | 无参数                          | 只存配置+校准（v2，216 字节 payload） |
| `encoder`   | `encoder [show\|reset\|detect]` | `reset` 清计数且清零点有效标志      |
| `show`      | 无参数                          | 霍尔组合值与三路 GPIO                 |

`saveparam` 拒绝条件：电机在跑、偏移校准占用、霍尔标定占用。

Flash **不保存**：enable、目标转速/电流、实时采样、PI 积分。重启后增益仍用代码默认；偏移和霍尔表从 Flash 恢复。偏移检测成功会自动保存；霍尔标定后仍要 `saveparam`。

### 6.8 无感 BLDC 六步

```text
bldc status
bldc start <duty 0..0.25> [cw|ccw]
bldc open <duty 0..0.25> <sector_ms 0.5..500> [cw|ccw]
bldc tune <integral_mV_s> <minimum_period_ms>
bldc stop
bldc exit
```

- `start` 依次执行定向、开环加速和 BEMF 伏秒积分闭环；FOC 必须已停止且不能有锁存故障。
- `open` 完成定向后按固定 60° 扇区周期强制换相；BEMF 只用于波形诊断，不改变换相时刻。
- `tune` 仅在停机时调整积分阈值和最短换相周期，参数不写入 Flash。
- `status` 中 `mode` 应依次出现 `ALIGN`、`OPEN_LOOP`、`CLOSED_LOOP`；`fault` 是六步无感故障，`motor_fault` 是公共电机保护故障。
- `stop` 关闭 PWM 并让三相进入悬空，同时继续占用控制出口；需要切回 FOC 时再执行 `bldc exit`。
- 当前参数是保守的首轮测试默认值，不写入 Flash。上板步骤见 `Examples/06_bldc_sensorless.md`。

### 6.9 系统与调试

| 命令         | 用法                | 说明                                  |
| ------------ | ------------------- | ------------------------------------- |
| `task`     | 无参数              | FreeRTOS 任务列表与 CPU 占用          |
| `reset`    | 无参数              | 软件复位 MCU                          |
| `openloop` | `openloop create` | 后台每秒打印状态，会抢 UART           |
| `plot`     | 见下                | VOFA+                                 |
| `duty`     | 见下                | 硬件探针，**会绕开 FOC 写 PWM** |

```text
plot create current|speed|pos|sine
plot destory

duty create|destory|set <0..100>|start|stop
```

`duty` 在故障锁存或 `ol_enable` 时拒绝。主路径请用 `olstart`/`olstop`。`destory` 是历史拼写，`plot` 同时接受 `destroy`/`stop`。

`plot` 通道：

| 模式    | 通道                                            |
| ------- | ----------------------------------------------- |
| current | ia, ib, ic, v_bus                               |
| speed   | 目标 RPM, 实测 RPM, 斜坡 RPM, 误差 RPM, Iq 给定 |
| pos     | 机械角, 电角, 开环角, Iq, Id                    |
| sine    | θ, sinθ, cosθ, Id, Iq                        |

## 7. 安全注意

- 先 `olstatus` 再 `olstart`。有锁存故障时 `olstart` 也不应作为排故手段。
- `olstop` 后桥臂仍可能输出中点 PWM；紧急关断看硬件 nFAULT / Break，不是这条命令。
- 校准（`detect offset` / `detect hall`）会占功率桥，期间不要同时 `olstart`。
- `duty`、`openloop create` 仅调试；实验结束 `duty stop` / 复位。
- 改对齐、HFI、无感 R/L/磁链前先 `olstop`。
- 无感 BLDC 首次测试必须使用低母线电压、限流电源和空载电机；先核对六步桥臂和悬空相，再尝试闭环。
