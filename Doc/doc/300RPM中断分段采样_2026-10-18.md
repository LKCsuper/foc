## 条件与获取

沿用已烧录固件、15 kHz FOC、24 V 母线、I/F 300 RPM、Iq 1 A、Id 0 A、4 V 限幅；速度 PI 与无感接管关闭，无感观测保留。未修改任务调度、增益和底层外设。

启动等待 4.5 秒并检查观测跟随后，执行已有 `slcadence lean detail`，每 256 个完整控制拍采一次分段耗时，关闭逐回调统计。八次精简安全查询后停机，再冻结统计；J-Link 不停核、只读提取 map 中现有三组分段数组。连续两次 240 字节读取完全一致，调度快照也两次读取一致。驱动脚本 `.build/matched_schedule.py --profile`，提取器 `.build/read_profile.py`。

## 限制与判断

- 每段达到 256 个样本会独立清零再累计，并非整个测试窗口累计。停机命令到冻结之间，外层段继续采停机路径、内层运行段不再更新，造成 110 与 86 的差异。外层均值混入停机，不能作为纯运行控制段均值，不能与运行内层均值直接相减。
- 分段为插桩后的墙钟时间，计时/记录调用也有开销。嵌套段互相包含；不可把所有均值或最大值相加，也不能据此给出未插桩的中断占用率。
- 1/256 采样不能保证捕获极端事件或所有相位；没有与任务最长延迟做同事件配对。
- 运行内层中，I/F 电流路径与无感观测都是显著耗时部分；双轴 PI 算式本身不是主要耗时。当前不能把全部延迟归因于无感观测。
- 下一项排除实验可比较无感观测开/关的相同开环工作点；关闭观测后不能继续依赖观测 RPM 作为起转/跟随证据，需重新定义安全检查，保留采样保护和低速限制。此次未执行该行为变更。
