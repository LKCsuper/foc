# HFI、磁链观测与弱磁联合仿真学习指南

> 适用范围：`Doc/matlab/hfi_flux_pmsm.slx` 及其 MATLAB 生成脚本  
> 学习目标：理解无位置传感器 PMSM 从零速 HFI 到高速磁链观测，再到弱磁超速的完整控制链。  
> 重要边界：本文记录的 `-12 A Id` 只用于离线仿真，不是真实电机的安全推荐值。

## 1. 为什么需要三段控制

无感 FOC 的核心问题是：电流必须按转子电角度做 Park 变换，但转子上没有编码器或霍尔传感器。

同一种观测方法很难覆盖零速到高速全范围：

| 区域 | 主要问题 | 本模型的解决方法 |
| --- | --- | --- |
| 零速/低速 | 反电动势太小，磁链观测器不可信 | HFI 高频注入 |
| 中高速 | HFI 带来噪声、损耗和转矩纹波 | Ortega 磁链观测器 |
| 基速以上 | 反电动势接近母线电压，`Iq` 环失去电压余量 | 负 `Id` 弱磁 |

因此整体流程是：

```text
零速对齐
   ↓
HFI 估算转子角
   ↓  转速超过切换门限
磁链观测器接管角度
   ↓  电压利用率过高
负 Id 弱磁
   ↓
24 V 母线下追踪 3000 RPM
```

该窗口名字保留了 `UVW`，但当前实际显示的是三相电流 `Ia/Ib/Ic`，不是三相电压。

深弱磁时三相电流幅值会显著增大。这并不代表转矩同比例增大，因为其中大部分是用来减磁的负 `Id`。

显示 PMSM 电磁转矩，单位为 N·m。成功波形在3000 RPM时稳态转矩约为0.0165 N·m，与模型的粘滞摩擦转矩一致：

```text
ωm = 3000 / 60 × 2π ≈ 314.16 rad/s
TB = B·ωm
   = 5.25×10⁻⁵ × 314.16
   ≈ 0.0165 N·m
```

这是一个很重要的交叉检查：转速稳定时，电磁转矩应与机械损耗平衡。

### 3.5 `Scope_Theta`

显示展开的电角度：

- Park 实际使用角；
- PMSM 真实转子电角；
- 磁链观测角。

由于是展开角，数值会持续增长。看大时间范围时三条线可能视觉上完全重合，但深弱磁下几度的误差已经会明显影响 `Iq`，因此不能只靠全局缩放判断角度精度。

## 4. 离散 PMSM 植物

植物位于 `sl_pmsm_discrete.m`，使用凸极 PMSM 的 dq 模型：

```text
vd = R·id + Ld·did/dt - ωe·Lq·iq
vq = R·iq + Lq·diq/dt + ωe·(Ld·id + ψm)
```

因此：

```text
did/dt = (vd - R·id + ωe·Lq·iq) / Ld
diq/dt = (vq - R·iq - ωe·(Ld·id + ψm)) / Lq
```

电磁转矩：

```text
Te = 1.5·p·[ψm·iq + (Ld-Lq)·id·iq]
```

机械方程：

```text
J·dωm/dt = Te - B·ωm - TL
```

当前模型没有额外负载转矩，所以 `TL=0`，稳态时主要对抗粘滞摩擦。

主要参数：

| 参数 | 数值 | 说明 |
| --- | ---: | --- |
| `R_PHASE` | 0.2 Ω | 每相电阻 |
| `Ld` | 0.5 mH | d轴电感 |
| `Lq` | 0.8 mH | q轴电感，`Lq>Ld` |
| `ψm` | 0.02573 Wb | 永磁体磁链 |
| `p` | 2 | 极对数 |
| `J` | 2.1×10⁻⁵ kg·m² | 转动惯量 |
| `B` | 5.25×10⁻⁵ N·m·s/rad | 粘滞摩擦系数 |

## 5. HFI 低速角度估算

### 5.1 物理基础

IPMSM 满足 `Ld ≠ Lq`。沿不同电角度方向注入同样的高频电压时，电流变化量不同：

```text
Δi ≈ Vh·Δt / L(θ)
```

控制器利用这个凸极响应反推转子 d 轴方向。因为它不依赖反电动势，所以可以在零速和极低速工作。

### 5.2 当前仿真配置

- 高频注入电压：2 V；
- 先进行0.2 s定角对齐；
- HFI 角用于低速 Park 变换；
- 磁链观测器在后台同时运行，为中速交接做准备。

### 5.3 HFI 的局限

- 对 `Ld≈Lq` 的表贴式 PMSM，凸极信号可能太弱；
- 注入会带来噪声、铜耗、转矩纹波和额外温升；
- 存在180°电角度方向歧义，实际控制器需要额外判别极性；
- 高速后应关闭或减小注入。

## 6. HFI 到磁链观测器的 VESC 式交接

### 6.1 ERPM 和机械 RPM

VESC 的无感门限常用 ERPM（电转速）：

```text
ERPM = 机械 RPM × 极对数
```

当前电机为2极对，因此：

```text
3000 ERPM = 1500 机械 RPM
```

模型使用3000 ERPM作为 HFI/磁链角切换基准，并加入±5%回差：

- 上升过程超过3150 ERPM且磁链观测有效时，切到磁链角；
- 下降过程低于2850 ERPM或磁链失效时，返回 HFI。

回差的作用是防止转速在门限附近时两种角度源反复跳变。

### 6.2 角度选择与注入关闭不是同一个门限

本模型对齐 VESC 的思路，将“用哪个角度”和“是否继续注入”分开：

- 角度源在3000 ERPM附近切换；
- HFI 注入的重新进入门限为 `1.5×`；
- HFI 注入的退出门限为 `1.8×`。

对当前2极对电机：

```text
注入完全退出 = 3000 × 1.8 ERPM
               = 5400 ERPM
               = 2700 机械 RPM
```

因此波形中大约在2700 RPM后，HFI高频注入才真正停止。

## 7. Ortega 磁链观测器

### 7.1 基本方程

定子磁链积分：

```text
dψs/dt = vs - R·is
```

转子磁链估算：

```text
ψr = ψs - L·is
```

转子电角度：

```text
θe = atan2(ψrβ, ψrα)
```

Ortega 观测器还利用磁链模长误差将积分状态拉回到合理的磁链圆附近，抑制纯电压积分的漂移。

### 7.2 为什么必须用每相参数

离散 PMSM 方程使用每相参数，因此观测器也必须使用每相电阻 `R_PHASE=0.2 Ω`。

如果误用线电阻 `R_LINE=0.4 Ω`，`R·i` 补偿会加倍。低电流时影响不明显，但在大负 `Id` 弱磁时会造成明显的角度偏差。

### 7.3 VESC 的凸极电感补偿

凸极 PMSM 没有唯一固定的标量电感。VESC 根据当前 `Id/Iq` 方向调整观测器使用的等效电感：

```text
Lavg  = (Ld + Lq) / 2
Ldiff = Lq - Ld

Lobs = Lavg - Ldiff/2
       + Ldiff·Iq²/(Id²+Iq²)
```

由此可得：

- `|Id|` 为主时，`Lobs → Ld`；
- `|Iq|` 为主时，`Lobs → Lq`。

这个补偿对深弱磁非常重要。如果一直用平均电感，大幅负 `Id` 会被错误投影成正 `Iq`，速度环会误以为转矩已经建立。

### 7.4 深弱磁相位补偿

即使加入凸极补偿，离散模型在满弱磁时仍存在约4°观测角超前。模型按弱磁深度渐进加入相位修正：

```text
ratio = |Id_fw| / Id_fw_max
θused = θflux - 4°·ratio
```

零弱磁时补偿为0°，因此不影响 HFI 交接；满弱磁时最大修正4°。这是当前仿真参数下的校正值，真实电机必须通过标定确定，不能直接照搬。

## 8. 为什么24 V下需要弱磁

SVPWM 线性区的 dq 电压矢量上限近似为：

```text
Vmax = Vbus/√3 × MAX_DUTY
     = 24/√3 × 0.95
     ≈ 13.16 V
```

不弱磁时，高速下的主要 q 轴电压是：

```text
Vq ≈ ωe·ψm
```

3000 RPM、2极对时：

```text
ωe = 3000/60 × 2π × 2
   ≈ 628.3 rad/s

ωe·ψm ≈ 628.3 × 0.02573
       ≈ 16.17 V
```

16.17 V已高于13.16 V的可用电压，所以只改速度 PI、增大 `Iq`或改观测器都不能解决问题。

弱磁通过负 `Id` 减小 q 轴有效磁链：

```text
ψeff = ψm + Ld·Id
```

因为 `Id<0`，所以 `ψeff<ψm`，反电动势下降，在相同24 V母线下可以继续提速。

## 9. 弱磁控制实现

### 9.1 VESC 的基本思路

VESC 中的典型参数包括：

- `foc_fw_current_max`：最大弱磁电流；
- `foc_fw_duty_start`：从多大占空比开始弱磁；
- `foc_fw_ramp_time`：弱磁电流斜坡时间；
- `foc_fw_backoff`：当 `Iq` 跟踪恶化时减少弱磁，为 q 轴留电压余量。

VESC默认的 `foc_fw_current_max` 可能为0，即默认不开启弱磁。必须在确认电机和逆变器能力后才设置。

### 9.2 本仿真的电压积分调节

为了在简化 PMSM 植物中稳定达到3000 RPM，本模型使用电压利用率积分器：

```text
mreq = sqrt(vd_req² + vq_req²) / Vmax
e = mreq - mtarget
Id_fw(k+1) = Id_fw(k) - Kfw·e·dt
```

重要：`vd_req/vq_req` 必须取矢量限幅之前的请求值。如果使用限幅后的电压，控制器只能看到固定的100%，无法知道真实饱和深度。

当前参数：

| 参数 | 数值 | 作用 |
| --- | ---: | --- |
| `FW_DUTY_START` | 0.80 | 超过80%电压利用率后允许弱磁 |
| `FW_VOLTAGE_TARGET` | 0.92 | 目标电压利用率 |
| `FW_VOLTAGE_GAIN` | 25 A/s | 电压误差积分增益 |
| `FW_CURRENT_MAX` | 12 A | 负 `Id` 上限 |
| `FW_CURRENT_BUDGET` | 12.5 A | `Id/Iq` 合成电流上限 |

### 9.3 电流圆限制

`Id` 和 `Iq` 不能分别无限增大，必须满足：

```text
Id² + Iq² ≤ Imax²
```

当速度环已经给出 `Iq_ref`时，弱磁可用的 d 轴空间为：

```text
|Id|max = sqrt(Imax² - Iq_ref²)
```

这可避免弱磁与转矩电流同时超过逆变器或电机电流能力。

## 10. 本次调试过程与故障特征

### 10.1 不弱磁：转速卡在2400 RPM左右

现象：

- 目标已经到3000 RPM；
- 实际转速稳定在2400 RPM左右；
- 继续增大速度 PI 没有根本改善。

原因：24 V下电压矢量已饱和，不是速度环增益太小。

### 10.2 线性映射弱磁：`Id`只到约-4.3 A

现象：

- 弱磁已经介入；
- `Id`只稳定在约-4.3 A；
- 转速仍停在2300～2400 RPM。

原因：负 `Id` 让电压利用率下降后，直接映射又立即减少弱磁，过早形成平衡。

处理：改用电压利用率积分调节。

### 10.3 弱磁积分后仍摆动：观测参数错误

现象：

- 示波器显示 `Iq≈1.2 A`；
- 但电磁转矩只有约0.01～0.02 N·m；
- 转速在2300～2700 RPM间周期摆动。

这三个现象不能同时由正确的 dq 电流解释。结合转矩方程可知：观测角有偏差，大幅负 `Id` 被投影成了假 `Iq`。

修正顺序：

1. 观测器电阻从线电阻改为每相电阻；
2. 按 VESC 公式加入 `Ld/Lq` 动态凸极补偿；
3. 按弱磁深度加0～4°相位修正；
4. 将弱磁积分增益从60 A/s降到25 A/s。

### 10.4 最终结果

- 目标转速：3000 RPM；
- 实际转速：稳定跟踪3000 RPM；
- 弱磁 `Id`：约-12 A；
- 稳态 `Iq`：约0.4～0.5 A；
- 稳态转矩：约0.0165 N·m；
- HFI→磁链观测交接后可稳定运行；
- 超过注入退出门限后，HFI高频注入关闭。

## 11. 参数调试顺序

不要一次同时调多个环路。建议按以下顺序：

1. **先确认电机参数与单位**  
   特别区分线电阻/每相电阻、线电感/每相电感、机械 RPM/ERPM。

2. **在不弱磁的中速区验证角度**  
   先以500～1000 RPM运行，确认观测角、真实角和转矩方向正确。

3. **验证 HFI/磁链交接**  
   在不进入深弱磁前，确认交接没有大角度跳变。

4. **再开启弱磁**  
   从小 `FW_CURRENT_MAX`、低增益开始，逐步增加。

5. **使用转矩方程检查假 Iq**  
   如果 `Iq` 看起来很大，但 `Te` 很小，优先检查角度和参数，而不是继续增大速度 PI。

6. **最后调速度 PI 和弱磁增益**  
   角度错误没有解决前，调 PI 只会掩盖问题。

- ERPM与机械 RPM的换算；

### 实验 E：故意改错电阻

将 `sl_flux.m` 中的 `R_PHASE` 暂时改为 `R_LINE`，对比深弱磁时：

- `Iq` 显示值；
- 实际转矩；
- 转速振荡；
- 角度误差。

这是理解“低电流时看起来正常，高电流时突然失效”的典型实验。

## 13. 仿真与真实 VESC/硬件的差异

本模型用于学习和算法验证，不等于完整 VESC 固件或真实逆变器。它尚未完整包含：

- MOSFET开关损耗和导通压降；
- 死区畸变及死区补偿；
- ADC噪声、偏置、量化和采样窗限制；
- 母线内阻与电压下降；
- 磁链、电感和电阻随温度/电流的非线性；
- 磁链观测器的完整失锁管理；
- VESC弱磁 `backoff`、输入电流限制、MOS温度限制和电机温度限制；
- 硬件过流、欠压、过压、超速和退磁风险保护。

尤其需要注意：当前仿真的额定电流为6.6 A，但最终弱磁 `Id` 约为-12 A。这个工况已超过额定电流，真实电机上可能带来：

- 显著铜耗和温升；
- 逆变器和电机过流；
- 磁钢不可逆退磁；
- 观测参数随温升漂移；
- 高速机械安全风险。

所以上板时必须从很小的弱磁电流开始，并同时完成过流、过温、母线电压、超速和观测失锁保护。

## 15. 学习总结

1. HFI解决的是低速“角度从哪里来”，不是高速电压不足。
2. 磁链观测器适合中高速，但对 `R/L/ψm`、单位和电压模型非常敏感。
3. HFI→磁链切换解决角度源问题，弱磁解决电压上限问题，两者不能混为一谈。
4. 弱磁本质是用大幅负 `Id` 换取高速电压余量，代价是更大电流、损耗、温升和退磁风险。
5. 深弱磁下，几度的角度误差就会把大负 `Id` 投影成假 `Iq`，因此必须联合检查 `Id/Iq`、转矩和转速，不能只看一条波形。
6. 仿真中“能达到3000 RPM”不等于真实电机“可以安全运行在3000 RPM”。
## 16. VESC式拆分控制模块

`hfi_flux_split_pmsm.slx` 将高速控制链继续拆分为下列可见模块：

拆分版默认以“只拆分、不改行为”为原则：`Speed_Mode_VESC=0` 选择已验证的并行速度 PI，`FW_Mode_VESC=0` 选择已验证的电压利用率积分弱磁。两个开关设为 `1` 时，才切入 VESC PID 和 Duty 映射弱磁实验支路。

1. `Speed_PID`：带低通微分项的速度 PID，并包含 Iq 限幅、斜率限制和回算抗饱和。
2. `Duty_Calculation`：由 dq 电压请求和母线电压估算调制率绝对值。
3. `Duty_LPF`：对调制率低通滤波，避免PWM纹波反复触发弱磁。
4. `FW_Duty_Map`：调制率超过 `FW_DUTY_START` 后，线性映射到 `0…FW_CURRENT_MAX`。
5. `FW_Iq_Backoff`：根据实际 Iq 与目标 Iq 的跟踪误差减小过量弱磁，为q轴电压留出余量。
6. `FW_Ramp`：按 `FW_RAMP_TIME` 限制弱磁电流变化速率，输出负的 `Id_fw`。
7. `IdIq_Current_Circle`：保证 `Id²+Iq²≤Imax²`，优先保留弱磁 Id，再限制 Iq。
8. `HFI_Observer_Sync`：角差同步实验模块。由于当前HFI与磁链观测角存在坐标/极性差异，直接学习角差会恶化电流与转速；默认 `HFI_Sync_Enable=0` 旁路该功能，仅保留用于观测两路角差。

`Scope_FW` 的三条曲线依次为：滤波后 Duty、映射得到的正值弱磁电流命令、斜坡后实际负 `Id_fw`。三者单位不同，该示波器主要用于判断触发顺序和渐变过程。

`Scope_Sync` 第一条为HFI角减原始磁链角的包角误差（deg），第二条为实际加到磁链观测角上的同步偏置（deg）。切换时两者应靠近，切换后偏置平滑回到0。

### 16.1 编码器、霍尔与无感选择

拆分版用 `Encoder_Enable`、`Encoder_Mode` 和 `Hall_Enable` 选择反馈。`Encoder_Mode` 只在编码器启用时生效：

| Encoder_Enable | Encoder_Mode | Hall_Enable | 实际反馈源 |
| ---: | ---: | ---: | --- |
| 0 | — | 0 | HFI/磁链无感 |
| 0 | — | 1 | 六步霍尔，并在高速交给无感 |
| 1 | 0 | 0 或 1 | 纯编码器，全程不切无感 |
| 1 | 1 | 0 或 1 | 低速编码器，高速无感 |
| 1 | 0 或 1 | 1 | 编码器优先于霍尔 |

`Encoder_Mode=0` 是纯编码器：编码器有效后，Park 角和速度环全程用 4096 CPR 量化角，不看转速门限。`Encoder_Mode=1` 是编码器与无感结合：低于 `3500 ERPM` 用编码器，高于 `3500 ERPM+5%` 交给磁链观测角，回到 `3500 ERPM-5%` 再切回编码器。本机 2 对极、目标 3000 RPM 对应 6000 ERPM，默认工况会越过这个门限，两条曲线可以对照。霍尔仍在 `2500…3500 ERPM` 之间按包角差平滑融合到无感观测角。`Encoder_Fault` 或 `Hall_Fault` 设为 1 可模拟传感器故障，管理器立即退回 HFI/磁链观测；故障清除后需连续有效 0.05 s 才重新接管。两种编码器模式都走这条故障回退。

`Scope_Feedback_State` 的三条线依次为来源编码、故障回退标志和有感权重。来源编码：`0=无感`、`1=霍尔`、`2=编码器`、`3=霍尔/无感融合`、`5=传感器故障回退`。仿真编码器由PMSM真实电角度按4096 CPR量化；仿真霍尔为60°电角度扇区中心角。

### 16.2 本机用哪种编码器

对照对象是 ATK-BL57H95D20E：2 对极，额定 3000 RPM，线间反电势 6.6 V/kRPM。机械 3000 RPM 对应 6000 ERPM、电频率约 100 Hz。电流环 15 kHz 时，角度反馈晚一拍大约 2.4° 电角。

本机正常换相用 `Encoder_Mode=0`（全程编码器）。`Encoder_Mode=1` 留作对照：约 1750 RPM（3500 ERPM，带回差）起，Park 角从编码器硬切到磁链观测角，并带上最多 4° 的弱磁相位补偿。默认目标 3000 RPM 会越过这个门限。`Scope_Feedback_State` 上，纯编码器的来源保持 `2`、有感权重保持 `1`；结合模式在高速变成来源 `0`、权重 `0`。

仿真里纯编码器更稳，是因为两条路径的角度品质不同：

- 仿真编码器是植物真实电角按 4096 CPR 量化，步进约 0.18°。
- 磁链观测器即使用与植物相同的 R、L、磁链，弱磁时仍有相位差。切换是一拍完成的，角差直接进 Park。
- 此时 `Id` 已经是较大的负值，角跳一拍会投影出假 `Iq`，转矩和转速出现台阶。速度环同时从编码器速度换成观测器 PLL 速度。

实机上观测器更吃亏。仿真里的电阻、电感和磁链与植物一致；铜电阻大约每升高 1 °C 增加 0.4%，死区、电压重构和电感饱和都会再拉偏观测角。编码器的主要误差是一次标定后的固定零点，以及接线和滤波不好时的丢脉冲。丢脉冲应修编码器。VESC 在很高 ERPM 把换相交给观测器，是因为一拍滞后会到几十度；这台额定只有 6000 ERPM，到不了那个区间。

速度用编码器计数的 PLL，Park 角用编码器位置。磁链观测器可以并排比较，编码器失效时再回退。`Encoder_Fault=1` 会立即退回 HFI/磁链，清除后连续有效 0.05 s 才重新接管。

这套 `.m` 和 `.slx` 是算法规格和波形对照。控制中断里的实现写在现有 C 模块（例如 `motor_flux.c` 与编码器模块），沿用当前 ADC/PWM 时序。不要用 MATLAB Coder 或 Embedded Coder 从教学模型生成固件；生成的 `step()` 带静态状态，对不齐现有分模块中断，也不适合在板上追问题。仿真确认公式后，用同一组输入比对 C 与 MATLAB 的输出，再接入 `Motor_Control_Step`。本次没有改固件。
