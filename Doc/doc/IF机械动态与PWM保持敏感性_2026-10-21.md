# I/F 机械动态与 PWM 保持敏感性

## 模型与范围

脚本 `Scripts/simulate_if_synchronism.py` 增加真实演化的相对角、机械角速度和 PI 状态，不再人为规定故障角轨迹：

```
delta_dot = p*omega_m - omega_forced
Te = 1.5*p*flux*(-Id*sin(delta)+Iq*cos(delta))
J*omega_m_dot = Te-Tload-B*omega_m
```

电气方程包含强制坐标系 omega*L 耦合和由模型转子速度/角度决定的反电势。R=0.474 Ω、L=0.112 mH、flux=2.390 mWb、7 极对、15 kHz、Kp=0.12、Ki=18 保持不变。

J 扫描 1e-6、5e-6、2e-5、1e-4 kg·m²；B 为 0 或 2e-6 N·m·s/rad；名义平衡相对角为 1、1.3、1.5 rad，负载按初始平衡求得。这些都是假设，不是本电机实测。转速为 3000/3500/5000 RPM，限幅为 8/8.5/10 V。反馈和输出额外延迟各取 0 或 1 拍。

分别计算理想旋转 dq 保持与静止 alpha/beta 零阶保持。后者在每拍内保持静止电压矢量，转换到旋转 dq 后电压随时间旋转，输出延迟还包含旧指令的旧角度。它仍只是平均 PWM 近似，不含载波脉冲、实际 ADC 孔径与 CCR 装载位置。

对每个数字系统先求完整离散固定点，再线性化，避免把连续模型平衡点误当离散平衡点。576 组中，按主特征值模长得到增长率；部分工况用非线性时域复核。模型是等 Ld/Lq、固定磁链和常数/黏性负载，不是完整实机辨识。

## 结果

3500 RPM 结果如下，组数不是实际故障概率：

| 保持模型 | 额外输出延迟 | 组数 | 增长组数 | 主模态增长率范围 1/s |
| --- | ---: | ---: | ---: | ---: |
| 理想旋转 dq | 0 拍 | 48 | 0 | -4.73～-3.69 |
| 理想旋转 dq | 1 拍 | 48 | 0 | -4.73～-3.68 |
| 静止 alpha/beta | 0 拍 | 48 | 0 | -2.28～-1.19 |
| 静止 alpha/beta | 1 拍 | 48 | 48 | +2.73～+3.55 |

全部 576 组中 192 组增长，均为静止矢量保持：3000/3500 RPM 的输出额外一拍组，以及 5000 RPM 的两种输出延迟组。

取 3500 RPM 扫描中增长率最大的一组，仅给 0.005 rad 初始主模态角扰动，对应约 0.0107 A 初始电流扰动。约 1.296 s 后角度偏离初始平衡 pi/2，电流峰值约 9.59 A，模型在此终止，避免继续把远离局部同步区的尾部当真实结果。**此截断不是硬件保护，也未触发仿真的 10 A/1 ms 过流条件。**相同参数但理想 dq 保持时扰动衰减，2 s 峰值约 1.003 A。两种轨迹按各自主模态初始化，不是所有状态扰动分量完全相同的试验。

## 结论与下一步

模型不再依靠人为指定大角漂移，也能在特定采样/保持条件下产生小扰动增长。输出矢量对应的角度时刻和生效延迟值得优先检查；此前理想 dq 保持电气仿真不能排除这些组合因素。

但尚未证明实机存在“一拍额外输出延迟”，也没有测得真实 J/负载；不能把模型当根因证明，不能直接据此加角度超前、改定时器或调增益。下一步只读核对 ADC 触发、计算结束、CCR 预装载与实际 PWM 更新的时间对应，保持 VESC 外设基线。

另核对原始轨迹，相邻记录均为 266～267 µs，强制角增量折算的转速中位数约 3500 RPM；没有发现该 136 ms 窗口内毫秒级记录空洞或持续强制速度偏移，但仍不能排除记录点之间的短抖动。
