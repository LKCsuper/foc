# 任务整轮耗时与 DMA 重叠补测

## 复核范围与计时口径

重点复核本轮新增的 `Motor_Timing_TaskRuntimeBegin/End`、任务接入、DMA 窗口计时及 J-Link 导出，不代表全部未提交历史修改已经逐行审查。

计时从外环任务 `osDelayUntil` 返回后的 Begin 内部时间戳开始，到本轮位置/速度处理、快照和节拍记账结束后的 End 内部时间戳为止。不包含周期睡眠和 End 自身计数更新，也不是从 RTOS 首次切入任务开始的精确指令级范围。单位为整数微秒，包含诊断、被其他任务和中断抢占的时间。

每轮复位 DMA 窗口计数，累计此任务执行期间 DMA 函数体的时间。最长任务同时保留该次 DMA 次数与累计时间，避免跨事件最大值相减。DMA 不含异常入出栈、计时钩子自身等全部开销，因此墙钟减 DMA 只能称为剩余时间，不能直接称为任务纯 CPU 时间；SysTick、其他中断及抢占也未完整扣除。

计数、64 位和、最小/最大值在任务结束时的短临界区更新；ISR 不执行 64 位汇总。统计最多 100000 轮；任务中途冻结会丢弃未完成轮次，复位清除旧轮次。诊断关闭时 Begin 直接返回，不额外进入临界区。新增固定 RAM 描述符为 40 字节，不改变原调度快照 ABI。停机冻结后只读 SWD 两次一致，按当前 map 定位。

主机测试覆盖累计、最小/最大、重复 End、微秒回绕、同事件 DMA、关闭和中途冻结；固件零错误零警告，主机完整回归通过。未改控制算法、增益、15 kHz FOC 或 VESC 外设基线。计时钩子仍会引入扰动，结果是诊断开启条件下的实测。
