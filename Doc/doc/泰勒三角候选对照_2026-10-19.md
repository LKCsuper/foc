# 泰勒三角候选对照

## 实现

新增 `sincos_taylor_f32` 候选，未替换现有 `sincos_f32` 查表默认后端。±64 rad 内先选择最近的 π/2 象限，再缩减到约 ±π/4：

`n = nearest(x * 2/pi)`

`r = (x - n * 1.5703125) - n * 0.00048382679489661923`

π/2 分成高低两部分，高部分可由二进制精确表示，减小多圈输入缩减误差。用 Horner 形式计算：

- `sin(r) = r + r^3*(-1/6 + r^2*(1/120 - r^2/5040))`，七阶。
- `cos(r) = 1 + r^2*(-1/2 + r^2*(1/24 + r^2*(-1/720 + r^2/40320)))`，八阶。

根据象限交换正余弦及符号，不访问表、不跨拍缓存。超范围、NaN/Inf 与现有查表后端一样回退标准库，零值保留 sin 正负零。公式与角度缩减只使用单精度浮点，保持原编译浮点设置。

## 精度与软件验证

新增 ±64 rad 共 262145 点与标准 sinf/cosf 对照，及 81 个 π/4 倍数相邻浮点边界、负零、非有限值/极大值回退测试。主机最大 sin/cos 绝对误差 3.57628e-7，最大 `abs(sin²+cos²−1)` 为 5.36442e-7。测试门槛分别 1e-6 与 2e-6，不是对所有实数输入的数学证明。

现有查表绝对误差扫点门槛 2.5e-5 继续保留；原同查表基准、Park/逆 Park、限幅、观测器测试未被候选替换。完整回归通过 `.build/host/taylor_candidate_regression.log`；严格 Keil 编译 0 错误、0 警告，Code 191556、RAM 不变、静态 DMA 栈深度不变。`.build/host/taylor_candidate_build.log`。

新增 `slcadence trigbench`，真实电机/命令 enable 关闭、目标为 0、位置/关节关闭、未检测、未选 BLDC 且无故障才允许运行。只比较独立数学调用，不操作 motor 或 PWM，不重置控制/诊断状态；每组四次调用短临界区隔离中断，输入构造和 checksum 累加在计时外。主机提取真实命令 helper，验证拒绝条件、计算仅在短临界区、打印在外、真实 motor 不变与总调用数。

| 输入族 | 查表 | 泰勒七/八阶 |

## 决策

保留高精度泰勒候选与可复现基准，但不改默认 sincos 后端，不修改增益、保护、控制频率或调度。当前板/编译器上查表在这些输入更快；不能推广成所有多项式实现或其他 MCU 都更慢。后续若要继续尝试，需有明确精度预算再比较较低阶或极小极大多项式，不以“用了泰勒”本身当作优化收益。

本轮真实电机未启动，最终 OFF、目标 0、fault 0、母线约 23.9 V。当前板上与构建 map 对应。尚未验证前一轮全路径快速三角迁移后的 300 RPM 实机运行、HFI/替代观测器及标定；停机微基准不能代替这些验收。
