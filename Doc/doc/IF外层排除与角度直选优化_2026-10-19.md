# I/F 外层排除与角度直选优化

## 停机基准扩展

在原 `slcadence currentbench` 增加 mode14～22，通过控制模块内同一 `Motor_Control_IfDiagnosticStep` 入口调用原有私有处理：空入口、默认选角、给定反馈选角、上下文填充、关闭弱磁步进、电压上限、RunIf、给定反馈 RunIf、同上下文 Current_Step。命令限定默认无感源，拒绝非零目标、运行中、位置/关节、BLDC、参数检测或故障状态。

固定软件角度 0.6 rad、24 V、15 kHz、1 A 给定、4 V 限幅，独立实例启动阶段设为稳定拖转、弱磁关闭，不运行真实启动或观测器。正常/饱和相电流与以前一致；每组四次调用、每模式每轮 256 次、三轮。新增控制状态与计数数组在命令任务栈，不增加静态 RAM。命令栈为 2048 个 StackType_t；不代表已经测过运行水位。

源级诊断接口只操作传入实例、读取默认反馈源/观测角，不含 HAL 和 PWM。合成调用仍会污染 PI/分段诊断窗口，基准结束关闭计时，不把这些统计作为实机运行数据。首次新增头文件依赖使主机编译缺少 common_assert.h 包含路径，补齐后完整回归通过。

## 等价优化

`Motor_Control_GetCurrentTheta` 在 sample 非空时仍直接返回传入电角。sample 为空且默认无感源时，沿用原强制角归一化后，按 sensorless_enable 直接选择原 `Motor_Sensorless_GetControlAngle(theta)` 或归一化开环角，不再只为角度而完整组装 `motor_feedback_sample_t` 并查询无感速度有效性。原 `Motor_Feedback_SampleDefault` 此路径没有状态写入，省略的速度有效性查询也只读。

编码器、霍尔与其他反馈源保留完整采样路径；没有修改默认反馈采样 API、速度反馈发布、PLL、PI、增益、限幅、保护、15 kHz 或 RTOS 调度。

新增四种反馈源×无感使能开关×三组正负跨圈角度的等价检查，比较新选角结果与原完整反馈采样给出的角度。既有给定反馈路径和传感器测试继续通过。完整回归 `.build/host/if_angle_reuse_regression.log`，严格编译 0 错误、0 警告，Code 190804，RAM 与静态 DMA 深度不变。

## 停机同条件复测

烧录校验 HEX `f48cf4f967c3cfbefa0a325f9fc8717d22f122472823ad751731d4eb9267704f`，`.build/host/if_angle_reuse_flash_20261019.log`。三轮原文 `Doc/verify/if_angle_reuse_bench_20261019.log`：

| 条件 | 优化前 µs | 优化后 µs |
| --- | ---: | ---: |
| 正常默认选角 | 1.863～1.875 | 1.199～1.238 |
| 正常 RunIf | 11.207～11.215 | 10.520～10.531 |
| 饱和 RunIf | 11.824～11.844 | 11.184～11.191 |

正常 RunIf 少约 0.69 µs（约 6%），饱和少约 0.65 µs。优化前后每轮 checksum 均 103384.804688。同入口正常 Step 仍约 7.04～7.07 µs，支持主要变化来自选角外层；其他入口编译布局/时基相位有小幅变化，不把小数当单拍高精度。

本轮只做停机独立软件实例测量，真实电机未启动，未完成新固件的 300 RPM 运行/任务延迟验证，不能把软件基准收益等价为总中断占用或调度长尾改善。基准结束 OFF、目标 0、fault 0、24 V。当前板上与构建 map 对应新优化固件；fault 0 不证明独立硬件过流保护。
