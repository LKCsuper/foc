# FOC 全范围代码简化审查

日期：2026-10-28。按用户要求，将范围从最近修改扩展到整个 FOC 自有控制代码；以本轮开始时的工作区为对照，保留此前未提交优化。

## 范围与实际修改

本轮建立了 App/motor、App/motor_sensor、App/motor_param、App/cmd、Library/Hal、Library/Bsp 共 224 个自有 C/H/inc 文件的基线快照，其中 109 个 C 文件。快照用于识别本轮变化，不代表对每行代码完成形式证明。第三方 VESC 实现只读。

| 模块 | 简化内容 | 保留的边界 |
| --- | --- | --- |
| SVPWM | 两套调制 API 共用私有内联扇区判断 | 两套占空比极性、浮点/整数取整和合成公式 |
| 反馈选择 | 删除初始化后的重复默认赋值，合并开环与默认来源 | 角度与速度独立有效性、传感器读取顺序 |
| I/F 启动 | 合并角度选择中重复的当前速度分支 | 已知转子位置、最低开环速度及原更新顺序 |
| 无感观测 | 非 CLOSED 状态提前返回，降低闭环融合路径嵌套 | 状态机、融合计算、同步调用及输出副作用顺序 |
| 失速保护 | 合并目标过低与爬坡未完成的复位分支 | 无效反馈独立处理、短路顺序、阈值与消抖 |
| 轨迹 | 两处到达目标的收尾复用私有内联函数 | 位置、速度、加速度、活动标志的写入顺序 |
| 位置 | 复用既有 SignedCount 回绕转换 | uint32 全范围的有符号计数差与浮点运算顺序 |

另修正 alignment 和 I/F 启动接口的空指针注释：这些接口原本要求非空并断言，不能写成允许 NULL。实际允许空指针的接口保留原契约。

控制入口、校准、诊断、关节及 HAL/BSP 也纳入检查范围；没有明确收益或难以证明等价的改写不落地。未为了覆盖文件数量而调整命名、搬目录或改硬件配置。诊断功能位合并试验因部分场景增加周期，已撤回。
