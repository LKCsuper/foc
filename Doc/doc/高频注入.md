# 高频注入（HFI）

> 更新日期：2026-09-20  
> 定位：讲清零速/低速为什么看不見反电势、凸极注入怎么估角，以及本仓库两套代码各自干什么。  
> 代码：`App/motor/observer/motor_hfi.c`（持续跟踪）、`App/motor/start/motor_hfi_start.c`（零速扫角）。  
> 频率数字见 [采样时间与控制频率](./采样时间与控制频率.md)。低速策略对照见 [低速反馈对比](./低速反馈对比_VESC_SimpleFOC_ODrive.md)。  
> **跟踪模块尚未接入 `Motor_Control_Step`，没有上板验收。** 当前实机低速仍走 I/F。不要把主机测试通过写成已经能无感零速闭环。

## 1. 一句话

转子停着或转得很慢时，反电势几乎是 0，磁链观测器看不见角度。  
**凸极电机**的 d/q 轴电感不相等。在估计 d 轴叠一个远高于电频率的电压，电流响应里会带出角度误差。这就是 **HFI（High Frequency Injection，高频注入）**。

本仓库拆成两步，不要混成一件事：

| | 扫角 `motor_hfi_start` | 跟踪 `motor_hfi` |
|--|------------------------|------------------|
| 干什么 | 零速扫 12 个试探轴，找凸极、分辨 N/S | 每个电流环周期 ±Vh，持续跟电角 |
| 有没有 180° 模糊 | 用正/负响应差补 π，尽量给出真 d 轴 | **有。** 必须先 Seed 初值 |
| 现在接没接主控制 | 已接，`hfistart` 打开才跑 | **没接**，只提供 Step 输出 |
| 默认 | 关 | 关 |

表贴机 `Ld ≈ Lq` 没有可用凸极，两套算法都无效。当前调试电机 ATK-BL57H95D20E 铭牌只给了一条线电感 0.8 mH，**没有分 Ld/Lq**，不能默认它能跟住。

## 2. 低速为什么观测器没用

一相电压：

```text
v = R·i + L·di/dt + e
e ≈ ωe · λ · f(θe)
```

`e` 跟电角速度成正比。本电机 2 对极、`λ ≈ 0.026 Wb`：

| 机械转速 | ωe | 反电势数量级 `ωeλ` |
|----------|-----|-------------------|
| 0 | 0 | **0 V** |
| 72 RPM | 15 rad/s | **0.4 V** |
| 300 RPM | 63 rad/s | 1.6 V |
| 1500 RPM | 314 rad/s | 8.1 V |
| 3000 RPM | 628 rad/s | 16.2 V |

72 RPM 时 0.4 V 淹没在开关噪声和采样误差里。把 Ortega 观测器增益拧大，放大的是噪声，不是转子角。  
所以低速只能：

1. **I/F**：电流闭环 + 强制角把转子拖起来（本仓库已验证的路）  
2. **HFI**：不靠反电势，靠凸极  
3. 霍尔 / 编码器：有感，不是无感

中高速反电势够大了，应切回观测器，停掉注入，避免噪声和损耗。观测器本身见 [磁链观测器](./磁链观测器.md)。本仓库这条交接还没做。

## 3. 凸极是什么

转子磁路上，d 轴（磁钢方向）和 q 轴（正交）的磁阻可以不同，于是：

```text
Ld ≠ Lq
```

内嵌式 IPMSM 通常 `Lq > Ld`。表贴 SPMSM / 很多小功率 BLDC 接近 `Ld ≈ Lq`。

在估计坐标系里，真实角和估计角的差写成：

```text
θ_err = θ_true − θ_hat
```

高频电压打在估计 d 轴上时，电流增量大约是：

```text
Δid ≈ p · Vh · Ts / Ld_eq
Δiq ≈ p · Vh · Ts · (Ld − Lq) / (2 Ld Lq) · sin(2 θ_err)
```

- `p = ±1`：本拍注入极性  
- `Vh`：注入电压幅值 (V)  
- `Ts`：电流环周期 (s)，本板 66.7 µs  

对齐时 `θ_err = 0`，`sin(2θ_err) = 0`，q 轴几乎没有高频电流。  
估偏了，ΔIq 跟着 `sin(2θ_err)` 变。**信息在 ΔIq，不在反电势。**

`sin(2θ_err)` 以 π 为周期，所以跟踪只能锁到 d 轴或 −d 轴，分不清 N/S。这就是 180° 模糊，必须靠扫角或预对齐给初值。

## 4. 本仓库用的是脉振方波，不是正弦、也不是 VESC 双边调制

### 4.1 注入长什么样

每个电流环周期把 `Vd` 叠上 `±Vh`，q 轴注入为 0：

```text
拍 n:   Vd_h = +Vh
拍 n+1: Vd_h = −Vh
拍 n+2: Vd_h = +Vh
…
```

这是**脉振 HFI**（pulsating）：高频电压始终打在估计 d 轴上，不是旋转注入。  
方波而不是正弦：电流环就能翻转极性，不必再跑一个正弦发生器。

本板电流环 15 kHz，注入频率是它的一半：

```text
f_h = f_current / 2 = 7.5 kHz
```

相对 72 RPM 的 2.4 Hz 电频率，7.5 kHz 是高频。相对 PWM 15 kHz，它正好是开关频率的一半，每个完整三角波翻转一次。

### 4.2 明确没做的事

VESC 的 HFI V2～V5 会在同一个 PWM 周期里改 V0 / V7 两套调制，用顶部、底部两次采样拆开电感响应。那要动采样窗和比较值更新时刻。

本模块**不改** TIM / ADC / DMA / PWM 基线，只在电流环算完 PI 之后叠加 `vd_inj`。  
所以它比 VESC 量产 HFI 更简单，也更吵、更依赖凸极大小。不要拿 VESC 的 `foc_hfi_*` 参数直接往这里填。

注入必须加在 **PI 输出之后**。若改成 Id 目标，电流环会把高频电流当误差掐掉，注入等于没打。

## 5. 一拍里代码做什么

`Motor_Hfi_Step` 每 FOC 周期一次，状态由调用者持有。

```text
用 θ_hat 做 Park：Iq = −iα sinθ + iβ cosθ

若已有上一拍：
    error = −(Iq − Iq_prev) · polarity     // IPMSM，Lq>Ld 时取负
    θ_hat += gain · error
    电角速度：一阶低通 dθ/dt（系数 0.10）
    polarity = −polarity

记下 Iq，输出：
    Vd_h = polarity · min(Vh, Vbus · 母线比例)
    Vq_h = 0
```

首拍只注入、不解调，避免用未定义的 ΔIq。关掉或 `voltage=0` 时不注入、不改角。

符号约定（必须和代码一致）：

```text
C = (Ld − Lq) · Ts / (2 Ld Lq)     // IPMSM 为负
ΔIq ≈ 2 · C · p · sin(2 θ_err)     // 极性翻转后的一阶差分
error = −ΔIq · p = 2 |C| sin(2 θ_err)
θ_hat += gain · error              // θ_err>0（估滞后）→ 增大 θ_hat
```

`gain` 必须 ≥0。单位是 rad/A：解调误差是电流，校正的是电角。凸极越弱，同样 `Vh` 下 |C| 越小，就要更大的 gain，噪声也更大。

注入电压还受母线比例限制，默认不超过 `0.20·Vbus`。24 V 时 2 V 注入远低于这个上限；真正要担心的是电流纹波和啸叫，不是母线比例。

## 6. 扫角：给初值、分辨极性

`MotorHfiStart_Step` 在 **12 个试探轴**上轮流打双极性电压（相邻轴隔 15° 电角度，只扫半圈，因为电感以 180° 重复）：

```text
θ_try = π · axis / 12 ,  axis = 0 … 11
每个轴 cycles_per_axis 次正负翻转
沿该轴投影电流，累加 |Δi|
响应最大的轴 ≈ 凸极轴
负向响应更大则再加 π → 分辨 N/S
confidence = (max − min) / max
```

默认：`hfistart` 关闭；打开时 `V=2 V`、每轴 8 个周期、`min_confidence=0.05`。  
I/F 启动前若扫角成功，会把 `ol_theta` 设成识别角，并标记对齐完成。

扫角占用整拍输出（探测电压直接当本拍 Vd），不是叠在电流环上面。跟踪则相反：电流环照常算 Vd/Vq，只叠加 `vd_inj`。

建议顺序（接入主控制之后才适用）：

```text
1. hfistart 扫出初值并分辨 N/S
2. Motor_Hfi_SeedAngle(识别角)
3. 低速用跟踪角做 Park，Vd += vd_inj
4. 转速够了停注入，交给观测器
```

## 7. 频率和时序（对着本板数字看）

```text
PWM 15 kHz          MOS 开关
ADC 30 kHz          顶部 + 底部各采一次
电流环 15 kHz       本板只用顶部那一帧算 FOC
HFI 方波 7.5 kHz    每个电流环拍翻转一次极性
电频率 2.4 Hz       72 RPM、2 对极
```

要成立，必须：

1. 电流环明显快于注入频率的若干倍——方波取 `fs/2`，刚好每个 PWM 周期一个样，是能做到的下限，不是余量很大的设计。  
2. 注入频率明显快于电频率——7.5 kHz / 2.4 Hz ≈ 3000，这项很宽裕。  
3. 采样必须和注入对齐：本拍采到的 Iq 是**上一拍** `Vd_h` 的结果。代码用 `polarity` 记住上一拍极性，再解调。

ISR 预算仍是 66.7 µs。HFI 本身只是几次乘加和一次 sin/cos，通常不是负载大户；真正费时的是观测器、Hall 诊断。不要为了 HFI 去降 PWM 频率。

## 8. 调用边界（跟踪模块）

纯算法，不读全局电机、不碰 HAL / RTOS。

| 函数 | 作用 |
|------|------|
| `Motor_Hfi_Reset` | 清状态。停机、切模式时调用 |
| `Motor_Hfi_NormalizeConfig` | 电压 0～12 V，gain 0～100，母线比例非法回退 0.20 |
| `Motor_Hfi_SeedAngle` | 写入 [0, 2π) 初值，不打乱极性历史 |
| `Motor_Hfi_Step` | 一拍。`apply=true` 时把 `vd_inj` 加到 PI 的 Vd |
| `Motor_Hfi_GetAngle` / `GetSpeedE` | 读跟踪角、电角速度 |

配置每拍传入，不进 Flash：

| 字段 | 含义 |
|------|------|
| `enabled` | 本拍是否注入 |
| `voltage` | \|Vd_h\| (V) |
| `gain` | 电角校正 (rad/A) |
| `max_bus_voltage_ratio` | 注入 / 母线上限 |

接入时 Park 应用角应改用 `output.angle`，不是继续积分 `ol_theta`。速度环若要用 HFI 速度，读 `GetSpeedE` 再换成机械 RPM：`n = ωe · 60 / (2π · 极对数)`。反馈失效时不要把这个速度当成有效零速去做堵转判断。

## 11. 什么时候不能用 / 常见失败

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 怎么调 gain 角都漂 | `Ld≈Lq`，ΔIq 里没有 2θ 信息 | 换凸极电机，或继续 I/F / 有感 |
| 锁在差 180° 的位置 | 跟踪的 2θ 模糊，没 Seed 或扫角认反 | 先扫角，看 `confidence`；失败不要硬跟 |
| 电流环把注入掐掉 | 把 Vh 加进了 Id 目标 | 加在 PI 输出的 Vd 上 |
| 啸叫很大、Iq 抖 | Vh 太大 | 先降电压，再加 gain；不要一上来 12 V |
| 高速还在注入 | 反电势已经够用 | 该停 HFI、切观测器（尚未实现） |
| 本电机线电感 0.8 mH 看不出凸极 | 铭牌没给 Ld/Lq | 先用主机测试验证算法，上板只当实验 |

过流软件阈值仍在。注入叠在基波电压上，空载也要留电流余量。`olstop` 是 PWM 中点，不是关桥。
