# 停机ADC差异与诊断开销核查

本轮仅离线分析、主机回归与编译/反汇编；没有连接串口、烧录或启动电机。控制板仍为上一轮已确认停机的half限制版。外设配置、控制公式与增益不变。

## 数据与分解

使用 `adc_half_stationary_20261016.log` 及repeat/repeat3三次冻结导出，仅合并CRC有效行，完整32对、拒绝3条损坏行，读取状态位均0，配对间隔33～34us。输出 `Doc/verify/adc_half_stationary_decomposition_20261016.json`。

所有差分统一为回调方向down−up，原始顺序仍为CURR1/2/3，不把方向当成真实ADC触发边沿。设每对差分为d、共同分量m=(d0+d1+d2)/3、差模ri=di−m：

- 总能量为所有配对的Σ(di²)，共模能量为Σ(3m²)，差模能量为Σ(ri²)；二者正交、相加为总能量。
- 固定均值分解另外计算各通道down−up均值mu，固定均值能量为NΣ(mu²)。这与共/差模是两种不同分解，不能把百分比相加。
- 差分RMS不除以sqrt(2)推单样本噪声；相邻样本可能相关。32对约30ms间隔抽样不能恢复频谱或证明噪声来源。

| 指标 | 本窗口结果 |
|---|---:|
| 原始差分共模能量占比 | 81.94% |
| 原始差分差模能量占比 | 18.06% |
| 共模差分RMS | 2.145 counts |
| 差模每通道RMS | 1.007 counts |
| 固定down−up均值解释的原始差分能量 | 17.07% |
| Clarke差分向量RMS（按当前比例折算） | 0.11475 A |
| 扣除固定向量均值后的Clarke差分RMS | 0.10900 A |
| 固定向量均值解释的Clarke差分能量 | 9.78% |

通道差分相关系数约0.655/0.682/0.856，说明共同变化较明显，但不证明一定是Vref、地噪声或某个放大器的问题。完整三分流Clarke本来就抑制等幅共模；剩余差模仍会进入alpha/beta，因此不能只说“82%共模所以无需处理”。

down−up通道均值为−0.50/−1.03125/−1.25counts，对应Clarke向量均值约[0.03442,−0.01018]A；扣均值后向量RMS仅下降约5.02%。这使“只补一个固定半周期偏移即可解决”的解释不足，但不排除偏移与动态误差共同作用。

软件PWM序号相同的16对，Clarke差分RMS约0.11075A；间隔一次软件提交的16对约0.11862A。两组与回调先后方向绑定，不是随机A/B；不能将差异归因于COM事件，也不能把相同软件序号当成相同活动PWM波形的证据。

## 诊断热路径证据

对上一轮已编译的安全限制版做只读反汇编，发现half停止采集检查之后、抽样判定之前，仅为了把ia/ib/ic置零就每回调执行一次VLDR和三次VSTR。这些字段在half格式里只是占位，根本不需要浮点运算。

本地FreeRTOS CM4F端口显式设置ASPEN/LSPEN；浮点指令存在增加浮点上下文处理成本的可能。是否在某次回调触发懒保存取决于实际上下文/寄存器状态，不能用静态指令直接换算时间或认定上轮串口失响应完全由它导致。

已将整个局部帧用memset清零，移除浮点赋零；同一ARMCC版本重新编译，反汇编确认：抽样判定前原4条FPU指令变为0条，清零为整数STR。抽样命中后的电压快照/PairPush仍可使用FPU，不宣称整个模式无浮点，也不开放运行采集。

其他逐回调成本仍存在：六次Hal_Motor_CurrentAdc调用（两个三次循环）、定时器/DMA状态读、多次门控/计时/序号调用、两份44字节历史帧复制。32条/901回调抽样不等于只在命中时付出开销。原始诊断若运行在30k回调/秒，每回调新增1us就约占3%CPU预算；这是算术示例，不是本轮实测耗时。

本轮没有WCET、CPU占用或停机延迟的硬件测量。不能据此宣称串口失响应已修复；停机专用限制、起转取消诊断及运行脚本禁用half保持不变。
