# 观测器参数下限调用优化

## 依据与修改

上一轮已烧录固件的 map 显示，`Motor_Sensorless_UpdateStateInternal` 仍引用 `__hardfp_fmaxf`。每个有效观测拍有五处固定有限非负下限：R、L、额定磁链、极对数和锁定转速误差限值。

增加仅限本文件的 `static inline Motor_Sensorless_AtLeast`，使用 `value > minimum ? value : minimum`。限定下限为有限非负值，NaN 输入选下限，正无穷保留，负无穷选下限；零下限调用传入正零。没有改变控制方程、归一化下限、增益、外设、15 kHz 频率、任务调度或诊断采样模式，没有跨拍缓存。不是可任意替换全部 fmaxf 的通用实现，不用于可为 NaN 的下限。
