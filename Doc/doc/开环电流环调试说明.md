# 开环电流环调试说明

本文记录当前工程"角度开环 + 电流闭环"FOC 调试流程，涵盖原理、参数、操作步骤和故障排查。对应代码主要在：

- [motor_param.c](../App/motor_param/motor_param.c) — 默认电机参数和开环参数初始化、Flash 持久化。
- [motor_it.c](../App/Motor/motor_it.c) — ADC-DMA 中断里执行开环 FOC、电流环 PI、SVPWM 输出。
- [cmd_openloop.c](../App/Cmd/cmd_openloop.c) — 串口 shell 命令，运行时修改开环参数。

---

## 1. 当前控制模式

当前默认使用：

```c
gpstMotorDefault->ol_mode = 1;
```

含义：

```text
角度开环 + 电流闭环
```

这不是完整闭环速度控制，也不是无感观测器闭环。它的角度由软件按目标转速积分产生，电流由 D/Q 电流 PI 闭环控制。

### 控制链路

```text
目标机械转速 RPM
  → 软启动斜坡 → ol_current_rpm
  → 软件积分得到电角度 theta (角度开环)
  → 采样三相电流 ia/ib/ic (ADC → 零点校正 → 电流系数)
  → Clarke/Park 得到 Id/Iq (电流反馈，实时)
  → Id/Iq PI 电流环输出 Vd/Vq (电流闭环)
  → 矢量限幅 (防积分饱和 windup)
  → 反 Park 得到 V_alpha/V_beta
  → SVPWM
  → TIM1 三相 PWM → 逆变器 → 电机
```

### 与完整 FOC 的区别

| 环节 | 本方案 (ol_mode=1) | 完整 FOC |
|------|-------------------|----------|
| 角度来源 | 软件积分 (开环) | 编码器/霍尔/观测器 (闭环) |
| 速度环 | 无 | 有 (速度 PI 输出 Iq 目标) |
| 电流环 | 有 (Id/Iq PI) | 有 |
| 弱磁控制 | 无 | 有 |

关键是：**角度是"假的"，但电流是"真的"被闭环控制的**。角度错了 → Park 变换后 Id/Iq 不是真实的 D/Q 轴电流 → PI 控的是错误量 → 电机可能抖、响、发热。

## 2. 硬件前提条件

在开始调电流环之前，必须确认以下基础链路正确。

### 2.1 PWM 输出正常

- TIM1 三相互补 PWM 有输出。
- 死区时间配置正确（上下桥臂不会直通）。
- `olstop` 后三相占空比回到 50%（安全中点电平）。

### 2.2 ADC 采样正常

- ADC-DMA 中断能正常触发 (`Motor_DmaInt`)。
- 三相电流 ADC 值在静止时接近中点 (12 位 ADC 中点 ≈ 2048，当前默认兜底值为 2045)。
- 母线电压 `v_bus` 读数正常 (如 24V 系统应接近实际电源电压)。

### 2.3 电流零点校准

电流 ADC 的零点偏移量存储在 Flash (`currentOffset[0..2]`)，代码会校验合法性：

```c
// 合法范围 (1.0V~3.0V 对应的 ADC 值)
#define MOTOR_CURRENT_OFFSET_MIN  (1000.0f)
#define MOTOR_CURRENT_OFFSET_MAX  (3000.0f)
#define MOTOR_CURRENT_OFFSET_DEFAULT (2045.0f) // 超出范围时兜底
```

调试前用 `olspeed` 查看三相电流 `Ia/Ib/Ic`：
- 电机静止、PWM 未输出时，三相电流应接近 0。
- 如果静止时显示明显非零电流，零点偏移有问题，电流环在此基础上闭环必然出错。

### 2.4 相序确认

三相电流 ADC 通道与电机相线的映射必须正确。当前代码中 `Motor_It_ParamCal()` 里 vb/vc 的 ADC 通道与相序不是简单一一对应（见函数内注释）。如果改过硬件或换过电机，优先确认真实相序。

快速验证方法：切到 `olmode 0` (V/F 模式)，给低压低速 (`olspeed 100`, `olvlimit 8`)，看电机能否平稳转起来。能转 → 相序大概率正确；只抖不转 → 相序或电角度方向可能反了。

## 3. 关键参数

默认参数在 `MOTOR_Param_Init()` 里：

```c
// 系统参数
gpstMotorDefault->ol_enable      = true;
gpstMotorDefault->ol_mode        = 1;          // 0=V/F, 1=角度开环+电流闭环
gpstMotorDefault->ol_foc_freq    = 30000.0f;   // FOC 控制频率 Hz
gpstMotorDefault->ol_pole_pairs  = 2.0f;       // 电机极对数

// 转速参数
gpstMotorDefault->ol_target_rpm  = 300.0f;     // 目标机械转速 RPM
gpstMotorDefault->ol_max_rpm     = 3000.0f;    // 目标转速上限
gpstMotorDefault->ol_min_rpm     = 30.0f;      // 最低转速地板 RPM
gpstMotorDefault->ol_ramp_rpm_s  = 100.0f;     // 加速斜坡 RPM/s

// 电流目标
gpstMotorDefault->ol_iq_set      = 1.5f;       // Q 轴目标电流 A
gpstMotorDefault->ol_id_set      = 0.0f;       // D 轴目标电流 A (永远保持 0)

// 电流环 PI
gpstMotorDefault->ol_current_kp  = 0.5f;       // 电流环比例增益
gpstMotorDefault->ol_current_ki  = 100.0f;     // 电流环积分增益

// 电压限幅
gpstMotorDefault->ol_vq_limit    = 18.0f;      // D/Q 输出电压矢量限幅 V

// 启动辅助
gpstMotorDefault->ol_start_phase_boost = M_PI / 2.0f; // 启动第一拍 90° 相位提前

// V/F 模式参数 (ol_mode=0 时使用)
gpstMotorDefault->ol_v_boost     = 1.0f;       // 启动补偿 V
gpstMotorDefault->ol_kv_f        = 0.057f;     // V/F 斜率 V/Hz
```

### 参数速查表

| 参数 | 命令 | 作用 | 调试建议 |
| --- | --- | --- | --- |
| `ol_target_rpm` | `olspeed` | 目标机械转速 | 先 80~300 RPM |
| `ol_max_rpm` | `olmax` | 目标转速上限 | 调试初期限制到 1000 RPM |
| `ol_min_rpm` | `olmin` | 最低转速地板，低于此值积分角度仍按此速度 | 默认 30 RPM，一般不动 |
| `ol_ramp_rpm_s` | `olramp` | 加速斜坡 RPM/s | 抖动就降低 (30~50)，响应慢再提高 |
| `ol_vq_limit` | `olvlimit` | D/Q 输出电压矢量限幅 | 先用 8~12V |
| `ol_iq_set` | `oliq` | Q 轴目标电流，主要决定转矩 | 从 0.5A 逐步加 |
| `ol_id_set` | `olid` | D 轴目标电流 | 永远先保持 0 |
| `ol_current_kp` | `olkp` | 电流环比例增益 | 大了硬、响、抖，小了软 |
| `ol_current_ki` | `olki` | 电流环积分增益 | 大了容易积分冲击，小了跟随慢 |
| `ol_start_phase_boost` | `olphase` | 启动第一拍相位提前 | 默认 `π/2`，一般不动 |
| `ol_pole_pairs` | (无命令，改代码) | 电机极对数 | 必须正确，否则电角度速度错误 |
| `ol_foc_freq` | (无命令，改代码) | FOC 控制频率 Hz | 必须接近真实中断频率 |

> **关于极对数**：如果电机参数表里写"磁极数 4"，通常表示 4 极，即 2 对极 → `ol_pole_pairs = 2.0f`。如果厂家明确写"4 对极"，才设成 `4.0f`。设错会导致电角度速度翻倍或减半，电机必然异常。

## 4. 主流程

### 4.1 中断驱动链

每次 ADC DMA 传输完成触发 `Motor_DmaInt()`，内部有分频机制：

```c
static bool Motor_DmaInt_ShouldRun(void)
{
    static int skip = 0;
    if (++skip >= FOC_CONTROL_LOOP_FREQ_DIVIDER) {
        skip = 0;
        return true;
    }
    return false;
}
```

DMA 中断频率 = PWM 频率 (如 30kHz)，但 FOC 算法不需要每 PWM 周期都跑。通过 `FOC_CONTROL_LOOP_FREQ_DIVIDER` 做分频，实际 FOC 运算频率 = PWM 频率 / 分频系数。

`ol_foc_freq` 应该设成真实 FOC 运算频率 (30kHz)，代码内部用此值计算控制周期 `dt`：

```c
dt = FOC_CONTROL_LOOP_FREQ_DIVIDER / ol_foc_freq
```

### 4.2 主流程

```text
Motor_DmaInt                          // DMA 中断入口
  → Motor_DmaInt_ShouldRun            // 分频判断
  → Motor_It_ParamCal                 // 采样：三相电流/电压/母线电压
  → Motor_OpenLoop_Run                // 开环状态机
    → v_bus < 1V → 复位 + 安全输出
    → !IsReady → 停机 (olstop)
    → IsReady → UpdateMotion → RunVf 或 RunCurrent
```

### 4.3 电流闭环流程 (`Motor_OpenLoop_RunCurrent`)

```text
theta = Motor_CurrentLoop_GetTheta()       // 获取角度 (启动第一拍 + 相位补偿)
Motor_CurrentFeedback_UpdateDq(theta)      // Clarke + Park → Id/Iq
Motor_CurrentTarget_Get(&id_target, &iq_target)  // 获取 Id/Iq 目标 (含低速缩放)
voltage = Motor_CurrentLoop_RunPi(...)     // PI 控制 → Vd/Vq
Motor_Foc_OutputVoltage(vd, vq, theta)     // 反 Park + SVPWM → 更新 TIM1 占空比
```

## 5. 角度开环详解

角度更新在 `Motor_OpenLoop_UpdateMotion()` → `Motor_OpenLoop_UpdateTheta()`：

```c
// 角度不能完全停在 0，否则磁场固定不动，只吸不转
if (rpm_for_angle < ol_min_rpm) {
    rpm_for_angle = ol_min_rpm;
}
// 机械转速 → 机械角速度 → 电角速度 → 积分
ol_theta += RPM2RADPS_f(rpm_for_angle) * ol_pole_pairs * dt;
utils_norm_angle_rad(&ol_theta);  // 归一化到 [0, 2π)
```

关键点：
- `olspeed` 改的是**目标速度**，软启动斜坡 (`olramp`) 决定实际转速 `ol_current_rpm` 逼近目标的速度。
- 即使目标转速为 0，一旦使能且 `ol_current_rpm < ol_min_rpm`，角度仍按 `ol_min_rpm` 持续递增。这保证了低速时磁场不会"冻住"。
- `ol_pole_pairs` 错了 → 电角度速度错 → 电流环控的是错误角度下的虚假 D/Q 电流 → 电机表现异常。

### 相位补偿机制

启动第一拍时，`Motor_CurrentLoop_GetTheta()` 会在积分角度上叠加一次 `ol_start_phase_boost`（默认 π/2，即 90° 电角度）：

```c
if (s_ol_was_stopped && m->ol_current_rpm > 0.0f) {
    theta += m->ol_start_phase_boost;  // 仅第一拍
    s_ol_was_stopped = false;
}
```

目的是让磁场一开始就"摆出"转矩方向，而不是从 0 角度慢慢找。后续完全跟随软件积分角度，不再叠加。

## 6. 电流闭环详解

### 6.1 电流反馈

```c
// Clarke: 三相静止 → 两相静止
clarke_transform(ia, ib, ic, &Ialpha, &Ibeta);
// Park: 两相静止 + 电角度 → 两相旋转 (D/Q)
park_transform(Ialpha, Ibeta, theta, &Id, &Iq);
```

这里依赖三件事全部正确：
1. 电流 ADC 零点正确。
2. 三相电流 ADC 通道与电机相线映射正确。
3. 软件开环角度方向和实际相序一致。

任何一个错误 → 电流环"以为自己在控电流"，实际电机会抖、响、发热甚至不转。

### 6.2 电流目标与低速缩放

```c
id_target = ol_id_set;   // 通常为 0
iq_target = ol_iq_set;   // 主要转矩电流
```

**低速 Iq 缩放**：当实际转速低于 `ol_min_rpm` 时，代码按比例缩小 Iq 目标：

```c
if (ol_current_rpm < ol_min_rpm && ol_min_rpm > 0.0f) {
    float scale = ol_current_rpm / ol_min_rpm;
    if (scale < 0.1f) scale = 0.1f;  // 下限 10%，不完全关断
    iq_target *= scale;
}
```

这意味着刚启动时电流不会立刻给满，而是随转速上升逐渐增加到目标值。这是保护机制——转子还没转起来时给满 Iq 只会发热，不产生有效转矩。

### 6.3 PI 控制器

D/Q 轴各自独立跑标准 PI：

```c
// PI 标准型 (非并联型)
vd_int += ol_current_ki * id_err * dt;  // 积分累加
vd_int = clamp(vd_int, ±v_limit);       // 积分限幅
vd = ol_current_kp * id_err + vd_int;   // P + I
```

PI 输出经过**矢量限幅**：

```c
// 不单独限 Vd/Vq，而是按矢量幅值整体限制
if (utils_saturate_vector_2d(&vd, &vq, v_limit)) {
    // 限幅发生后，回写积分项防止 windup
    ol_vd_int = vd - kp * id_err;  // 反推：积分 = 输出 - 比例
    ol_vq_int = vq - kp * iq_err;
}
```

限幅值取 `ol_vq_limit` 和 `v_bus * 0.75` 的较小值。SVPWM 保守限制到 75% 调制深度，防止过调制后 PI 持续积分（积分饱和 / windup）。

### 6.4 PI 参数调试原则

| 参数 | 增大效果 | 减小的效果 |
|------|---------|-----------|
| Kp | 响应更快、转矩更硬、电流跟随紧 | 响应软、跟随慢、更安静 |
| Ki | 稳态误差消除快、跟踪紧 | 稳态误差消除慢、更平滑 |

**典型整定流程**：
1. 先设 Ki = 0，只调 Kp。从 0.05 开始，每次翻倍，直到电流阶跃响应出现轻微振荡。
2. 把 Kp 降到振荡值的 50%~70%。
3. 逐步加 Ki，从 Kp × 100 开始（注意：单位是 Hz 级别）。观察 `olspeed` 里的 Id/Iq 反馈是否紧跟目标。
4. Ki 过大 → 听到周期性"嗡嗡"声或电流波形过冲振荡 → Ki 减半。
5. Kp 过大 → 高频尖锐啸叫、电机发烫 → Kp 减半。

## 7. 推荐启动命令序列

### 第一步：确认基础状态

```text
olspeed
```
确认 `v_bus` 正常，电流接近 0。如果没有输出，检查串口和 DMA 中断。

### 第二步：V/F 模式验证相序

```text
olstop
olmode 0
olboost 1.0
olkvf 0.057
olvlimit 8
olramp 50
olspeed 100
olstart
```

电机能平稳转起来 → 相序、PWM、电角度方向基本正确 → 可以切电流模式。

### 第三步：电流模式低速试转

```text
olstop
olmode 1
olid 0
oliq 0.5
olkp 0.10
olki 20
olvlimit 8
olramp 30
olmin 30
olmax 1000
olspeed 80
olstart
```

观察：
- `olspeed` 查看 Id/Iq 反馈是否跟踪目标。
- 电机是否平稳低速旋转。
- 声音是否平顺。

### 第四步：逐步提电流

```text
# 0.5A 稳定后:
oliq 0.8
olspeed 120

# 稳定后:
oliq 1.2
olspeed 200

# 稳定后:
oliq 1.5
olspeed 300
olramp 80
```

### 第五步：调 PI

```text
# 如果电流跟随慢:
olkp 0.2
olki 50

# 如果电流抖动/尖啸:
olkp 0.08
olki 15
```

## 8. 现象诊断与调整

### 8.1 电机不转，只吸住或嗡嗡响

**优先排查**：

1. 相序不对 → V/F 模式验证。
2. 电角度方向反了 → 改 `ol_pole_pairs` 符号或检查逆 Park 角度方向。
3. `ol_pole_pairs` 不对 → 确认电机规格。
4. Iq 太小，克服不了负载转矩。
5. 电流采样方向反了或 ADC 通道映射错。

**试调参数**：
```text
oliq 1.5
olkp 0.08
olki 15
olramp 30
olspeed 80
```

如果仍然只抖不转，**先不要继续加电流**——先检查相序、电流映射、电流方向。

### 8.2 能转但声音尖、抖、发热快

通常是电流环太硬或反馈不干净：

```text
olkp 0.08
olki 10
oliq 0.6
olvlimit 8
```

降 PI 后明显变安静 → 说明原 PI 偏大。降完后仍吵 → 可能是：
- 电流采样噪声大（需要硬件滤波或软件低通）。
- 角度增量不均匀（`ol_foc_freq` 与真实中断频率不匹配）。

### 8.3 能转但没力

逐步加转矩电流和电压限幅：

```text
oliq 1.5
oliq 2.0
olvlimit 15
```

如果加 `Iq` 后电流显示有变化但电机仍没力 → 可能是角度/相序/电流采样方向问题，而不是参数小。可以在 `olspeed` 中观察实际 Id/Iq：
- 设 `olid 0, oliq 1.5`，如果实际 Id 很大而 Iq 很小 → 角度偏移严重。
- 如果 Id/Iq 都接近目标但电机仍没力 → 角度方向反了，或实际电流与显示不符。

### 8.4 加速时丢步或突然抖

```text
olramp 30       # 降低斜坡
olspeed 80      # 降低目标速度
oliq 1.2        # 必要时增加一点转矩电流
```

失步的本质是磁场转太快，转子机械惯性跟不上。开环没有位置反馈，无法感知失步。

### 8.5 低速抖动

低速时 V/F 模式的通病——反电动势小，电压裕量少，加上没有位置反馈，容易抖。缓解方法：
- 提高 `ol_min_rpm`（如从 30 提到 60），让角度积分保持一定速度。
- 适当提高 `ol_v_boost`（V/F 模式）或 `oliq`（电流模式）。
- 降 Kp，让电流环更软。

### 8.6 静止时电流不为零

用 `olspeed` 看在 PWM 未输出时 Ia/Ib/Ic：
- 如果静止显示明显非零 → 电流零点偏移有问题。
- Flash 里存的 `currentOffset` 可能异常，代码会自动兜底到 2045，但 2045 不一定是你板子的实际中点。

### 8.7 无法启动，`olstart` 后立即保护

可能原因：
- `ol_vq_limit` 太大 → 启动瞬间电压冲击 → 过流 → 硬件保护。
- `ol_current_kp` 太大 → 启动瞬间 PI 输出跳变 → 过流。
- `ol_start_phase_boost` 不适合当前电机。

## 9. 诊断工具：读懂 olspeed 输出

`olspeed` 打印所有关键运行时数据。以电流模式为例：

```text
===== Open-Loop Status =====
  Enable     : ON
  Mode       : 1 (Current-loop VESC style)
  Target RPM : 300
  Current RPM: 288          ← 实际斜坡转速，应接近目标
  Min RPM    : 30
  Ramp       : 80 RPM/s
  V_bus      : 23.8 V       ← 母线电压，应接近电源电压
  Iq set     : 1.50 A       ← 目标 Iq
  Id set     : 0.00 A       ← 目标 Id
  Current Kp : 0.2000
  Current Ki : 50.00
  Vq limit   : 12.0 V
  Ia,Ib,Ic   : 0.512 -0.234 -0.278 A   ← 三相电流瞬时值
  Id, Iq     : 0.030 1.420 A           ← 实际 D/Q 电流反馈
  Vd, Vq int : -0.051 2.340            ← PI 积分项 (反映稳态电压需求)
=============================
```

### 关键诊断线索

| 观察值 | 正常 | 异常及原因 |
|--------|------|-----------|
| Id 反馈 | 接近 0 (设了 olid 0 时) | Id 很大 → 角度不对或 Park 变换有偏 |
| Iq 反馈 | 接近 ol_iq_set | 差很远 → Kp/Ki 太小、电压限幅太小、或角度不对 |
| Vq_int | 稳态时应稳定 | 大幅振荡 → Ki 太大；一直顶在 vq_limit → 电压不够 |
| Ia+Ib+Ic | 接近 0 | 明显非零 → 零点偏移或采样有共模误差 |

## 10. V/F 模式备用

如果电流采样还没确认，可以切到纯 V/F 模式先验证硬件链路：

```text
olstop
olmode 0
olboost 1.0
olkvf 0.057
olvlimit 8
olramp 50
olspeed 100
olstart
```

V/F 模式不闭环电流，只按频率给电压：

```text
f_elec = ol_current_rpm / 60 × ol_pole_pairs   [Hz]
Vq = ol_v_boost + ol_kv_f × f_elec              [V]  (受限幅)
Vd = 0
```

适合：
- 先确认 PWM、相序、电角度方向能不能拖动电机。
- 隔离问题——如果 V/F 能转但电流模式不能转，问题一定在电流采样或电流环参数上。
- 不需要电流采样的应用场景。

## 12. 调试顺序建议

推荐按这个顺序走：

```
1. 确认 PWM 输出正常，TIM1 三相有波形
2. 确认串口命令能输入，olspeed 能打印状态
3. 确认 v_bus 显示正常
4. 确认静止时 Ia/Ib/Ic 接近 0
5. olmode 0 低压低速确认电机能被拖起来（验证相序/电角度方向）
6. olmode 1，oliq 0.5，低速试转
7. olspeed 观察 Id/Iq 反馈是否跟踪目标
8. 慢慢提高 Iq 和 speed
9. 最后再调 Kp/Ki，让电流跟随更稳
```

**调试黄金法则**：
- 一次只改一个参数，观察声音、温升、电流和转动状态。
- 每次改参数前先用 `olspeed` 记录当前状态，方便回溯。
- 不要同时改 Kp、Ki 和 Iq——改一个，观察，再改下一个。
- 调试时不要长时间低转速大 Iq 运行，热量会迅速积累。

## 13. Flash 持久化注意事项

参数通过 Flash (`easyflash`) 持久化。重要陷阱：

1. **结构体大小变化**：`MOTOR_PARAM_S` 加了新字段后，Flash 已有大小与代码中结构体大小不一致 → 自动写默认值覆盖 Flash。
2. **开发阶段覆盖块**：`motor_param.c` 末尾有个 `// TODO：调试使用` 覆盖块，强制把代码默认值写入运行时变量。**这意味着开发阶段改 `motor_param.c` 的默认值即可生效，不需要 `ef_set_env_blob`**。
3. **生产阶段**：去掉覆盖块，用 shell 命令调参 → `ef_set_env_blob` 写 Flash → 下次上电自动加载。

当前覆盖块覆盖的参数不全（只覆盖了开环参数，没有覆盖所有字段）。如果改了其他 Flash 持久化的字段（如电机电阻电感），需要确认是否也被覆盖块覆盖，否则可能被 Flash 旧值覆盖。
