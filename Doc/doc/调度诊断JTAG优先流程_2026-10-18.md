# 调度诊断：命令行控制，J-Link 读取

## 分工

- 启停、目标、参数和停机确认仍走串口命令行。保留必要的低频安全状态查询，不因改用调试器而取消。
- 调度统计和故障轨迹优先从冻结 RAM 读取；不在运行时输出长报表，不在高频中断中加入 RTT/printf。
- J-Link 使用现有 SWD 连接，只生成 connect/savebin/q。禁止运行中 halt、单步、断点或自动复位；调试器失联也不能代替硬件安全关断。

## 调度窗口

1. 停机后用 `slcadence task` 武装任务统计（最低干扰）。需要定位唤醒延迟与 DMA 重叠时改用 `slcadence probe`；它会增加目标 tick 附近的 DMA 计时开销。
2. 按原命令行流程启动并低速观察，保留必要安全查询；本改动不授权自动启动或升速。
3. 命令行停止电机、目标清零，并查询确认 OFF/目标 0。
4. 执行 `slcadence debug`。该命令只停止诊断累加、冻结280字节快照并返回一行说明；运行时拒绝执行。不要先执行 `slcadence stop`，否则快照 mode 反映的是已经关闭后的模式。
5. 运行主机脚本，例如：

```powershell
python Scripts/jlink_schedule.py --jlink 'D:\Users\15403\AppData\Local\Keil_v5\ARM\Segger\JLink.exe'
```

默认从当前 `F:\code\build\foc.map` 查找符号，输出到 `Doc/verify/jlink_schedule_*.bin/.json/.log`。可用 `--map` 与 `--output` 显式指定；map 必须对应板上固件，符号/ABI 检查不能证明固件身份。

## 证据与限制

- 当前版本3固定70个小端uint32（280字节）；magic/version/奇偶sequence/state校验，两次完整读取一致才输出结果。新武装立即使旧快照失效；重复debug保留原窗口和模式。旧版本1为188字节、版本2为256字节，本脚本不再读取旧ABI；必须先烧录配套新固件，下列历史结果仍保留原始版本。
- 快照包含任务最大间隔、PI 更新/未更新次数及间隔分布、各任务阶段最大耗时、最差唤醒窗口的 DMA 次数/函数体时间，以及 DMA/SysTick 抽样统计。
- 新增task_gap_bins：任务完成间隔≤1000/1100/1250/1500/2000/>2000us六档；首个完成点不计间隔。与PI间隔分布独立，速度PI关闭时仍可定位任务延迟。
- worst_task_gap保存最长完成间隔的完成序号、前后完成时间戳，以及这两次完成各自对应的唤醒探测；不再把全局最差唤醒和全局最长完成间隔误当成同一事件。只有wake.valid=1时该次DMA信息有效；完成间隔还包含任务执行与前一轮完成时刻的影响，不能全归因于当前唤醒。序号和时间戳均可32位回绕。
- 版本3在同一事件中增加阶段分解：before_wait_us为前次完成采样点至本轮阶段1；phase_us依次为阶段1→2等待、2→3位置路径、3→4速度路径、4→完成采样点的completion_snapshot。它们都是含中断抢占的墙钟时间，不是模块纯CPU自耗时；completion_snapshot不等于旧全局publish峰值，旧峰值结束于下轮阶段1。
- 仅完整顺序1/2/3/4且五段总和等于完成间隔时phase_valid=1；缺失、乱序、跨轮残留或异常时间顺序不会被解释为有效零耗时。主机另校验总和；无效时必须忽略阶段字段，不拿独立全局峰值补齐。
- mode bit0=任务模式、bit1=唤醒探测、bit2=性能计时、bit3=冻结前采集开启。冻结命令之前的停机和查询过程也可能进入统计窗口，不能当成严格的纯运行区间。
- task 模式不采 IRQ；probe 模式只额外探测唤醒窗口，不开启全程 IRQ 抽样。需要 IRQ 抽样时另做 `slcadence lean` 对照，不同时叠加所有诊断。
- IRQ stride=31，抽样 sum 不是全程总占用；SysTick 时间含抢占，不可与 DMA 时间直接相加。唤醒窗口的 DMA 函数体不包含异常出入栈，差值不能全部归因于调度器。
- 各项最大值未必属于同一次事件；PI 关闭时零更新不代表调度正常。当前统计不能替代逐事件轨迹或实际轴速测量。
- 版本2在任务完成路径增加六档计数、前次唤醒保留及新峰值事件复制，仅诊断开启时执行；有额外开销，但未新增DMA/SysTick插桩，不扩大高频轻量轨迹使用的任务快照结构。SWD读SRAM也不保证零总线干扰，因此本脚本只用于停机后读取。
- 版本3复用既有阶段调用的时间戳，不新增读时钟或高频ISR采样；阶段链在任务路径独立存储，只在新最长间隔时计算并保存分解。仍有记录开销，需实机对照。
