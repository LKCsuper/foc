## 已实现

- 新增 `motor_settings.c/h`：独立 config/calibration 快照、显式字段映射、固定 216-byte 小端编码、合法性检查；不依赖 STM32/FreeRTOS。
- 固定格式使用 IEEE754 binary32 与 32 位整数编码，霍尔表按 8 个无符号字节保存；包括 128..200 的原有表编码。未重构原 int8_t 霍尔表读写接口。
- 检查有限数值、整数极对数 1..255、基本正负范围、频率关系、霍尔表 0..200/255 和额外采样次数 0..32。板级 ADC 上限及所有工况限制尚不属于此通用校验。
- Flash v2 使用独立 payload、长度、CRC 与双槽提交，不持久化 enable、目标电流/速度、采样或积分。校验失败的槽（包括语义无效）不参与选择。
- v1 不自动迁移/擦除；加载失败采用默认配置。上电不再自动保存默认值，明确保存才写 Flash。
- 初始化先清默认对象并建立完整默认状态，再应用有效配置/校准，避免加载陈旧实时状态。遗留 `e_iq_set` 现在也获得声明的默认值 1.5 A；主 ISR 使用 `ol_iq_set`，未改其 0.3 A 默认值。
- 当前开发策略保持：控制配置仍采用代码默认值，已保存校准及 hall_extra_samples 恢复。用整体 config 赋值代替逐字段覆盖长列表。
- 保存入口拒绝运行及校准占用；接口仍要求调用者串行执行，尚未实现跨任务完整存储互斥。
- 已在 Keil 工程加入新源文件；测试工具、缓存和产物放 `.build/` 并忽略，不提交二进制依赖。

## 静态控制基线

| 项目 | 核查结果 |
| --- | --- |
| 主入口 | DMA2 Stream4 → BSP handler → Motor_DmaInt；根据 ADC 通道分支处理 HT 或 TC |
| 分频 | ADC 每拍保护，FOC_CONTROL_LOOP_FREQ_DIVIDER=2；配置推算 ADC 30 kHz、FOC/PWM 15 kHz，未实测 |
| 默认命令 | 初始化 enable=false；默认目标 500 RPM，随后开机偏移校准将目标清零 |
| 默认模式 | I/F、Iq=0.3 A、PI=0.2/30、对齐 0.5 A/0.3 s；HFI 开，观测器开，接管/速度环关 |
| 保护配置 | 10 A/0.1 ms 过流、8 V/0.1 s 欠压；速度保护依赖有效反馈，均为代码值 |
| 中点输出 | 三相 period/2 并 COM 提交；不等于输出禁用或保证无转矩，代码行为本轮保留 |
| PwmStop | 强制主通道无效、关闭互补通道并 COM 提交；实际门极电平须结合板级极性验证 |
| 硬件 Break | BSP 受 HW_USE_BRK 宏控制；当前搜索到的项目头未定义该宏，不能宣称已启用硬件关断 |
| 偏移校准 | active 时 ISR 提前返回，逐相校准，结尾 PwmStop 并清 active；期间软件保护覆盖不足，需后续按校准工况补齐 |
| 学习路径 | main 调用 Motor_Simple_BldcInit 仅设置其学习参数；主 ISR 不使用该路径 |
| 遗留入口 | Motor_Ctrl_OpenLoop/OpenLoop1 未发现外部 C 调用；Motor_PidControl 空实现，无外部 C 调用 |
| 传感器 | 编码器和霍尔标定已有；正常主角度入口仍是开环/无感选择，完整有感链路待接入 |
