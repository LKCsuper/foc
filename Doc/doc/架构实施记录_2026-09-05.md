## 已实现

- 新增 `motor_settings.c/h`：独立 config/calibration 快照、显式字段映射、固定 216-byte 小端编码、合法性检查；不依赖 STM32/FreeRTOS。
- 固定格式使用 IEEE754 binary32 与 32 位整数编码，霍尔表按 8 个无符号字节保存；包括 128..200 的原有表编码。未重构原 int8_t 霍尔表读写接口。
- 检查有限数值、整数极对数 1..255、基本正负范围、频率关系、霍尔表 0..200/255 和额外采样次数 0..32。板级 ADC 上限及所有工况限制尚不属于此通用校验。
- Flash v2 使用独立 payload、长度、CRC 与双槽提交，不持久化 enable、目标电流/速度、采样或积分。校验失败的槽（包括语义无效）不参与选择。
- v1 不自动迁移/擦除；加载失败采用默认配置。上电不再自动保存默认值，明确保存才写 Flash。
- 初始化先清默认对象并建立完整默认状态，再应用有效配置/校准，避免加载陈旧实时状态。遗留 `e_iq_set` 现在也获得声明的默认值 1.5 A；主 ISR 使用 `ol_iq_set`，未改其 0.3 A 默认值。
- 当前开发策略保持：控制配置仍采用代码默认值，已保存校准及 hall_extra_samples 恢复。用整体 config 赋值代替逐字段覆盖长列表。
- 保存入口拒绝运行及校准占用；接口仍要求调用者串行执行，尚未实现跨任务完整存储互斥。
- 已在 Keil 工程加入新源文件；测试工具、缓存和产物放 `.build/` 并忽略，不提交二进制依赖。
