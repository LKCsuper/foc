# Hall FOC 空载 3000：电流原理与使用边界

> 2026-09-20 晚。BM75 / STM32F405RG，ATK-BL57H95D20E，24 V，空载，Hall + I/F，弱磁 0 A。COM20，SWD 100 kHz 烧录，不要芯片擦除。
>
> 这篇把换 VESC `foc_svm` 之后、空载爬到 3000 的测试和原理收在一起：看起来 1～3 A 的电流是什么、观测器要不要上、现在能不能当 Hall 速度闭环用。
>

口头说的 **oldriver** 即 ODrive。本机 2 对极。

## 1. 先说结论

**不用观测器，空载 Hall 速度闭环现在可以正常用。** 从 150 起转，速度环斜坡到 3000，能停干净。观测器不是这条路径的前置条件。

| 问 | 答 |
|----|----|
| 空载 150～2500 | 真到目标 |
| 空载 3000 | 约 2960～3040，电压约 10.2 / 13.8 V，没顶满 |
| 平均 Id | 全程 ≈ 0 A，速度环要的 Iq 约 0.3～0.56 A |
| 快照上看到的 1～3 A | **D 轴交流峰值**，不是持续三相真流 |
| 重构 | 门槛收到 ARR−500 后，空载 3000 命中 0 |
| 弱磁 / CCR 倍率 | 不要开、不要加回去 |
| 观测器 | 现在不必。Hall 验证一直 `slenable 0` |
| 带载额定 6.6 A / 带载 3000 | **没测**。`spiq` 还只有 0.8 A，弱磁仍关 |

日常组合见手册 [4.9](./命令行使用手册.md)。手打顺序就是脚本发出去的那套：`olfb hall`、`slenable 0`、`olkp 0.12` / `olki 18`、`spkp 0.006` / `spki 0.003` / `spiq 0.8`，**先 `olspeed 150` 再 `olstart`**，然后只改目标。

## 2. 今晚测到的数

台架：分流 0.5 mΩ × INA240A1 增益 20，`FAC_CURRENT ≈ 0.0806 A/count`。电流环 15 kHz。Hall 角每 4 拍更新一次。插值 150 RPM 以下钉扇区中心，300 RPM 以上满插值。I/F Hall 路径**不加** `ωψf` 前馈。

### 2.1 转速与电压

对齐 `foc_svm` 之后（CCR 中点 ARR/2=2800，`PWM ideal` 接近 `|Vd,Vq|`）：

| 目标 | 实测 | `|V|` / Vlim | 说明 |
|------|------|--------------|------|
| 150 | 153～157 | 0.59～0.75 / 13.8 | 必须先过这一档 |
| 2000 | 2009 | 约 6.8 / 13.8 | |
| 2500 | 2500 | 约 8.6 / 13.8 | 真到目标 |
| 3000 | 2961～3041 | 约 10.2 / 13.7 | ±10% 脚本过；有时 ±1.3% |

日志：[SVM 首过 3000](../verify/hall_verify_ed43d8a7-dirty_20260920-162848_3000RPM.log) · [mean 固件 150](../verify/hall_verify_e6e4cdde-dirty_20260920-194246_150RPM.log) · [mean 固件 150→3000](../verify/hall_verify_e6e4cdde-dirty_20260920-194519_3000RPM.log)。

### 2.2 直接 `olspeed 3000` 曾锁 `MOTOR_SPEED_LOSS`

在大约 150 运转中直接把目标改成 3000，旧保护拿**实测去比目标**，斜坡还没到 3000 就当丢速。

改成和 VESC 同类：速度给定按 `25000` ERPM/s（本机约 **12500 RPM/s**）爬；`olramp` 只给 I/F / V/F 开环，保留命令但 Hall 速度环不用。斜坡未到位不算失速；跟上之后若曾到目标 50%、再跌破 20% 持续 0.3 s 才锁。加速卡在 `spiq 0.8`。

### 2.3 重构 900 会在空载 3000 误触发

VESC `vesc_foc.c` 门槛是 **ARR−500**；`mcpwm` 的 900 更早改写。空载 3000 峰值 CCR 约 4864～4902：

| 门槛 | 150 重构 | 空载 3000 重构 |
|------|----------|----------------|
| 900 | 0 | 约 5.9%（A/B/C 均匀） |
| **500** | 0 | **0 / 21 万拍** |

收到 500 后 `|Id|>1 A` 的比例几乎没变（约 34%→36%），所以高速差模 Id **不是重构改出来的**。带载窗口真短于约 3.0 µs 时仍会改写。

### 2.4 换向窗对不上「只在边沿毛刺」

`olcurdiag` 把 Hall 分频冻结窗（边沿年龄 < 0.15 ms）和扇区内部拆开。mean 固件 150→3000：

| 转速 | 换向窗 `|Id|>1` | 扇区内部 `|Id|>1` |
|------|----------------|------------------|
| 150 | 0.7%～1.0% | 0.03% |
| 1800 | 5.6% | 4.4% |
| 2500 | 28% | 19% |
| **3000** | **42%** | **36%** |

换向前一拍电流已经偏大。电角几乎在扇区中心（曾经 `ddeg=1.3°`）时 Id 仍约 0.94 A。所以不是「只在霍尔换向那一拍」。不要靠加密 Hall 更新或丢掉换向拍来修。

### 2.5 mean / RMS：1～3 A 是交流

`olcurdiag` 对**每一拍**累加（不是 1/16 抽样）：

| 转速 | mean Id | mean Iq ≈ IqT | mean \|Id\| | rms Id | rms I |
|------|---------|---------------|-------------|--------|-------|
| 150 | 0.000 | 0.34 | 0.23 | 0.28 | 0.45 |
| 300 | 0.000 | 0.29 | 0.10 | 0.13 | 0.33 |
| 800 | 0.000 | 0.35 | 0.21 | 0.25 | 0.43 |
| 1200 | 0.001 | 0.40 | 0.30 | 0.35 | 0.54 |
| 1800 | 0.001 | 0.45 | 0.39 | 0.50 | 0.68 |
| 2000 | 0.001 | 0.47 | 0.38 | 0.51 | 0.70 |
| 2500 | 0.002 | 0.51 | 0.60 | 0.74 | 0.92 |
| **3000** | **0.004** | **0.56** | **0.86** | **1.04** | **1.22** |

3000 快照可以是 `Id/Iq = −0.20 / 0.33 A`、三相只有零点几安；最差一拍才到 `Id = −3.2 A`。Vd 积分从约 0 V 走到 **−2.5 V**，幅值大致跟转速成正比。mean Ia/Ib/Ic 只有零点零几安量级，不是三路一起偏了 1 A。

判读：

- **mean Id ≈ 0** → 不是固定 Park 偏 30°，也不是一直在弱磁。
- **mean Iq ≈ IqT** → 速度环要的转矩电流是真的，采样比例在 150 和 3000 上自洽。
- **rms Id 随转速涨** → 交流，频率跟电角 6 次谐波走。
- 快照 1～3 A 是这个交流的峰值，不是「空载在吃 1～3 A 有效电流」。

## 3. 原理

### 3.1 三种电流不要混

| 看到的量 | 空载典型 | 进不进 Id | 怎么处理 |
|----------|----------|-----------|----------|
| `Ia+Ib+Ic` 峰值 1.4 A | 各转速都有 | 完整 Clarke 丢掉相等共模 | 遥测，不跳闸 |
| 速度环 Iq | 0.3～0.56 A | 就是 q 轴 | 空载该有的 |
| rms Id、峰值 1～3 A | 1800 以上明显 | 差模，进 Id | 霍尔角 6 次谐波，见下 |

电源面板空载母线大约 0.22 A（约 5 W）。分流器上 1.5 A 级三相和比真实母线电流大一个数量级，不能当成电机在吃那么多。

### 3.2 为什么高速会有交流 Id

霍尔每个电周期只有 **6 个真点**。300 RPM 以上已经在用邻扇区半宽插值，但：

1. 真点之间的角是用 `ω × 边沿年龄` 推的，扇区不等分、测速滞后都会剩下一小段角度误差。
2. Hall 状态每 **4 个电流拍** 才更新一次。3000 RPM 时电角频率 100 Hz，4 拍约 0.27 ms，转子继续走约 **9.6°**，Park 角这段是冻住的。
3. 反电势大约 10 V 量级。角度误差 δ 时，D 轴看到约 `ωλ·sin(δ)`。6 次谐波在 3000 时是 **600 Hz**。
4. 电流环 `olkp 0.12`，带宽大约几十赫，跟不上 600 Hz。PI 积分会走出一个随转速变大的直流 Vd（实测 −2.5 V），**平均 Id 仍被压在 0**，交流 Id 留下来。

所以：`|Id|>1 A` 的样本占比随转速升到 36%，和「平均直轴电流 1 A」不是一回事。

### 3.3 已经排除的

- **采样比例**：ADC 相对零偏几十个计数 × 0.0806 A/count，和相电流安培数对得上；150 的 Iq 也跟目标对得上。
- **Clarke**：`Iα = 2/3 Ia − 1/3 Ib − 1/3 Ic`。三相和进不了 Id。
- **30° Park 偏置**：mean Id 会离开 0，实测没有。
- **重构**：500 后空载 3000 命中 0，Id 交流还在。
- **只在换向拍**：扇区内部 36% 同样越界。
- **SVM 极性**：不取反时 150 的 Id 跑到 −12 A（正反馈）。取反后 150 稳定，极性是对的。不要改 A-C-B。
- **弱磁 / CCR**：空载电压没顶满；CCR 倍率已经证明会把低速电流环绑死。

### 3.4 铭牌反电势不要直接拿来要求弱磁

铭牌 Ke 6.6 V/kRPM 线间 RMS，3000 RPM 折合相峰值大约 16 V，大于软件 `Vlim ≈ Vbus/√3 ≈ 13.8 V`。空载实际 `|V|` 只有约 10.2 V 就转到了，说明空载 Iq 小、角度也不是理想 q 轴。**不能据此说空载 3000 必须弱磁。** 带载 IR、`ωLI` 上去，电压会先顶满。

## 4. 插值和观测器

两件都不是今晚必须做的。插值**已经有了**，上面的交流 Id 就是插值全开时测到的。

| | 现在 | 要不要再做 |
|--|------|------------|
| Park 电角 | 邻扇区半宽 + `ω × 年龄`；&lt;150 钉中心 | 不必再写一套。若要压交流，才考虑每拍更新角，或 Park 改用 Hall-PLL 位置 |
| 速度环 | &lt;200 RPM 用 Hall-PLL，高了改回六边沿 | PLL 位置目前**不**给 Park |
| 观测器 | `sltakeover` 默认关；代码是 **I/F → 无感** 渐变 | 现在不必。VESC 的 Hall 模式也是插值跑全程，不是到 3000 就切无感 |

Hall 6 扇区消不掉全部 6 次谐波。观测器能把高速角做连续，但是另一条产品路径：参数、锁定、失锁回退，还得从 150 重新验。空载 `rmsI ≈ 1.2 A` 对霍尔 FOC 可以先接受。

## 5. 现在可以怎么用，哪里还不能当验收

**可以：** 24 V 空载或很轻的负载；Hall 表有效；从 150 起；`spenable 1`；目标用 `olspeed` 让斜坡走；弱磁保持 0。保护仍是相电流峰值 10 A、脚本空载 `√(Id²+Iq²) > 2.5 A` 或母线 &lt; 22 V。

**不要当成已经验收：**

- 带载额定扭矩 / 6.6 A。速度环 `spiq 0.8 A` 会先顶满，转速掉下去。
- 带载 3000。弱磁仍关，电压顶满后到不了铭牌转速。
- 停机直起 72 RPM。以前就不稳，日常从 150 起。
- 编码器 / V/F。仍是 `svm_hqd`，和 Hall 这条调制不是一套。
- 整片擦除。会清掉 Hall 表和电流零偏。

速度环 `spkp/spki/spiq` 不写 Flash，重启后回到代码默认，手打或脚本每次都要设一遍。

## 6. 怎么复测

```text
Scripts/hall_build_flash_verify.ps1 -Port COM20 -SwdSpeedKhz 100 -Profile up -MaxRpm 150 -Samples 1
python Scripts/hall_verify_serial.py --port COM20 --profile up --max-rpm 3000 --samples 1
```

`olsnap`：`Enable ON`、`Fault CLEAR`、CCR 中点约 2800、`PWM ideal` 接近 `|Vd,Vq out|`、`Reconstruct` 空载 3000 应为 `hits=0`。

`olcurdiag`：看 `mean` 那两行。mean Id 应接近 0，Iq 接近 IqT；rmsI 随转速涨是预期，不是过流。`id_over` 只告警。

UART 无响应：SWD 100 kHz 重烧，不要芯片擦除。
