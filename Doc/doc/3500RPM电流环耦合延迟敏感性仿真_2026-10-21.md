# 3500 RPM 电流环耦合/延迟敏感性仿真

补充限制：本文电气模型在旋转 dq 中保持输出，不等价于实际每拍静止 alpha/beta 矢量保持。其“延迟未单独造成失控”不能推广到包含机械自由度和真实电压保持时序的系统；后续对照见 `IF机械动态与PWM保持敏感性_2026-10-21.md`。

## 模型与复现

纯主机脚本 `Scripts/simulate_current_loop.py`，没有控制板操作，不修改真实增益或保护。参数固定 R=0.474 Ω、L=0.112 mH、磁链 2.390 mWb、7 极对、3500 RPM、15 kHz、Kp=0.12、Ki=18、限幅 8.5 V。PI 更新和单轴/矢量限幅抗饱和顺序与当前代码一致。

采用以强制角速度 ω 旋转的 dq 电气方程：

```
L*dId/dt = Vd - R*Id + ωL*Iq - Ed
L*dIq/dt = Vq - R*Iq - ωL*Id - Eq
```

以 Id=0、Iq=1 的平衡点起步，初始转子磁链与强制 d 轴相差 π/2。反电势为 `Ed=-ψ*(ω+δ_dot)*sin(δ)`、`Eq=ψ*(ω+δ_dot)*cos(δ)`；δ 在 20 ms 时开始，按 20 ms 半余弦过渡人为减小 0、0.25、0.5、1、1.5、2 rad。幅值同时考虑规定角轨迹的相对转速，避免角度变化却遗漏反电势速度项。

注意：角轨迹是外部规定的扰动，不是由机械方程求出，也不是编码器实测转子轨迹。模型没有惯量、摩擦、负载、磁饱和、真实采样窗、ADC 量化、死区及实际延迟波形。不能据此预测实际失步速度或直接确定新增益。

为排除因素，分别打开/去掉 ωL 耦合；去耦合组是人为对照，不表示真实高速电机没有耦合。比较反馈/输出延迟 0/0、1/0、0/1、1/1、2/2 个控制周期；2/2 意味着两项各 133.3 µs。额外以初始 Id=0.05 A、无角扰动测试小扰动稳定性。

电气积分使用每控制周期八个 RK4 子步；控制输出零阶保持，延迟队列先填充平衡值。每个控制周期计算平衡三相电流峰值，按 10 A、1 ms 进行仿真保护，触发则终止，不模拟保护后继续失控。总计 63 个组合。

## 结果

以下为保留耦合组的控制周期采样相电流峰值，不是硬件实测：

| 人为相对角变化 rad | 无额外延迟峰值 A | 反馈/输出各延迟两拍峰值 A |
| --- | ---: | ---: |
| 0 | 1.00 | 1.00 |
| -0.25 | 1.08 | 1.09 |
| -0.5 | 2.91 | 2.93 |
| -1.0 | 6.46 | 6.49 |
| -1.5 | 9.57 | 9.62 |
| -2.0 | 11.56，触发保护 | 11.53，触发保护 |

Id=0.05 A 小扰动组在延迟 0/0～2/2 时均衰减，峰值低于 1.1 A，没有过流。平衡点无扰动组本身保持不动，不能仅凭这一组声称稳定性，因此另加小扰动检查。

同样 -0.5 rad 角扰动，无耦合 Id 最小约 -1.02 A，保留耦合约 -2.13 A；-2 rad 时保留耦合组 Id 可达约 -11.52 A，呈现类似实测的强负向 Id 形态。这仅说明这类扰动能够产生相近现象，不是对真实起因的辨识。大扰动导致保护后提前停止，不同组的极值不代表同一时刻。

## 可以与不能得出的结论

- 在本模型和参数范围内，单独增加到两拍采样延迟加两拍输出延迟，没有造成自发失控；不支持立即把正常固定延迟认定为这次唯一根因。
- 相对角偏移与 dq 耦合能显著改变电流，故障形态具有这种敏感性；但角漂移被人为输入，不能据此宣称“已证明机械失步”。
- 没有解释真实相对角为何持续变化。实际机械扰动、I/F 同步稳定性、参数/比例误差与异常延迟仍需分别验证，也不能排除模型外的偶发采样错误。
- 不凭这轮仿真提高 Ki、PLL 增益或过流阈值，不清故障重跑高速。
