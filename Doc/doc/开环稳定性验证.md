# 开环稳定性验证

> 更新日期：2026-09-08
> 对象：BM75 + 当前固件，**角度开环**（V/F / I/F）。本轮不验证霍尔、编码器闭环、速度环、无感。
> 命令：`Doc/doc/命令行使用手册.md`。IO：`Doc/sch/BM75_IO定义.md`。

## 怎么用

1. 按 V0 → V11 做（V12 可选）。全程保持：`olalign 0`、`hfistart 0`、`olfb openloop`、`spenable 0`、`slenable 0`。切模式先 `olstop`。不要用 `duty`。
2. 每一项：先跑给出的命令，再把**串口原文**贴进「粘贴输出」。轴转没转串口看不到，在「轴/听感」写一句。
3. **不要自己勾达标。** 把填好的文档或对应段落发回对话，由我对照判据填「审核」和文末总表。
4. `olstatus` 的 `Current RPM` 是软件斜坡，不是轴转速。失步只能靠轴/声音判断。

判据摘要（审核时用）：

| 项                   | 达标要点                                                                       |
| -------------------- | ------------------------------------------------------------------------------ |
| 停机                 | Enable=OFF，Fault=CLEAR，V_bus 接近电源，三相电流约 0 A，ADC raw 约 1000～3000 |
| V/F                  | 轴单方向连续转；Fault=CLEAR；Current RPM 能爬向目标；母线不塌                  |
| I/F 建流（约 0.8 s） | 轴几乎不动或不剧摆；Current RPM≈0；Id 向目标爬且不是 −几安；Vd/Vq int 未顶死 |
| I/F 拖转/稳速        | 轴单方向匀转；Iq≈设定；Id≈0；Fault=CLEAR                                     |
| 变速/反转            | 斜坡走完后轴跟随；不晃、不过流                                                 |

安全：空载；电源约 24 V，第一次限流 **3 A**；过流软件阈值相电流峰值 ≥ **10 A** 约 1 ms；第一次 `oliq 0.6`。`olstop` 是 PWM 中点，不是关桥。
