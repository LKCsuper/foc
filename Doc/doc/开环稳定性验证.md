# 开环稳定性验证

> 更新日期：2026-09-10
> 对象：BM75 + 当前固件。正文验证**角度开环**（V/F / I/F），另含独立的霍尔稳定性验证；暂不验证编码器闭环和无感。
> 命令：`Doc/doc/命令行使用手册.md`。IO：`Doc/sch/BM75_IO定义.md`。

## 怎么用

1. 按 V0 → V11 做（V12 可选）。全程保持：`olalign 0`、`hfistart 0`、`olfb openloop`、`spenable 0`、`slenable 0`。切模式先 `olstop`。不要用 `duty`。
2. 每一项：先跑给出的命令，再把**串口原文**贴进「粘贴输出」。轴转没转串口看不到，在「轴/听感」写一句。
3. **不要自己勾达标。** 把填好的文档或对应段落发回对话，由我对照判据填「审核」和文末总表。
4. `olstatus` 的 `Current RPM` 是软件斜坡，不是轴转速。失步只能靠轴/声音判断。
5. 串口带上电时基：提示符 `[T+12.345s] $ `，回车后 `[T+12.500s] > 命令`，`olstatus` 页头有 `Uptime`。截图请带上这几行，两项间隔用 `T+` 相减即可。下面「粘贴输出」来自 COM17 自测，已带时基；台账里的 `f024406` 当时还没有时基。完整串口原文保存在 `Doc/verify/`（文件名 `ol_verify_<提交短哈希>_<YYYYMMDD-HHMMSS>.log`，可提交）。
6. 2026-09-08 的问题、原因和固件改法见下文「发现问题与处理」。文末总表是改之前那一轮，烧新固件后另开台账复测。
7. 串口脚本 `Scripts/ol_verify_serial.py`：默认证完整 V0～V11。单测一项：`python Scripts/ol_verify_serial.py --only V9`（可 `V4,V5` 或 `4,9`）。`--list` 看项。`--port COM17`。单测会先做 V0 关闭环，再起该项所需的最小步骤；结束时 `olstop`。`olstart` 之后会打印 `wait Ns`。运行中抓电流用 `olsnap`（短快照），不要用完整 `olstatus`。`olsnap` 必须打完并 `Flush`；命令任务空闲也会轮询 UART TX DMA，避免 300 RPM 下第一段发出后整页卡死。日志在 `Doc/verify/`。串口工具占用 COM 时不要同时跑。无完整页尾和 `Id, Iq` 会判失败。

判据摘要（审核时用）：

| 项                   | 达标要点                                                                       |
| -------------------- | ------------------------------------------------------------------------------ |
| 停机                 | Enable=OFF，Fault=CLEAR，V_bus 接近电源，三相电流约 0 A，ADC raw 约 1000～3000 |
| V/F                  | 轴单方向连续转；Fault=CLEAR；Current RPM 能爬向目标；母线不塌                  |
| I/F 建流（约 0.8 s） | 轴几乎不动或不剧摆；Current RPM≈0；Id 向目标爬且不是 −几安；Vd/Vq int 未顶死 |
| I/F 拖转/稳速        | 轴单方向匀转；Iq≈设定；Id≈0；Fault=CLEAR                                     |
| 变速/反转            | 斜坡走完后轴跟随；不晃、不过流                                                 |

安全：空载；电源约 24 V，第一次限流 **3 A**；过流软件阈值相电流峰值 ≥ **10 A** 约 1 ms；第一次 `oliq 0.6`。`olstop` 是 PWM 中点，不是关桥。

## 2026-09-08 发现问题与处理

对象：BM75 + ATK-BL57H9，空载 24 V。记录固件 `f024406`（无时基）手测 + 随后带时基的 COM17 自测（日志 `Doc/verify/ol_verify_f0244064_20260908-221916.log`）。文末总表是**该轮**审核，不是改完后的结论。

### 现象

| 问题 | 证据 | 原因 |
| ---- | ---- | ---- |
| I/F 运行时 `Theta` 不动 | 停在 −1.336 rad，同时 TIM1 CCR 在变 | 角度积分写 `ol_theta`，`olstatus` 读 `motor.theta`，I/F 路径从不回写 |
| 300 RPM 电流跟踪差 | 自测 Id/Iq≈1.12/1.53（给定 0/0.60）；后续 21 点快照显示 Id/Iq 随电角强烈波动 | 旧 `svm_hqd` 的 β 分量调制增益只有 α 轴的一半，在 dq 中形成二倍电角电流纹波；不是 PI 平均值跟不上，也不应在 I/F 开环角上加 `ωψf` |
| 低速 Iq 在 0.26～0.63 晃 | V6 四次快照 | 齿槽 + `olstatus` 瞬时值；不是 Theta 显示 bug。V6 自测无轴观察 |
| 运行中直接 72↔−72 过零发慌 | 手测听感 | `olspeed` 只改目标，斜坡过零时 Iq 仍在 |
| `olalign 0` 时轴不自起，手拨一下才转 | `--only V9` 复现 | 未开对齐仍走 0.8 s 定角灌 Id，转子被吸进齿槽；随后 10 RPM/s、0.6 A Iq 拖不动 |

低速 I/F（72 / 150 RPM）能拖转、能反转、无过流锁存。V/F 72 RPM 轴连续转。未达「开环稳定」全项。

### 固件处理（须重新烧录后再测）

1. **状态电角**：`Motor_Control_Step` 在 `OUTPUT_DQ` 时把本拍 Park/PWM 角写回 `motor.theta`。`Theta/CCR` 应一起变。实现：`App/motor/motor_control.c`。
2. **电流前馈**：`ωe·ψf` 只属于转子 dq。开环 I/F 的 Park 角不是转子角，**不再**在 I/F 路径叠加该前馈（两种符号都已在 300 RPM 上证伪：Iq 0.17 A 或 Id/Iq≈1 A）。函数 `Motor_Current_ApplySpeedFeedforward` 保留给有感。不改 Kp/Ki。
3. **反转**：运行中 `olspeed` 改符号会拒绝，提示先 `olstop`。实现：`App/cmd/cmd_openloop.c`。手册已同步。
4. **未开对齐的起步**：`olalign 0` 时跳过 `CURRENT_RAMP` 定角灌 Id，同一拍进入拖转，只按比例爬升 Iq。实现：`App/motor/motor_control.c`。
5. **SVPWM 双轴等增益**：旧 `svm_hqd` 的 β 项在时间合成中少一倍，导致 α/β 增益比为 2:1。将 `X/Y/Z` 中的 β 分量系数统一乘 2，保留已验证的扇区、整体极性和 A-C-B 映射。实现：`App/motor/motor_foc.c`。
6. **开环 ISR 减负**：`olfb openloop` 时不再于每个 30 kHz ADC 中断更新未选用的编码器/霍尔，保留电流采样与过流保护，避免串口命令任务在约 90% ISR 负载下被饿死。实现：`App/motor/motor_it.c`。

未改：电流环增益、极对数、相序映射、过流阈值。V6 齿槽顿挫仍靠轴/听感判断。

### 烧录后怎么复测

仍按本文 V0→V11。重点：

- V5/V6/V8/V9：`Theta` 是否在变；Id≈0、Iq≈0.60；Fault=CLEAR。**72 RPM 应能自起，不要靠手拨。**
- V9 300 RPM：Iq 应回到约 0.60 A；不要靠 I/F 开环角上的 ωψf。若 Id、Iq 都到 1 A，按失步查。
- V11：先停再反；运行中直接 `olspeed -72` 应被拒绝。

串口原文仍写入 `Doc/verify/ol_verify_<短哈希>_<YYYYMMDD-HHMMSS>.log`。

原理说明见 [开环电流环调试说明](./开环电流环调试说明.md) 第 5、6、9 节。

## 霍尔稳定性验证（脚本）

本节与 V0～V11 开环台账相互独立。验证对象是：已标定霍尔表、霍尔电角反馈、边沿周期测速、多边沿滤波和速度 PI。脚本不会自动执行 `detect hall`，也不会写 Flash。

### 前置条件

1. 空载，轴可自由旋转，24 V 电源第一次限流 3 A。
2. 已使用当前固件成功执行 `detect hall`，六个有效角度沿一圈分布，随后执行过 `saveparam`。
3. `olsnap` 必须包含 `Ramp RPM`、`Meas RPM (...valid)` 和 `Hall RPM: raw=... filtered=... age=... state=...`。缺少这些字段表示固件过旧。
4. 串口工具不要同时占用同一 COM 口。出现抖动、异响、失控加速或过流时立即 `olstop`。

### 一键验证

COM15 完整验证 150→300→500→800 RPM：

```powershell
python Scripts/hall_verify_serial.py --port COM15
```

只验证到某一档：

```powershell
python Scripts/hall_verify_serial.py --port COM15 --max-rpm 300
```

每档默认采 3 张快照，可调整：

```powershell
python Scripts/hall_verify_serial.py --port COM15 --max-rpm 800 --samples 5
```

日志默认保存到：

```text
Doc/verify/hall_verify_<提交短哈希>_<YYYYMMDD-HHMMSS>_<最高转速>RPM.log
```

脚本固定配置：I/F 电流环 `Kp/Ki=0.2/30`，速度环 `Kp/Ki=0.006/0.003`，`spiq=0.8 A`，`spbrake=0`，启动 Iq=`0.6 A`，斜坡 `50 RPM/s`。速度 PI 的接管门槛取“启动转速的 50%”与“当前斜坡转速的 50%”中的较大值；门槛以下保留启动 Iq，并持续复位速度 PI，防止未使用的积分项在后台饱和。达到门槛后 PI 才开始无积分历史地接管；运行中失速跌回门槛以下会自动恢复启动转矩。150 RPM 首档等待 10 秒供低速积分稳定。运行中逐级修改 `olspeed`，不会重复 `olstart`；任何自动判定失败都会执行 `olstop`。

### 自动判据

| 档位 | 滤波转速允许误差 | 其他必需条件 |
| ---- | ---------------- | ------------ |
| 150 RPM | ±25% | Hall valid；state=1～6；age<200 ms；Fault=NONE |
| 300 RPM | ±15% | 同上 |
| 500 RPM | ±15% | 同上 |
| 800 RPM | ±15% | 同上 |

`raw` 是把最近单个边沿固定按 60°电角换算的瞬时速度，受齿槽、霍尔安装位置和转矩纹波影响，允许明显波动；`fast` 按霍尔标定表的实际扇区角差换算并低通，且在边沿迟到时按边沿年龄主动降速，供速度 PI 使用；`filtered` 使用最近 6 个合法边沿的总时间计算，供稳态显示和脚本审核。`Meas RPM` 是速度 PI 当前使用的反馈，霍尔模式下等于 `fast`；`Ramp RPM` 只是斜坡后的当前指令。
