# Hall 提速：CCR、母线电压与弱磁

> 原名单「FOC 弱磁」。2026-09-20 晚间按 VESC 对齐收口：Hall 电流环改为 `foc_svm`（中点 ARR/2），去掉 CCR 倍率。空载 **150→3000 RPM** 脚本通过；弱磁仍关。`fw` 命令见第 6 节。
>
> 配套：[对齐 VESC SVM](./Hall_对齐VESC_SVM_2026-09-20.md) · [电机铭牌](../../App/motor_param/inc/motor_nameplate.h) · [motor_fw](../../App/motor/motor_fw.c) · [命令行使用手册](./命令行使用手册.md) · [Hall FOC 提速调试经验](./Hall_FOC提速调试经验_2026-09-17.md) · [Hall 偶发 Id 毛刺](./Hall偶发Id毛刺_2026-09-19.md) · [1500 RPM 原因](./Hall_1500RPM达标原因与限制_2026-09-16.md)

口头说的 **oldriver** 即 ODrive。本机 2 对极、铭牌 24 VDC / 3000 RPM。COM20，SWD 100 kHz 烧录，不要芯片擦除。

## 1. 现在停在哪

BM75 / STM32F405RG，24 V，空载，Hall + I/F，`spiq 0.8`，`MOTOR_HALL_USE_VESC_SVM = 1`，`olkp 0.12` / `olki 18`，`fw_current_max = 0`。

| 目标 | 结果 | `|V|` / Vlim | CCR | 日志 |
|------|------|--------------|-----|------|
| 150 RPM | **通过**（153 / 149 / 163） | 0.59～0.67 / 13.8 | 中点 2800 | [150](../verify/hall_verify_ed43d8a7-dirty_20260920-162155_150RPM.log) |
| **2000 RPM** | **通过**（2009 / 1974） | 约 6.8 / 13.8 | 峰值约 4124 | [2000](../verify/hall_verify_ed43d8a7-dirty_20260920-162355_2000RPM.log) |
| **2500 RPM** | **通过**（2500.1 / 2500.2） | 约 8.6 / 13.8 | 峰值约 4511 | [2500](../verify/hall_verify_ed43d8a7-dirty_20260920-162613_2500RPM.log) |
| **3000 RPM** | **脚本通过**（2961，±1.3%） | 10.3 / 13.7 | 771～4828 | [3000](../verify/hall_verify_ed43d8a7-dirty_20260920-162848_3000RPM.log) |

`PWM ideal` 现在与 `|Vd,Vq|` 一致，说明请求已经送到电机端。3000 时空载 `Speed Iq=0.73 A`，电压还没顶满；带载另说。1800 以上 `|Id|` 毛刺变多，转速能跟、电流环仍不能当准。

软件电压上限：

```text
Vlim = min(ol_vq_limit, Vbus / √3) ≈ 24 / 1.732 ≈ 13.8 V
```

`PWM ideal` 是按逻辑 CCR、ARR、母线估的理想平均 αβ 幅值，**不是端子实测电压**。换成 `foc_svm` 之后它已经和 `|Vd,Vq|` 一致。旧 1.70 倍率在 2500 档曾出现请求顶满、PWM 理想只有约 7.8 V，那是 `svm_hqd` 比较值偏矮，见第 2 节。

## 3. 三种手段分别做什么

| 做法 | 改什么 | 是不是弱磁 | 对现在 |
|------|--------|------------|--------|
| Hall CCR 倍率 | 同一套 `svm_hqd` 的比较值 | 否 | **已撤销**。1.80 起转失败，改走 VESC SVM |
| 起步低倍率、起来再切高倍率 | 按转速切换 CCR | 否 | 不再做。速度环不能绑在调制分段上 |
| 抬母线电压 | `Vlim` 变大 | 否 | **不要**。电机铭牌 24 VDC |
| 负 Id 弱磁 | 削弱气隙磁链 | 是 | **还早**。空载 3000 `|V|≈10.3/13.7 V`，且高速 Id 仍不可信 |
| 一次换成完整线性 SVPWM | CCR 中心从约 ARR/4 挪到 ARR/2 | 否 | 2026-09-16 未取反直接换，150 起转约 58 RPM；20 日按 VESC 归一 + αβ 取反后已换上 |

VESC **没有** Hall CCR 倍率。Hall I/F 已走 `foc_svm_from_voltage`：`mod = 1.5 * v / v_bus`，再限幅到 `(√3/2)*0.95`，零电压 **ARR/2**。HD75 相序仍是 A-C-B；标准 `foc_svm` 叠这次交换后相对已验证的 `svm_hqd`/Park 差 180°，输入取反，否则起转 Id 正反馈到约 −12 A。电流环默认 `Kp=0.12`、`Ki=18`（按旧 1.70 倍率的带宽折算）；仍用 `olkp 0.2` 会在 150 RPM 过冲到约 210。弱磁学的仍是 VESC `foc_run_fw`（占空比门槛 + 负 Id），默认 0 A。

ODrive Pro 弱磁是实验项；SimpleFOC 没有自动弱磁。

弱磁只改 Id 目标，不改 PWM 外设，也不改 Iq。对齐 / 定角阶段强制 `Id_fw = 0`。

## 4. 当前排序：SVM 已对齐 → 空载 3000 先记下 → 弱磁仍等 Id 可信 → 不抬母线

### CCR 倍率已撤销

Hall 电流环不再乘 `MOTOR_HALL_PWM_GAIN`。旧 1.35～1.80 扫描只作历史，见第 2 节。

### 弱磁（空载 3000 电压还没顶满，且 Id 仍不可信）

负 Id 的物理前提是电机端电压接近 `Vbus/√3`。空载 3000 时 `|V|≈10.3 / 13.7 V`，`Speed Iq` 约 0.73 A，还没顶满。2026-09-16 开 `fw 1.5` 时 Id 不跟踪。现在 1800 以上 `|Id error|>1 A` 的样本明显变多，开弱磁同样跟不上。

打开弱磁的最低条件：

1. `PWM ideal` 接近请求 `|Vd,Vq|`，并接近 `Vbus/√3`。
2. 2000 RPM 上空载 Id 大体跟目标，不是扇区乱跳。
3. 从 150 RPM 起转，`fw_current_max` 从小值加起（例如 0.5 A）。

铭牌 3000 RPM 时 `ωeλ ≈ 16.2 V`，超过 13.8 V，**那时候**弱磁才是正路。下表假设电机端已经用满 `Vlim`，**不能**拿它解释 1.35 时的 1815 封顶。

```text
需要的 Id ≈ (Vlim / ωe − λ) / L     （负值）
```

| 机械转速 | ωeλ | Id=0、线性 SVPWM 用满时 | 约需 \|Id\|（L=0.8 mH） |
|----------|------|-------------------------|-------------------------|
| 1800 | 9.7 V | 能 | 0 |
| 2000 | 10.8 V | 能 | 0 |
| 2500 | 13.5 V | 临界 | ≈0 |
| 2700 | 14.5 V | 否 | ≈1.3 A |
| 3000 | 16.2 V | 否 | ≈4.6 A，超出台架电流圆 |

### 抬母线（本电机不要用）

BM75 输入大约 4.5～85 V，固件大约 6～74 V，是**驱动板**耐压。电机 `MOTOR_FIXED_RATED_VOLTAGE = 24.0` VDC。

## 5. 怎么判断「已经该换手段」

```text
Vd,Vq out : 软件电流环请求（会被 Vlim≈13.8 V 钳住）
PWM ideal : CCR 重建的理想平均电压
```

| 现象 | 含义 | 下一步 |
|------|------|--------|
| 请求顶满，`PWM ideal` 仍约倍率/3 | 调制没送出去 | 1.70 以前：加 CCR；**现在不要再加** |
| 150 RPM 起转失败（如 1.80） | 低速送出电压太大 | **回退**，或以后做转速分段倍率 |
| 脚本 ±10% 通过、实速贴着下限（2250/2500） | 验收容差掩盖平台 | 按实测写，不写「到了 2500」 |
| 请求与 `PWM ideal` 都接近 13.8 V | 电机端电压真用满 | **再谈弱磁** |
| 弱磁 Id 目标已负，实测不跟着走 | 电流/角度不可信 | **先修反馈** |

## 6. 弱磁模块怎么跑（默认关闭）

```text
上一拍 Vd、Vq
  → mod = |V| / Vlim
  → mod ≥ duty_start     目标 Id_fw = −fw_current_max
  → mod ≤ duty_start−0.05 目标 Id_fw = 0
  → 中间滞回，保持上一拍
  → 按 fw_ramp_a_s 斜坡
  → 再按电流圆削减 |Id_fw|（优先留 Iq）
  → Motor_Current_GetTargets：Id = ol_id_set×soft + id_fw
```

| 参数 | 默认 | 含义 |
|------|------|------|
| `fw_current_max` | 0 A | 弱磁 \|Id\| 上限，0=关 |
| `fw_duty_start` | 0.80 | 进入门槛；仅启用弱磁时生效 |
| `fw_ramp_a_s` | 8 A/s | Id 斜坡 |
| `MOTOR_FW_SUPPLY_CURRENT` | 3.0 A | 旧台架电源限流口径 |
| `MOTOR_FW_I_BUDGET` | 2.5 A | 定子电流圆 |

`fw` 命令和 `NormalizeConfig` 把 `fw_current_max` 钳在 **2.5 A**，不能设到铭牌 6.6 A。`fw_*` 不进 Flash，断电恢复代码默认值。

```text
|Id_fw| ≤ min(fw_current_max, √(I_budget² − Iq²))
Iq ≥ 2.5 A 时弱磁余量为 0
```

`spiq 0.8` 时目标弱磁余量最多约 2.37 A。

| 文件 | 职责 |
|------|------|
| `App/motor/motor_fw.c` | 滞回、斜坡、电流圆 |
| `App/motor/motor_control.c` 的 `RunIf` | 拖转阶段写回上一拍 Vd/Vq |
| `App/motor/motor_current.c` | 把 `id_fw` 叠进 Id 目标 |
| `App/cmd/cmd_openloop.c` | `fw` / `olsnap` / `olstatus` |
| `App/motor_param/motor_param.c` | 上电默认 |

```text
fw                      查询
fw 0                    关闭
fw 1.5                  只改 |Id| 上限
fw 1.5 0.80             上限 + 进入门槛
fw 2.0 0.80 8           再加上斜坡 A/s
```

`olsnap`：`Id, Iq` 的 target 含弱磁；`FW` 行有 max / duty。判断弱磁是否在干活：`|Vd,Vq|/Vlim` 过门槛、Id 目标变负、实测 Id 跟着走、转速还能贴近 `olspeed`。

UART 无响应：J-Link 复位停机，不要芯片擦除。
