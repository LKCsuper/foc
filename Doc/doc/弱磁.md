# Hall 提速：CCR、母线电压与弱磁

> 原名单「FOC 弱磁」。2026-09-19 按实机改成三种手段对照：当前优先加 Hall CCR 倍率，弱磁排后，抬母线最不合适。
> 弱磁模块代码仍在、默认关闭。`fw` 命令与参数见第 6 节。
>
> 配套：[电机铭牌](../../App/motor_param/inc/motor_nameplate.h) · [motor_fw](../../App/motor/motor_fw.c) · [命令行使用手册](./命令行使用手册.md) · [Hall FOC 提速调试经验](./Hall_FOC提速调试经验_2026-09-17.md) · [Hall 偶发 Id 毛刺](./Hall偶发Id毛刺_2026-09-19.md) · [1500 RPM 原因](./Hall_1500RPM达标原因与限制_2026-09-16.md)

口头说的 **oldriver** 即 ODrive。本机 2 对极、铭牌 24 VDC / 3000 RPM。

## 1. 现在卡在哪

BM75 / STM32F405RG，24 V，空载，Hall + I/F，`spiq 0.8`，`MOTOR_HALL_PWM_GAIN = 1.35`，`fw_current_max = 0`。

| 目标 | 结果 | 请求 `|Vd,Vq|` | `PWM ideal` | 母线 | 面板电流 |
|------|------|----------------|-------------|------|----------|
| 1800 RPM | 进入 ±2% | 贴近软件限幅 | 约请求的 0.45 | ~24 V | 约 0.22 A（高级电源） |
| 2000 RPM | 实测约 **1815 RPM**，脚本 ±2% 失败 | 约 13.74 / 13.81 V | 约 **6.18 V** | 23.9 V | 约 0.22 A（约 5.3 W） |

软件电压上限：

```text
Vlim = min(ol_vq_limit, Vbus / √3) ≈ 24 / 1.732 ≈ 13.8 V
```

`PWM ideal` 是按逻辑 CCR、ARR、母线估的理想平均 αβ 幅值，**不是端子实测电压**。当前请求已经顶到 13.8 V，电机端估算只有约 6.2 V。这是调制幅值没用满，不是反电势已经顶死 24 V 母线。

1500 RPM 曾被误判成「要弱磁」；ChatGPT 只把 Hall `svm_hqd` 的 CCR 乘 1.20 / 1.35 后，1500、1800 先后通过。2000 的签名与当时相同。

## 2. 三种手段分别做什么

| 做法 | 改什么 | 是不是弱磁 | 对当前 1815 封顶 |
|------|--------|------------|------------------|
| Hall CCR 倍率（1.20 → 1.35 → 1.40…） | 同一套 `svm_hqd` 的比较值，扇区/相序/PWM 外设不动 | 否 | **现在优先**。把软件请求更多地送到电机端 |
| 抬母线电压 | `Vlim` 变大 | 否 | **现在不要**。电机铭牌 24 VDC；板子能吃到约 74 V 不等于电机能吃 |
| 负 Id 弱磁 | 削弱气隙磁链，把 `ωeλ + ωe L Id` 压回 Vlim | 是 | **现在还早**。电机端电压远没到线性上限，且 Id 反馈还不可信 |
| 一次换成完整线性 SVPWM | CCR 中心从约 ARR/4 挪到 ARR/2 | 否 | 已试过，150 RPM 起转失败，已撤回 |

过调制、六步、方波也能提高可用电压，本仓库没有，也不当本轮手段。

VESC / ODrive / SimpleFOC 对「真弱磁」的态度：

| | 触发 | 动作 | 备注 |
|--|------|------|------|
| **VESC** | 占空比超过 `fw_duty_start`（默认约 0.9） | 斜坡加负 Id，上限 `fw_current_max` | 本仓库学这个；默认 `fw_current_max=0` |
| **ODrive Pro** | 实验项 `fw_enable`，按调制比 PI | 负 Id | 不是主路径默认 |
| **SimpleFOC** | 无自动弱磁 | 用户自己设 `Id` / `Ud` | 教学向 |

弱磁只改 Id 目标，不改 PWM 外设，也不改 Iq。对齐 / 定角阶段强制 `Id_fw = 0`。

## 3. 当前排序：CCR → 弱磁 → 母线

### 第一：继续加 Hall CCR（建议下一档 1.40，再不行 1.45）

理由：

1. 请求约 13.8 V、`PWM ideal` 约 6.2 V，比例仍约 0.45，和 1.35 倍率一致。电机端还有大约一倍的软件请求没出去。
2. 同一条路径已经用 1.20 过 1500、用 1.35 过 1800，变量单一、可回退。
3. 旧 `svm_hqd` 的 CCR 最大约 ARR/2；乘 1.35 后峰值约 0.55～0.61 ARR。1.40 / 1.45 仍低于 ARR，不必先改外设。
4. 一次换成完整 SVPWM 已在 150 RPM 失败，本轮不走那条。

约束（未改代码前不要破）：

- 从 **150 RPM** 起转，逐档升，不要直接 1800。
- 弱磁保持 0 A，不改 ADC / PWM / TIM / DMA。
- 一次只改倍率。过流看 `|i_abs|=hypot(Id,Iq)`，不要把偶发 `|Id|>1` 当过流；见 [偶发 Id 毛刺](./Hall偶发Id毛刺_2026-09-19.md)。

### 第二：弱磁（等 PWM 真正顶满，且 Id 跟得上目标）

负 Id 的物理前提是：**电机端电压已经接近 `Vbus/√3`**。现在 `PWM ideal` 只有约 6.2 V，先灌负 Id 等于在电压还没用满时抽转矩电流配额。

2026-09-16 曾在电流跟踪很差时开 `fw 1.5`：800 RPM 个别扇区 Id 已偏，1200 RPM 三次快照 Id 为 −0.187、−3.183、+1.911 A，1500 RPM 卡在约 1278 RPM。弱磁没有帮上忙。默认已改回 0 A。

打开弱磁的最低条件：

1. `PWM ideal` 接近请求 `|Vd,Vq|`，并接近 `Vbus/√3`（不再是 0.45 这种比例）。
2. 空载面板电流、`olcurdiag`、扇区 Id 能说明电流环大致在跟目标，而不是扇区乱跳。
3. 仍从 150 RPM 起转，`fw_current_max` 从小值加起（例如 0.5 A），不要一上来 1.5 A。

铭牌 3000 RPM 时 `ωeλ ≈ 16.2 V`，超过 13.8 V 的线性上限，**那时候**弱磁才是正路。L 用的是铭牌线电感 0.8 mH，没有 R/L 实测，Id 需求只是数量级。

```text
需要的 Id ≈ (Vlim / ωe − λ) / L     （负值）
```

| 机械转速 | ωeλ | Id=0、线性 SVPWM 用满时 | 约需 \|Id\|（L=0.8 mH） |
|----------|------|-------------------------|-------------------------|
| 1800 | 9.7 V | 能 | 0 |
| 2000 | 10.8 V | 能 | 0 |
| 2500 | 13.5 V | 临界 | ≈0 |
| 2700 | 14.5 V | 否 | ≈1.3 A |
| 3000 | 16.2 V | 否 | ≈4.6 A，超出台架电流圆 |

上表假设电机端已经用满 `Vlim`。当前 Hall 调制远未用满，**不能拿这张表解释 1815 RPM 封顶**。

### 第三：抬母线（本电机不要用）

BM75 输入大约 4.5～85 V，固件大约 6～74 V，那是**驱动板**耐压，不是电机耐压。电机 `MOTOR_FIXED_RATED_VOLTAGE = 24.0` VDC。空载再抬母线会把反电势和绝缘都往上推，收益是 `Vlim` 变大，但本轮瓶颈在 CCR 比例，不在 24 V 不够。

电源从旧的 3 A 限流换成高级电源、面板约 0.22 A，只说明空载铜耗/铁耗很小，**不能**据此把母线升到 36 V / 48 V。

## 4. 怎么判断「已经该换手段」

同时看这两行，不要只看 `|Vd,Vq|`：

```text
Vd,Vq out : 软件电流环请求（会被 Vlim≈13.8 V 钳住）
PWM ideal : CCR 重建的理想平均电压
```

| 现象 | 含义 | 下一步 |
|------|------|--------|
| 请求顶满，`PWM ideal` 仍约 0.45×请求 | 调制没送出去 | **加 CCR** |
| 请求与 `PWM ideal` 都接近 13.8 V，转速仍不够 | 电机端电压真用满了 | **再谈弱磁** |
| 打开弱磁后 Id 目标已负，实测 Id 不跟着走 | 电流/角度不可信 | **先修反馈，不要加 |Id|** |
| 150 RPM 起转失败或过流 | 倍率/调制太大或采样窗口被破坏 | **回退上一档**，不要改外设凑 |

## 5. 建议试验顺序（尚未改固件）

1. `MOTOR_HALL_PWM_GAIN` 1.35 → **1.40**。编译、烧录（SWD 100 kHz，不要芯片擦除），`olstop` 确认 `FW max=0`。从 150 RPM 起，过 1800 后再打 2000。
2. 若仍停在约 1815，再试 **1.45**，同样从 150 起。
3. 若 `PWM ideal` 已经贴近 13.8 V 仍上不去，再开弱磁小电流。
4. 不抬母线。不改 VESC 基线 ADC/PWM/TIM/DMA。

## 6. 弱磁模块怎么跑（默认关闭）

```text
上一拍 Vd、Vq
  → mod = |V| / Vlim
  → mod ≥ duty_start     目标 Id_fw = −fw_current_max
  → mod ≤ duty_start−0.05 目标 Id_fw = 0
  → 中间滞回，保持上一拍
  → 按 fw_ramp_a_s 斜坡
  → 再按电流圆削减 |Id_fw|（优先留 Iq）
  → Motor_Current_GetTargets：Id = ol_id_set×soft + id_fw
```

| 参数 | 默认 | 含义 |
|------|------|------|
| `fw_current_max` | 0 A | 弱磁 \|Id\| 上限，0=关 |
| `fw_duty_start` | 0.80 | 进入门槛；仅启用弱磁时生效 |
| `fw_ramp_a_s` | 8 A/s | Id 斜坡 |
| `MOTOR_FW_SUPPLY_CURRENT` | 3.0 A | 旧台架电源限流口径 |
| `MOTOR_FW_I_BUDGET` | 2.5 A | 定子电流圆 |

`fw` 命令和 `NormalizeConfig` 把 `fw_current_max` 钳在 **2.5 A**，不能设到铭牌 6.6 A。`fw_*` 不进 Flash，断电恢复代码默认值。

```text
|Id_fw| ≤ min(fw_current_max, √(I_budget² − Iq²))
Iq ≥ 2.5 A 时弱磁余量为 0
```

`spiq 0.8` 时目标弱磁余量最多约 2.37 A。

| 文件 | 职责 |
|------|------|
| `App/motor/motor_fw.c` | 滞回、斜坡、电流圆 |
| `App/motor/motor_control.c` 的 `RunIf` | 拖转阶段写回上一拍 Vd/Vq |
| `App/motor/motor_current.c` | 把 `id_fw` 叠进 Id 目标 |
| `App/cmd/cmd_openloop.c` | `fw` / `olsnap` / `olstatus` |
| `App/motor_param/motor_param.c` | 上电默认 |

```text
fw                      查询
fw 0                    关闭
fw 1.5                  只改 |Id| 上限
fw 1.5 0.80             上限 + 进入门槛
fw 2.0 0.80 8           再加上斜坡 A/s
```

`olsnap`：`Id, Iq` 的 target 含弱磁；`FW` 行有 max / duty。判断弱磁是否在干活：`|Vd,Vq|/Vlim` 过门槛、Id 目标变负、实测 Id 跟着走、转速还能贴近 `olspeed`。

UART 无响应：J-Link 复位停机，不要芯片擦除。
