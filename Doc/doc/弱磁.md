## 1. 为什么额定 3000 RPM 需要弱磁

本机 ATK-BL57H95D20E：4 极 / 2 对极，24 V，Ke = 6.6 V/kRPM（线间 RMS），λ = 0.02573 Wb。

线性 SVPWM 电压上限：

```text
Vlim = Vbus / √3 ≈ 24 / 1.732 ≈ 13.9 V
```

反电势（相电压峰值）：

```text
ωe      = 2π × n × 极对数 / 60
ωe λ    = Ke_line_rms × n/1000 × √2 / √3
3000 RPM → ωe ≈ 628 rad/s → ωeλ ≈ 16.2 V
```

Id = 0 时，理想线性 SVPWM 的相电压峰值上限约为 13.9 V。电压顶满会使速度 PI 增加 Iq 也无法继续提速。但本仓库旧 Hall 调制的 CCR 幅值约为软件电压请求的三分之一；曾在 1500 RPM 附近看到的 `|Vd,Vq|≈13.2 V` 是软件请求，并不能证明电机端已到理想线性调制上限。第 8 节的小步调制试验在未弱磁时已达到 1500 RPM。

负 Id 削弱气隙磁链，把 `ωeλ + ωe L Id` 压回 Vlim 以内，电压余量还给 Iq。这才叫弱磁。过调制、六步、抬母线也能提高基速，但机制不同。

## 2. 哪些方案是弱磁，哪些不是

| 做法 | 是不是弱磁 | 说明 |
|------|------------|------|
| 负 Id / 负 λd | 是 | 本仓库当前路径 |
| 过调制、六步、方波 | 否 | 提高可用电压，不改磁链 |
| 抬母线电压 | 否 | 直接加大 Vlim |
| 手动把 Ud 打负（SimpleFOC 常见） | 是（人工） | 没有自动环 |

VESC / ODrive / SimpleFOC：

| | 触发 | 动作 | 备注 |
|--|------|------|------|
| **VESC** | 占空比（电压利用率）超过 `fw_duty_start`（默认约 0.9） | 按斜坡加负 Id，上限 `fw_current_max` | 本仓库学这个 |
| **ODrive Pro** | 实验项 `fw_enable`，按调制比 PI | 负 Id | 不是主路径默认 |
| **SimpleFOC** | 无自动弱磁 | 用户自己设 `Id` / `Ud` | 教学向 |

本模块只改 Id 目标，不改 PWM 外设，也不改 Iq。对齐 / 定角阶段强制 Id_fw = 0，避免把转子按进齿槽。

## 3. 本仓库怎么跑

```text
上一拍 Vd、Vq
  → mod = |V| / Vlim
  → mod ≥ duty_start     目标 Id_fw = −fw_current_max
  → mod ≤ duty_start−0.05 目标 Id_fw = 0
  → 中间滞回，保持上一拍
  → 按 fw_ramp_a_s 斜坡
  → 再按电流圆削减 |Id_fw|（优先留 Iq）
  → Motor_Current_GetTargets：Id = ol_id_set×soft + id_fw
```

| 参数 | 默认 | 含义 |
|------|------|------|
| `fw_current_max` | 0 A | 弱磁 \|Id\| 上限，0=关；本次实测后默认关闭 |
| `fw_duty_start` | 0.80 | 进入门槛；仅在手动启用弱磁时生效 |
| `fw_ramp_a_s` | 8 A/s | Id 斜坡，避免一步灌满 |
| `MOTOR_FW_SUPPLY_CURRENT` | 3.0 A | 台架可调电源 |
| `MOTOR_FW_I_BUDGET` | 2.5 A | 定子电流圆，留 0.5 A 给纹波和启动 |

`fw` 命令和 `NormalizeConfig` 把 `fw_current_max` 钳在 **2.5 A**，不能设到铭牌 6.6 A。此限制只约束目标电流，实测瞬时电流仍须监测。

电流圆：

```text
|Id_fw| ≤ min(fw_current_max, √(I_budget² − Iq²))
Iq ≥ 2.5 A 时弱磁余量为 0
```

Hall 验证常用 `spiq 0.8` 时，按目标值计算的弱磁余量最多约 2.37 A；实测电流可能超出目标电流圆。

相关文件：

| 文件 | 职责 |
|------|------|
| `App/motor/motor_fw.c` | 滞回、斜坡、电流圆余量 |
| `App/motor/motor_control.c` 的 `RunIf` | 拖转阶段调用，写回上一拍 Vd/Vq |
| `App/motor/motor_current.c` | 把 `id_fw` 叠进 Id 目标 |
| `App/cmd/cmd_openloop.c` | `fw` / `olsnap` / `olstatus` |
| `App/motor_param/motor_param.c` | 上电默认；**不写入 Flash** |

## 4. 3 A 电源下能跑多快

电源 3 A 是直流母线电流，不是电机铭牌 6.6 A。弱磁 Id 和 Iq 加在同一个定子电流圆上，电源还要供铜耗和机械功率。

下面按 **L = 0.8 mH（代码里的线电感）**、Vbus = 24 V、空载、线性 SVPWM 估算。若实际相电感接近 L_line/2 = 0.4 mH，同样 |Id| 能压掉的反电势更少，转速更低。

```text
需要的 Id ≈ (Vlim / ωe − λ) / L     （负值）
```

| 机械转速 | ωeλ | Id=0 能否到 | 约需 \|Id\|（L=0.8 mH） | 3 A 台架 |
|----------|------|-------------|-------------------------|----------|
| 1200 | 6.5 V | 能 | 0 | 已实测过（无弱磁） |
| 1500 | 8.1 V | 理论上能，实机曾顶满 | 0～少量 | 弱磁固件后应再测 |
| 2500 | 13.5 V | 临界 | ≈0 | 空载优先看这里 |
| 2700 | 14.5 V | 否 | ≈1.3 A | 理想模型估算，尚未实测 |
| 2800 | 15.1 V | 否 | ≈2.4 A | 顶满电流圆，Iq 必须很小 |
| 3000 | 16.2 V | 否 | ≈4.6 A | **电源不够** |

上述只是理想电机模型估算，**不是本台架当前可达转速**。目前 Hall 调制小步试验已通过 1500 RPM，但 Id/Iq 仍有扇区偏差；更高转速需要先解决电流跟踪并复核电源电流。

母线电流在空载高速时主要是损耗，不一定等于 |Id|。仍把电源 3 A 限流开着：启动、加速、Iq 顶满时更容易撞限流。

## 5. 串口怎么用

上电默认弱磁关闭（0 A / 0.80 / 8 A/s）。仅在排查电流跟踪问题后受控启用：

```text
fw                      查询
fw 0                    关闭
fw 1.5                  只改 |Id| 上限
fw 1.5 0.80             上限 + 进入门槛
fw 2.0 0.80 8           再加上斜坡 A/s
```

`olsnap` 里：

```text
Id, Iq : <实测> (target <含弱磁的 Id> <Iq>)
FW     : max=... duty=...
```

判断是否在弱磁：

1. `|Vd,Vq| / (Vbus/√3)` 接近或超过 0.80
2. Id 目标变成负数，且实测 Id 跟着走
3. 转速还能继续贴近 `olspeed`；若 Id 已负、电压仍满、转速不再涨，就是电流/电压都到头了

1200/1500 RPM 的早期复测异常后曾暂停弱磁升速；第 8 节的弱磁关闭试验已通过 1500 RPM。下一轮先复核 Hall 扇区角度、Id/Iq 和电源电流，再设计受限的更高转速验证。

UART 若再次无响应：J-Link 复位停机，不要芯片擦除。

## 6. 2026-09-16 实机复测

使用 STM32F405RG、COM16、24 V 母线、Hall 速度环、`spiq 0.8`，弱磁设为 1.5 A / 0.80 / 8 A/s，逐档升速。主机测试全部通过，Keil 编译 0 错误、0 警告，J-Link 烧录校验成功。完整记录见 [1500 RPM 日志](../verify/hall_verify_da452b0f-dirty_20260916-220414_1500RPM.log)。

| 目标 | 结果 | 关键观测 |
|------|------|----------|
| 800 RPM | 781～827 RPM | `|V|` 约 8.3～8.5 V；个别扇区 Id 实测约 −0.94 A，而目标为 0 |
| 1200 RPM | 约 1278 RPM | 弱磁目标 Id=−1.5 A；三次快照 Id 为 −0.187、−3.183、+1.911 A，输出 `|V|` 约 13.1～13.7 V |
| 1500 RPM | 约 1278 RPM，失败 | Iq 目标 0.8 A、实测 −0.202 A，Id 目标 −1.5 A、实测 −0.324 A；`|V|`=13.573/13.871 V；脚本中止并确认 `olstop` |

弱磁没有突破 1500 RPM。Id/Iq 在不同霍尔扇区明显不跟随目标；1200 RPM 曾采到约 3.18 A 的 Id 幅值。当前不继续升速，先排查霍尔角度、相电流采样与电流环饱和。输出电压接近上限是真实观测，但单靠这一点不能确定根因是反电势。

测试结束后已把默认 `fw_current_max` 改为 0 A，主机测试与 Keil 编译再次通过，并烧录校验。复位后串口查询 `FW: max=0.00 A`，`olsnap` 显示 `Enable: OFF`、三相中点占空比、无故障；随后再次收到 `olstop` 确认。

## 7. Hall 更新节拍与调制对照

原 Hall 软件分频位于 15 kHz FOC 控制拍之后，却设为 32，实际只约 469 Hz；1500 RPM 时每个 Hall 扇区约 3.33 ms，只有 1～2 次角度更新。将软件分频改为 4（约 3.75 kHz）后，弱磁关闭条件下连续两次 1200 RPM 复测均通过。第二次升至目标 1500 RPM，脚本按 ±12% 容差判为通过，但三次实测仅 1339.3、1339.3、1323.5 RPM，Iq 目标 0.8 A，输出电压**请求**为 13.80～13.85 V / 约 13.85 V 限幅。日志：[1200 RPM](../verify/hall_verify_da452b0f-dirty_20260916-221246_1200RPM.log)、[1500 RPM](../verify/hall_verify_da452b0f-dirty_20260916-221427_1500RPM.log)。

静态检查发现历史 `svm_hqd` 的 CCR 公式只使用部分 PWM 周期；按理想占空比重建逻辑 αβ，轴向幅值约为输入的 1/3。为验证此点，曾仅对 Hall 电流闭环试用标准线性 SVPWM。主机测试与 Keil 编译通过，但上板 150 RPM 起转仅约 58 RPM，脚本立即中止。日志：[调制试验](../verify/hall_verify_da452b0f-dirty_20260916-222044_150RPM.log)。该试验代码已撤回，控制板重新烧录此前通过 1200 RPM 测试的调制路径；复位后确认弱磁 0 A、输出关闭、无故障。**因此尚不能把 CCR 算式的理论比例直接当作电机端实测电压比例**，还需核对 PWM 有效极性、A/C/B 物理映射、逆 Park 符号、采样窗口与各扇区输出。试验把 CCR 中心从历史约 1/4 周期移到 1/2 周期，可能影响固定时刻的电流采样；该因果关系尚未测定。

恢复固件重新运行 150 RPM 三次快照通过，脚本停机；停机后 `olsnap` 再次确认输出关闭、CCR 全为 2800、弱磁 0 A、无故障。日志：[恢复验证](../verify/hall_verify_da452b0f-dirty_20260916-222409_150RPM.log)。

新增 `olsnap` 的 `PWM ideal`，按三路逻辑 CCR 和母线电压估算理想平均 αβ 电压幅值，**不是端子实测电压**。保持旧调制、弱磁关闭、Iq 上限 0.8 A 再测：[150 RPM](../verify/hall_verify_da452b0f-dirty_20260916-223247_150RPM.log) 三次通过；[逐档至 1500 RPM](../verify/hall_verify_da452b0f-dirty_20260916-223448_1500RPM.log) 在 1200 RPM 约 1197 RPM，通过；1500 RPM 首次快照约 1323.5 RPM，超出 ±5% 后脚本停机。该快照请求 `|Vd,Vq|=13.815 V`，CCR 理想估算仅 `4.603 V`，比例为 0.333；150 RPM 的请求约 1.8 V，CCR 估算约 0.6 V，比例相同。故目前的 13.8 V 是**软件请求限幅**，不能据此认定电机端已用满 24 V 母线的线性调制范围。应先解决调制比例与电流/霍尔角跟踪，再重新评估弱磁需求。

静态复核确认 FOC 电流环读取规则组 ADC/DMA 缓冲的 CURR1/2/3，当前没有读取注入组结果；TIM2 的规则组触发时刻由 TIM1 更新同步。标准调制在 150 RPM 失败的原因仍未定位，不能仅归因于 ADC 采样窗口。VESC 锁定源码 `ThirtyLibrary/bldc/motor/foc_math.c` 的标准 `foc_svm` 与现有 `svm_hqd` 公式不同；本轮没有改动 ADC、PWM、TIM、DMA 或同步触发配置。

## 8. Hall 调制小步试验：1500 RPM 通过

只在 Hall + I/F 电流模式下，把旧 `svm_hqd` 的三路逻辑 CCR 统一乘以 1.2，保留扇区、相序、PWM/ADC/TIM/DMA 设置及弱磁默认关闭。原公式 CCR 最大不超过 ARR/2，因此此试验最大不超过 0.6 ARR。先以 [150 RPM](../verify/hall_verify_da452b0f-dirty_20260916-223922_150RPM.log) 三次快照验证通过，再 [逐档升至 1500 RPM](../verify/hall_verify_da452b0f-dirty_20260916-224126_1500RPM.log)：

| 目标 | 结果 | 关键观测 |
|------|------|----------|
| 1200 RPM | 三次通过；最后一次 1196.8 RPM | 请求电压约 10.36 V，CCR 理想估算约 4.14 V |
| 1500 RPM | 1480.3、1480.3、1500.0 RPM；三次均在 ±5% 内 | 弱磁 0 A；请求电压约 12.86～13.00 V，CCR 理想估算约 5.14～5.20 V；脚本停机确认 |

与旧调制下 1500 RPM 仅约 1323.5 RPM 对比，小幅提高实际占空比幅值后已可接近目标；因此 1500 RPM 不需要先加入负 Id。仍有明显电流跟踪问题：1500 RPM 的三次快照中 Id 为 +0.880、+0.412、−0.394 A，而目标均为 0 A，Iq 也有偏差。`PWM ideal` 仍只是 CCR 理想估算，电源面板的实时电流未采集。当前不据此升到 2000/3000 RPM 或验收弱磁。

## 9. Hall ADC 帧方向诊断

只读统计显示，原 Hall 电流环有时选 TIM1 向上计数侧、有时选向下计数侧；一次 [150 RPM 记录](../verify/hall_verify_da452b0f-dirty_20260916-224548_150RPM.log) 中 `up` 停在 343305，而 `down` 在约 3 秒内从 50530 增至 95571。另一次 [1500 RPM 记录](../verify/hall_verify_da452b0f-dirty_20260916-225046_1500RPM.log) 在运行期间只增加 `down`，1500 RPM 三次快照为 1500、1480、1520 RPM。由于本板是低边三分流电阻，TIM1 顶部零矢量后的向下侧是更合适的共同采样窗口。

据此只在 Hall 电流环选择向下计数侧的现有 ADC/DMA 帧；未修改 ADC、PWM、TIM、DMA 或同步触发配置。[150 RPM](../verify/hall_verify_da452b0f-dirty_20260916-225238_150RPM.log) 三次通过；[逐档至 1500 RPM](../verify/hall_verify_da452b0f-dirty_20260916-225440_1500RPM.log) 三次快照均为 1500 RPM，脚本停机确认。运行期间只有 `down` 计数增长。不过 1500 RPM 的 Id 仍为 +0.294、−0.384、+0.711 A（目标 0），三相电流和也不稳定。因此只能确认采样侧已固定、1500 RPM 通过；不能宣称电流误差已经解决。继续提速前需要核对电流采样波形、零偏与电源面板实际电流。

## 10. 尚未验收

- Hall 1500 RPM 已在弱磁关闭、20% 调制小步试验下通过；弱磁本身尚未验收，2000 RPM 及以上未测试。
- L 用的是铭牌线电感，没有 R/L 实测，Id 估算有偏差。
- 没有过调制，Vlim 仍是 `Vbus/√3`。
- `fw_*` 不进 Flash，断电恢复代码默认值。
- 带载 3000 RPM 超出本台架能力，不做验收目标。
