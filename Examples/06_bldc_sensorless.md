# 06 无感 BLDC 六步上板验证

本例验证传统 BLDC 六步换相与 BEMF 伏秒积分无感控制。反电势物理、悬空相、过零与积分、BM75 采样链见 [BEMF原理.md](../Doc/doc/BEMF原理.md)。代码和 PC 测试通过不代表功率板已经验证；第一次通电必须低压、限流、空载。

## 前提

- 电机三相接到 A/B/C 输出，母线先使用安全低压，电源限流设得足够低。
- 串口 Shell 可用，公共电流/母线电压偏移已经校准，硬件过流或 Break 能关断功率级。
- 示波器优先观察三相端电压与门极驱动输出，不要在高压下首次尝试。

## 操作顺序

1. 上电后先查询状态：

   ```text
   bldc status
   ```

   预期 `selected=0`、`running=0`、`mode=IDLE`。

2. 在不接电机或功率受限条件下，先核对六步输出映射。当前命令直接进入自动启动，因此建议用示波器确认 A/B/C 中每一步是一相 PWM、一相下管导通、一相悬空；若相序或极性不符，应先停机检查 HAL 映射，不要靠提高占空比硬转。

3. 空载电机先使用当前已验证的 8% 受限闭环基线：

   ```text
   bldc start 0.08 cw
   bldc status
   ```

   `mode` 正常会从 `ALIGN` 进入 `OPEN_LOOP`，开环斜坡到达 12 ms 稳定周期后进入 `CLOSED_LOOP`。启动中可重复执行 `bldc status`。

   闭环使用 BEMF 伏秒积分换相：消隐后只累加正确极性且超过噪声带的 BEMF 面积，避免单个 PWM 尖峰直接换相。
   当前阶段把最短扇区周期锁在 12 ms，并限制单步周期变化，先验证六步极性和积分路径；尚未开放宽范围自动调速。
   `tune` 的参数只在本次上电期间有效，并且只能在 BLDC 停止时设置。
   若闭环仍剧烈抖动，可先做固定周期开环分界测试：

   ```text
   bldc open 0.08 12.5 cw
   bldc status
   bldc stop
   bldc exit
   ```

   `12.5` 表示每个 60° 电气扇区固定 12.5 ms，状态应为 `OPEN_FIXED`。该模式记录 BEMF 极值和八段波形，但采样结果不会改变固定换相周期。
   开环也抖优先检查六步表、相序和桥臂波形；开环平顺而自动模式抖则检查 BEMF 采样与换相时刻。

4. 若方向不对，先停止并退出，再换方向：

   ```text
   bldc stop
   bldc exit
   bldc start 0.05 ccw
   ```

5. 实验结束：

   ```text
   bldc stop
   bldc status
   bldc exit
   ```

`stop` 会关闭 PWM 并保留 BLDC 对输出的占用，避免 FOC 的中点输出覆盖三相悬空；`exit` 才把调度权交回 FOC，且不会自动启动 FOC。

## 抖动问题的排查步骤

排查时不要一开始就调积分阈值、换相相位或 ADC 外设。先用对照试验确定问题属于功率换相、启动斜坡，还是 BEMF 闭环。

### 1. 先确认硬件事实

1. 以 `Doc/sch/BM75_IO定义.md` 和原理图为基准，确认本板是 BM75/HD75，不套用 BM60 或 DRV8323 的引脚配置。
2. 确认 TIM1 CH1/2/3 对应 INHA/B/C，SENS1/2/3 来自三个半桥中点。
3. 确认 BLDC 集成入口恢复了原理图 ABC 采样顺序，不能把 FOC 内部的 ACB 映射直接当成 BLDC 逻辑相序。
4. 确认 PC13 `SENS_FILTER` 的电气作用。当前 BLDC 运行时断开该滤波，避免相电压滤波延时改变 BEMF 相位。

这一步的原则是：外设和引脚必须由原理图证明，不能因为某个参考工程“也是 VESC”就直接替换。

### 2. 用固定开环分离问题

先运行已经证明基本平稳的工作点：

```text
bldc open 0.08 12.5 cw
bldc status
bldc stop
bldc exit
```

根据现象分流：

| 现象 | 优先检查 | 不要先做的事 |
| --- | --- | --- |
| 固定开环也持续剧烈抖动 | 六步表、ABC 相序、PWM/LOW/悬空桥臂、负载与周期 | 不要调 BEMF 阈值 |
| 只在起步抖，后续稳定 | 定向力矩和开环斜坡是否过快 | 不要换 ADC 通道 |
| 固定开环平稳，自动闭环抖动 | BEMF 极性、采样时刻、换相判据和周期限幅 | 不要改功率桥六步表 |
| 12.5 ms 可顺滑运行，8 ms 失步 | 转子的可跟随速度边界 | 不要让闭环一步跳到 8 ms 以下 |

本次实测中，`bldc open 0.08 12.5 cw` 可重复顺滑运行，而 8 ms 时已无法稳定跟随。这个对照证明六步功率输出不是主要矛盾，并给出了闭环先锁定 12 ms 附近的实测依据。

### 3. 用状态数据判断是否伪同步

`mode=CLOSED_LOOP` 和 `fault=NONE` 只说明状态机没有报错，不能单独证明电机真正顺滑。还应同时看：

- `last_period/step` 六个周期是否接近；长短严格交替通常是换相相位错误或错过当前扇区。
- `period_range` 是否突然扩大；周期快速压缩到转子跟不上的区域会引起失步。
- `min/step` 和 `max/step` 的极性是否与当前六步表一致；数据均衡不等于极性正确。
- `commutations` 是否持续增加，以及听感、轴的连续性和示波器波形是否一致。

曾经的过零方案出现过约 `47 ms, 4 ms, 47 ms, 4 ms` 的长短步交替。即使六个 step 都有计数，电机仍剧烈抖动。真正有价值的证据是“各扇区换相时间是否一致”，而不是“有没有过零计数”。

### 4. 最终解决方法

本项目当前收敛到 VESC 风格的 BEMF 伏秒积分受限闭环：

1. 定向后用 80 ms 到 12 ms 的平滑开环斜坡加速。
2. 达到已验证的 12 ms 工作点后，从下一个完整扇区进入积分闭环。
3. 使用 `Vbus/2` 作为虚拟中性点；换相消隐后，根据 step 和悬空相确定正确 BEMF 极性。
4. 忽略负向区域和噪声带，只累加能产生正向转矩的 BEMF 面积。
5. 积分达到阈值后换相，但当前仍受 12 ms 最短周期和每步 10% 变化限制约束。
6. 预测最长周期无条件生效；保护换相不写回正常周期估计，避免一次漏检把周期不断拉长。
7. 按 step 分别统计积分/保护换相，并用八段 BEMF 波形验证极性，而不是用“有过零计数”代替机械验证。

当前实测顺滑的命令为：

```text
bldc start 0.08 cw
bldc status
bldc stop
bldc exit
```

固件当前阈值为 `0.0004 V·s`，最短 60° 换相周期为 12 ms。这是约 24 V、8% 占空比、当前电机空载条件下的已测起点，不是任意电机、电压或负载的通用参数。当前阈值会早于 12 ms 达到，因此本次“顺滑”主要验证受限闭环，不代表阈值标定已经完成。

## 这次排查学到了什么

### 可以直接复用的技术经验

- 无感 BLDC 的“传感器”实际是整条采样链：半桥中点、分压、滤波开关、ADC 触发时刻、相序映射和软件中性点缺一不可。
- 六步换相是 60° 电角度一步，不是机械角度。电机能否跟上由扇区周期、极对数、负载和转动惯量共同决定。
- 一个过零点是瞬时值，对 PWM 尖峰、振铃和滤波相移很敏感；伏秒积分利用一段波形的面积，对单点噪声更不敏感。
- 闭环必须有速度变化限制。检测器即使给出一个“很快”的结果，也不能立即命令磁场跳到转子无法跟随的速度。
- 开环平稳只能证明功率桥、六步表和该工作点基本正确；不能证明无感闭环相位正确。
- 状态机“没报错”不等于控制质量合格。需要把日志、波形、机械感受和对照试验放在一起判断。

### 排查方法上的教训

- 每次只改一个可验证假设，并事先写明预期现象。同时改相序、极性、阈值和外设，即使现象变好也无法知道真正原因。
- 先做最小对照试验。本次最有价值的不是又调了一个阈值，而是固定开环 12 ms 与自动闭环的对比。
- 参考 VESC 和 AM32 时应学习控制思路，再根据本板原理图做适配；不能直接复制它们的 ADC 通道、定时器或门极驱动配置。
- 找到稳定路径后要删除失败的生产分支。长期保留两套策略、多个调参开关和已失效的统计，会让下一次调试更难。

### 你可以从中掌握的能力

1. 把“电机抖”这种主观现象拆成功率输出、开环同步、反电动势检测和闭环换相四个可验证环节。
2. 用固定参数的 A/B 对照定位问题，而不是靠听感随机调参。
3. 从每步周期、BEMF 极值和积分换相数中识别伪闭环和失步。
4. 区分“参考算法”与“硬件配置”：前者可以借鉴，后者必须回到自己的原理图。
5. 用保守的已测边界建立基线，再逐项扩展到更高转速、更高占空比和带载工况。

## 需要记录

- `ALIGN`、`OPEN_LOOP`、`CLOSED_LOOP` 的持续时间。
- `commutations` 是否持续增加，`bemf` 极性是否与换相步一致。
- 三相端电压、悬空相波形、母线电流和电机声音。
- `fault` 与 `motor_fault` 的数值，以及故障发生时所处模式。

## 串口自动采集

PC 安装 `pyserial` 后，可用 `Scripts/bldc_capture_serial.py` 执行有时限的单次采集。脚本会自动停止旧状态、启动 BLDC、周期读取 `status`，正常结束、故障或 `Ctrl+C` 后都会请求 `bldc stop` 和 `bldc exit`。

自动积分模式采集：

```powershell
python Scripts/bldc_capture_serial.py --port COM17 --mode auto --duty 0.10 --period-ms 13 --integral-mvs 0.4 --duration 20 --note "空载，有声"
```

固定开环对照采集：

```powershell
python Scripts/bldc_capture_serial.py --port COM17 --mode open --duty 0.10 --period-ms 13 --duration 20 --note "空载，声音较小"
```

默认在 `Doc/verify/` 生成同名 `.log` 和 `.csv`。`.log` 保留完整串口原文，`.csv` 用于对比周期、BEMF、积分和换相数。运行中要保持功率限流；不要用手直接接触旋转的转子或负载。

### 一键编译、烧录、采集和分析

连接 J-Link、串口和限流电源后，在根目录执行：

```powershell
.\bldc_test.ps1 -Port COM18 -Mode auto -Duty 0.08 -Duration 20
```

脚本依次执行以下操作：

1. 通过串口请求 `bldc stop` 和 `bldc exit`。
2. 调用 Keil 批编译 Foc 工程，并检查日志中是否存在编译错误。
3. 检查 `foc.hex` 不早于当前 App 源码，防止烧录旧产物。
4. 使用 J-Link SWD 烧录 STM32F405RG，并复位运行。
5. 等待串口恢复，执行有时限的 BLDC 测试，最终停止并退出。
6. 保存日志和 CSV，自动报告控制状态、故障和六步周期离散程度。

找不到工具时可显式指定：

```powershell
.\bldc_test.ps1 -Port COM18 `
  -Uv4 "D:\Users\15403\AppData\Local\Keil_v5\UV4\UV4.exe" `
  -JLink "D:\Users\15403\AppData\Local\Keil_v5\ARM\Segger\JLink.exe"
```

固定开环对照使用 `-Mode open -PeriodMs 13`。自动模式默认不发送 `bldc tune`，使用固件内的启动学习参数。任何编译、产物校验、烧录、串口或运行故障都会中止后续步骤。自动分析只能验证控制器换相时序，不能证明转子实际同步；即使周期均匀且无软件故障，只要听感或机械振动异常，仍按不稳定处理。

## 已验证基线

2026-09-13 在 BM75/HD75、约 24 V、8% 占空比、空载条件下，`bldc start 0.08 cw` 的受限 BEMF 积分闭环由用户确认为“实际顺滑”。日志 `Doc/verify/bldc_pipeline_20260913-222442.log` 显示六个 step 均为 12.000 ms，积分换相分别为 `211,211,212,212,211,211`，保护换相全为 0，总积分换相 1268 次，控制和公共保护均无故障。

该结果证明当前工作点的六步表、ABC/浮空相映射、`Vbus/2` 中性点、偶正奇负积分极性、开闭环接管和保护逻辑能够协同工作。它只是受限空载基线，不代表重复启停、CCW、带载、堵转、更高转速、积分阈值标定或硬件 Break 已通过。

## 常见失败

- `start rejected`：FOC 仍在运行、保护已锁存、方向无效或占空比不在 `(0, 0.25]`。
- `STARTUP_TIMEOUT`：开环斜坡未完成接管，常见原因是相序、采样映射、负载或启动占空比不合适。
- `BEMF_LOST`：已经接管后超过限定时间仍未达到积分阈值；先检查悬空相采样、极性和消隐时间。
- 抖动或反转：立即 `bldc stop`，核对 A/B/C 逻辑相序和六步表，不要直接增加电压或占空比。
